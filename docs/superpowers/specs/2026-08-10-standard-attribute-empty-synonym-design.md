# Пустой синоним стандартного реквизита

## Контекст

В XML стандартного реквизита пустой `Synonym` является значением по умолчанию. Сейчас общий договор `excludeIfEqualNameYAML` сохраняет явно пустой I8nText как `Синоним: ""`, потому что для обычных реквизитов отсутствие синонима означает восстановление текста из имени. Из-за этого импорт конфигурации создаёт в YAML избыточные значения по умолчанию.

## Договор

- XML → YAML не выводит `Синоним`, если синоним стандартного реквизита пуст.
- YAML со `Синоним: ""` у стандартного реквизита не проходит проверку как явно указанное значение по умолчанию.
- YAML без `Синоним` восстанавливает пустой `Synonym` при YAML → XML.
- Непустой синоним сохраняется, в том числе когда он совпадает с именем стандартного реквизита: его значением по умолчанию остаётся пустая строка.
- Поведение синонимов обычных реквизитов не меняется.

## Решение

В `StandardAttributeDescriptionRules.properties.synonym` пустая строка объявляется через существующий `implicitValueYAML`. `excludeIfEqualNameYAML` удаляется, потому что он описывает другой договор: неявный синоним, восстановленный из имени.

Общий построитель JSON-схемы начинает распознавать строковый `implicitValueYAML` у I8nText. Это не добавляет новый параметр правила: существующий договор распространяется на строковое YAML-представление I8nText и исключает пустую строку из допустимой схемы.

При импорте пустой I8nText без `excludeIfEqualNameYAML` уже преобразуется в отсутствие значения. При обратном преобразовании существующий `defaultValueXMLRaw: ""` восстанавливает пустой XML-тег, поэтому отдельная логика сериализации не нужна.

## Проверки

- Тест XML → YAML подтверждает, что пустой синоним стандартного реквизита не выводится, а остальные изменённые свойства сохраняются.
- Тест схемы/валидации подтверждает, что `Синоним: ""` запрещён именно для стандартного реквизита.
- Тест YAML → XML подтверждает восстановление пустого `Synonym` при отсутствии поля в YAML.
- Существующая проверка обычного реквизита продолжает подтверждать сохранение явно пустого синонима.
