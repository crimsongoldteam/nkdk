# Ускорение проверки имён элементов формы

## Цель

Убрать повторный полный обход дерева формы, сохранив глобальную в пределах одной формы проверку явных и зарезервированных single-имён без учёта регистра.

## Архитектура

Существующий `collectFormPendingChecks` остаётся единственным рекурсивным обходом элементов формы. Во время этого обхода он передаёт явные и вычисленные single-имена в отдельный сборщик, а после обхода сборщик группирует имена и формирует диагностики.

Сборщик отвечает только за нормализацию, поиск конфликтов и YAML-диагностики. Знание структуры `rules.ts`, разрешение типа элемента и рекурсия остаются в существующем обходе.

## Профилирование

Именованный подшаг `Проверка уникальности имён элементов формы` измеряет только завершение проверки собранных имён: группировку и формирование диагностик. Само обнаружение имён выполняется внутри общего обхода и отдельно не измеряется, поскольку дополнительное измерение каждого узла исказило бы результат.

## Ограничения

- Область уникальности — один `Форма.yaml`.
- Сравнение выполняется без учёта регистра.
- Single-имена резервируются даже при отсутствии блока в YAML.
- Вложенные отсутствующие single-элементы учитываются рекурсивно.
- TypeBox/Ajv остаются структурной проверкой JSON Schema.
- Поведение и расположение диагностик не меняются.
