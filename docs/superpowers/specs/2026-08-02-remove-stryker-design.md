# Удаление Stryker

## Цель

Полностью убрать mutation testing на Stryker из проекта. Причина — слишком
высокая длительность проверки по сравнению с её текущей пользой.

## Изменения

- удалить зависимости `@stryker-mutator/core` и
  `@stryker-mutator/vitest-runner` вместе с записями lock-файла;
- удалить команды `test:mutation` и `test:mutation:compare`;
- удалить `stryker.config.mjs`, запускатель mutation testing, сравнение отчётов
  и их тесты;
- удалить специальные переменные окружения и ветвления, нужные только Stryker,
  из конфигурации и обычных тестов;
- удалить требования запуска и описания mutation testing из
  `.agents/testing.md`.

## Что сохраняется

- обычные модульные, интеграционные, архитектурные и round-trip тесты;
- обязательные `pnpm type-check` и `pnpm test`;
- проверка появления новых дублей через `pnpm duplicates`;
- существующие XML-фикстуры без изменений.

## Проверка

После удаления выполняются `pnpm install --lockfile-only`, `pnpm type-check`,
`pnpm test` и `pnpm duplicates`. Поиск по репозиторию не должен находить
действующие команды, зависимости, конфигурацию или инструкции Stryker.
