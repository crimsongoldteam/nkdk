# JSON Schema для представления групп FilterItem

## Контекст

После свежего импорта `/home/nikita/git/round-trip/erp` в `/home/nikita/git/temp-yaml` и валидации осталось 26 ошибок `Expected union value`.
Первая группа содержит 20 ошибок на строках `ТипГруппы: ГруппаИ` и `ТипГруппы: ГруппаИли`.

Пример:

```yaml
Отбор:
  Элементы:
    - ТипГруппы: ГруппаИли
      Представление: '"ГруппаОрганизацияПредприятие"'
```

Сами значения `ТипГруппы` уже поддерживаются схемой: существующие тесты принимают группы с `ТипГруппы` и вложенными `Элементы`.
Ошибка возникает потому, что объект группы не проходит union целиком.
Фактическая причина — свойство `Представление` у группы.

## Наблюдение

`FilterItemGroupRules.presentation` и `FilterItemGroupRules.userSettingPresentation` имеют тип `FilterItemPresentationValue`.

В registry этот тип сейчас описан как `I8nTextYAML`, но фактический импорт и экспорт в `filterItem/typedValues.ts` используют `MetadataDcsMetadataValue` с `valueType: "DesignTimeValue"`.
Для такого значения строка вида `'"Мои отчеты"'` является допустимой YAML-формой.

Значит, YAML/XML-поведение уже умеет обрабатывать эти данные, а JSON Schema отстала от фактического контракта.

## Решение

Локально расширить JSON Schema для `FilterItemPresentationValue` внутри схемы `FilterItem`, не меняя YAML/XML-преобразования.

Для групп `FilterItemGroupRules` свойства:

- `Представление`
- `ПредставлениеПользовательскойНастройки`

должны валидироваться как `MetadataDcsMetadataValue` с `valueType: "DesignTimeValue"`.
Это разрешает короткую строковую форму и сохраняет поддержку объектной i18n-формы.

## Границы

Не менять:

- YAML, который генерирует импорт;
- XML round-trip;
- правила fromXML/toXML/fromYAML/toYAML;
- общий registry для `FilterItemPresentationValue`;
- схему `ТипГруппы`.

Изменение должно быть локальным для JSON Schema `FilterItem`, как уже сделано для массивного `ПравоеЗначение`.

## Проверки

Добавить тесты в `filterItem/toJSONSchema.test.ts`:

- группа с `ТипГруппы: ГруппаИли` и `Представление: '"..."'` принимается;
- группа с `Использование: Ложь`, вложенными `Элементы` и `Представление: '"..."'` принимается;
- существующие проверки групп, сравнений и неверных вложенных элементов остаются зелеными.

После реализации выполнить:

- точечный тест `filterItem/toJSONSchema.test.ts`;
- валидацию `/home/nikita/git/temp-yaml` и проверить, что группа ошибок `ТипГруппы: ГруппаИ/ГруппаИли` исчезла.
