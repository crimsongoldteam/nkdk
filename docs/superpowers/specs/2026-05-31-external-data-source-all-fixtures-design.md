# Замена sync-фикстур внешнего источника данных

## Цель

Заменить компактный набор `metadataExternalDataSource/__fixtures__/sync` на внешний источник данных из полного набора `all`:

- источник: `/home/nikita/git/round-trip/all/ExternalDataSources/ВнешнийИсточникДанныхВсеСвойства*`;
- назначение: `packages/core/metadata/appliedObjects/metadataExternalDataSource/__fixtures__/sync`;
- результат: точечные тесты внешнего источника данных проходят и воспроизводят реальные дочерние объекты из `all`.

## Границы

Заменяются только sync-фикстуры внешнего источника данных и тестовые ожидания, которые завязаны на эти фикстуры. `full.xml` и `minimal.xml` не меняются. XML из `all` считается источником истины.

Если после замены выявляется ошибка преобразования, исправляется минимальная причина, необходимая для прохождения тестов внешнего источника данных. Новые ручные правила `fromXML/toXML/fromYAML/toYAML` не добавляются без отдельного решения; предпочтение остаётся за существующими правилами и `rules.ts`.

## Подход

1. Полностью заменить `__fixtures__/sync/xml` деревом `ExternalDataSources/ВнешнийИсточникДанныхВсеСвойства` из `all`.
2. Обновить ожидаемый YAML для sync-набора на структуру, полученную из новых XML-фикстур.
3. Переписать проверки, которые сейчас ожидают старые имена `ТаблицаНоменклатура`, `Продажи`, `Номенклатура`, на имена из `all`: `ТаблицаВсеСвойства`, `ТаблицаПоУмолчанию`, `ТаблицаМодульНабора`, `КубВсеСвойства`, `КубПоУмолчанию` и дочерние объекты куба.
4. Сохранить проверку строковых reference-дочек: новый parent XML из `all` уже содержит строки в `ChildObjects`, поэтому отдельная искусственная копия нужна только если покрытие порядка mixed-структуры исчезнет.
5. Запустить точечные тесты `metadataExternalDataSource`; при необходимости исправить минимальный кодовый дефект, который мешает им пройти.

## Проверка

Минимальный критерий готовности:

- точечные тесты `metadataExternalDataSource` проходят;
- перенос не требует изменения существующих XML вне явно заменяемого sync-набора;
- если правится общий код metadata, поведение покрыто тестом на новой фикстуре.

Финальный критерий перед закрытием задачи: `pnpm test` из корня проходит.
