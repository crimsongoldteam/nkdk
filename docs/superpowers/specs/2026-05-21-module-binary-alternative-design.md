# Module Binary Alternative Design

## Контекст

`round-trip-yaml` показывает потерю `Ext/ObjectModule.bin` у нескольких обработок.
Текущий тип `Module` ожидает путь из `rules.ts`, обычно `*.bsl`, и не знает о зашифрованном
варианте `*.bin`.

Модули 1С могут быть представлены обычным исходным файлом `.bsl` или зашифрованным двоичным
файлом `.bin`. Это относится не только к модулю объекта, а к любому свойству типа `Module`.

## Решение

Поддержку `.bin` нужно добавить на уровне общего типа `Module`.

Правило модуля остается одним свойством, например `objectModule`.
Если в `rules.ts` указан путь `Ext/ObjectModule.bsl`, обработчик `Module` должен считать
альтернативным путем `Ext/ObjectModule.bin`.

Поведение:

- fromXML ищет оба варианта модуля;
- если найден только `.bsl`, он копируется в YAML как `МодульОбъекта.bsl`;
- если найден только `.bin`, он копируется в YAML как `МодульОбъекта.bin`;
- если найдены оба варианта, это ошибка;
- toXML восстанавливает тот вариант, который есть в YAML;
- если в YAML есть оба варианта, это ошибка.

Для функциональных путей дочерних модулей правило такое же: альтернативный `.bin` строится
заменой расширения `.bsl` на `.bin` после вычисления пути.

## YAML-Контракт

Имя YAML-файла сохраняет расширение фактического представления модуля.

Примеры:

- `МодульОбъекта.bsl` для обычного модуля;
- `МодульОбъекта.bin` для зашифрованного модуля;
- `Команды/<Команда>/МодульКоманды.bsl` или `Команды/<Команда>/МодульКоманды.bin` для дочерних модулей.

Одновременно хранить `.bsl` и `.bin` для одного модуля нельзя.

## Тестирование

Тесты общего `Module` должны покрыть:

- импорт `.bin` при отсутствии `.bsl`;
- экспорт `.bin` обратно в XML;
- ошибку при наличии `.bsl` и `.bin` на XML-стороне;
- ошибку при наличии `.bsl` и `.bin` на YAML-стороне.

Sync-фикстура прикладного объекта должна включить пример зашифрованного модуля `.bin`, чтобы
полный путь через объект тоже был закреплен.

## Вне Границ

Этот пункт не расшифровывает `.bin`, не преобразует его в `.bsl` и не меняет YAML-формат обычных
модулей. Файл `.bin` копируется как непрозрачный внешний файл.
