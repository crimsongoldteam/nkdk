`source-inventory.json` фиксирует пути, строки и SHA-256 всех 1051 TS-файлов common (636 исходников, остальные — тесты и TS-данные фикстур). `fixture-inventory.json` отдельно фиксирует XML и прочие файлы фикстур. Хеши предназначены для обнаружения изменений исходной базы; они не доказывают семантическую полноту обзора.

`registration-inventory.json` дополнительно фиксирует 577 буквальных регистраций/объявлений с 142 различными именами типов, операцией и строкой источника. Вычисляемые регистрации не выдаются за найденные этим поиском; они учитываются по register/fragments и в карточках.
