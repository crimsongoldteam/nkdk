# README MCP install section design

## Цель

Обновить раздел README о подключении NKDK для пользователей-агентов после перехода с CLI-поставки на MCP-сервер.

## Решение

Раздел `## Установка` заменяется на `## Подключение MCP-сервера`.

Новый раздел должен:

- не упоминать установку `@nakidka/cli`;
- не описывать NKDK как npm-пакет для пользователя;
- объяснять, что пользователь подключает локальный MCP-сервер из репозитория;
- дать минимальные шаги: клонировать репозиторий, выполнить `pnpm install`, указать агенту команду запуска;
- показать команду запуска `packages/mcp/bin/nkdk-mcp`;
- дать пример JSON-конфигурации агента с сервером `nkdk`;
- коротко перечислить доступные MCP tools первой версии.

## Пример содержания

~~~md
## Подключение MCP-сервера

NKDK подключается к агенту как локальный MCP-сервер.

```sh
git clone https://github.com/crimsongoldteam/nkdk.git
cd nkdk
pnpm install
```

Укажите агенту команду запуска:

```json
{
  "mcpServers": {
    "nkdk": {
      "command": "/path/to/nkdk/packages/mcp/bin/nkdk-mcp"
    }
  }
}
```

После подключения агенту доступны tools ...
~~~

## Не входит

- инструкции по установке `@nakidka/cli`;
- обещание опубликованного npm-пакета `@nakidka/mcp`;
- подробные инструкции для конкретного клиента, если они требуют нестабильного формата.

## Проверка

- `rg -n "@nakidka/cli|Установите CLI-пакет|pnpm add -D @nakidka/cli" README.md` не должен находить старый блок;
- README должен содержать `packages/mcp/bin/nkdk-mcp`;
- проверка форматирования через `git diff --check`.
