# Проверка единственного совпадения

Общее выражение `one` проверяет, что в коллекции ровно одна строка удовлетворяет
условию. Оно использует ту же форму, что `each` и `exists`:

```yaml
one:
  in: {field: rows}
  as: item
  where:
    and:
    - {present: {get: {of: {var: item}, field: name}}}
    - {eq: [{get: {of: {var: item}, field: name}}, {literal: Second}]}
```

Пустая коллекция, отсутствие совпадения и два или более совпадений дают `false`.
Ровно одно совпадение даёт `true` независимо от его положения среди соседних
строк. Условие связывается с типом элемента; неизвестная переменная, скаляр
вместо коллекции и небулево условие являются ошибками декларации при сборке.

Выражение не удаляет строки, не меняет их порядок и не выбирает первый из
дублей. Сгенерированный Rust использует общий механизм определения числа
совпадений: один проход без промежуточного списка, с остановкой после второго
совпадения. Данные записей остаются в исходном хранилище.

`one` — булево условие, а не самостоятельная регистрация аномалии. Оно может
входить в нормальный договор значения или ограничение; отклонения обрабатываются
существующим общим механизмом. Ложный результат сам по себе не даёт права
терять исходные записи или сохранять неизвестные нормальные правила через raw.

Это подключение проверки единственности к компилятору. Выделение значения
строки, распределение остатка и обратная сборка общей коллекции остаются
отдельными частями полного отношения `PropertyState`.
