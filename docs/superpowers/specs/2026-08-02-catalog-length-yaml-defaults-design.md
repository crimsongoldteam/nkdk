# YAML-defaults длины кода и наименования справочника

## Контекст

В `MetadataCatalogRules` сейчас расходятся XML- и YAML-defaults двух свойств:

| Свойство | YAML | XML | `defaultValueXML` | `implicitValueYAML` |
|---|---|---|---:|---:|
| `codeLength` | `ДлинаКода` | `Properties.CodeLength` | 9 | 10 |
| `descriptionLength` | `ДлинаНаименования` | `Properties.DescriptionLength` | 25 | 30 |

Значения `10` и `30` были добавлены коммитом `72c4b1a405` без указания
источника. Аудит текущих правил длины показал, что только эти два свойства
имеют разные литеральные `defaultValueXML` и `implicitValueYAML`.

Из-за расхождения полный round-trip `cf/doc` изменяет два справочника:

- `ОбработкиОбъектов`: исходный `CodeLength=10` исключается из YAML, после
  чего экспорт создаёт `CodeLength=9`;
- `УровниДоступа`: исходный `DescriptionLength=30` исключается из YAML, после
  чего экспорт создаёт `DescriptionLength=25`.

## Договор

Для справочника YAML-defaults должны совпадать с XML-defaults:

- `ДлинаКода`: `implicitValueYAML=9`;
- `ДлинаНаименования`: `implicitValueYAML=25`.

Значения `10`, `30` и любые другие значения, отличающиеся от defaults,
сохраняются в YAML явно и экспортируются без изменения. При отсутствии полей
в YAML экспорт создаёт `CodeLength=9` и `DescriptionLength=25`.

Configuration index и reference XML для восстановления этих значений не
используются: вся семантически значимая информация находится в YAML.

## Изменения

Изменяются только два `implicitValueYAML` в `MetadataCatalogRules` и
ожидания существующего контрактного теста defaults справочника. Общие типы
правил, `numberRule`, XML-фикстуры и правила других прикладных объектов не
изменяются.

## Тестирование

Следует расширить существующий тест наблюдаемого договора справочника:

1. XML `CodeLength=10` и `DescriptionLength=30` импортируется в явные
   `ДлинаКода: 10` и `ДлинаНаименования: 30`.
2. Эти явные YAML-значения экспортируются обратно без изменения.
3. При отсутствии обоих YAML-полей XML получает `CodeLength=9` и
   `DescriptionLength=25`.
4. Контрактный тест ожидает `implicitValueYAML=9` и `25`.
5. Выполняются целевые тесты, `pnpm type-check`, полный `pnpm test` и
   `pnpm duplicates`.

## Вне границ

- Проверка остальных числовых, логических и перечислимых defaults из коммита
  `72c4b1a405`.
- Изменение defaults длин других прикладных объектов.
- Изменение XML-фикстур.
