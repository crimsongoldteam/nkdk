# Пустые значения YAML без `{}`

## Цель

При экспорте XML в YAML не выводить пустые отображения `{}`. Пустой объект и
отсутствующее YAML-значение считаются одним состоянием и записываются без
лексического значения.

Примеры канонического вывода:

```yaml
Значения:
  МеждуОписаниямиЗатрат:
  МеждуСтатьямиРасходов:
```

Пустой корневой объект записывается как пустой файл. Пустой объект внутри
последовательности записывается как пустой элемент `-`.

## Договор данных

- Сериализация рекурсивно заменяет пустые объекты на `undefined`.
- `{}` и пустое значение намеренно не различаются после YAML round-trip.
- Явный `null`, пустая строка `""`, непустые объекты и массивы сохраняют прежний
  смысл.
- Текст, сформированный штатным сериализатором, не содержит `{}`.
- Чтение пустых значений должно оставаться допустимым во всех местах, где ранее
  допускался пустой объект.

## Реализация

Изменение выполняется в общем YAML-слое, а не в правилах отдельных объектов
метаданных. Подготовка данных для `js-yaml` рекурсивно распознаёт объект без
собственных перечислимых полей и передаёт его как отсутствующее значение.
Существующий механизм маркеров для `undefined` расширяется на значения,
полученные из пустых объектов, включая элементы массивов.

Если проверка схемы или обратное преобразование сейчас требует именно объект,
соответствующая общая граница принимает `undefined` как эквивалент пустого
объекта. Частные условия по типам метаданных не добавляются.

## Проверки

- Модульный тест сериализатора закрепляет корневой, вложенный и массивный случаи.
- Тест подтверждает сохранение различия с явным `null` и пустой строкой.
- Интеграционная проверка импорта перечисления закрепляет вывод пустых именованных
  элементов без `{}`.
- Обратное преобразование подтверждает, что пустые значения восстанавливают тот
  же XML, что ранее восстанавливался из `{}`.
- После целевых тестов выполняются `pnpm type-check`, `pnpm test` и проверка новых
  дублей относительно исходного коммита.

## Границы

XML-фикстуры и правила `rules.ts` не изменяются. Формат `null` и пустых строк не
меняется. Частные обходы для элемента стиля или перечисления не добавляются.
