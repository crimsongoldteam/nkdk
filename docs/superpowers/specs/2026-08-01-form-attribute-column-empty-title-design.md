# Пустой заголовок колонки реквизита формы

## Проблема

У колонки реквизита формы отсутствие XML-узла `Title` означает отсутствие заголовка. В YAML это состояние должно быть представлено явно как `Заголовок: ""`. Сейчас `FormAttributeColumnRules.title` содержит только `excludeIfEqualNameYAML`, поэтому при XML → YAML ключ пропадает, а при YAML → XML отсутствие ключа трактуется как заголовок, равный имени колонки. В результате round-trip добавляет отсутствовавший `Title`.

## Решение

Переиспользовать для `FormAttributeRules.title` и `FormAttributeColumnRules.title` одно локальное правило заголовка. Оно сохраняет существующий договор:

- отсутствующий `Title` в XML превращается в `Заголовок: ""`;
- `Title`, равный имени, исключается из YAML;
- `Заголовок: ""` не создаёт `Title` при экспорте в XML;
- отсутствующий `Заголовок` восстанавливает `Title` из имени.

Решение остаётся рядом с конкретным объектом формы и использует существующие параметры `defaultValue`, `skipEmptyToXML` и `excludeIfEqualNameYAML`. Общие типы правил и orchestration не изменяются.

## Проверка

Расширить существующий параметризованный тест XML → YAML для колонок реквизита формы случаем без `Title` и ожиданием `Заголовок: ""`. Усилить существующую проверку YAML → XML: пустой заголовок не создаёт `Title`, а отсутствующий ключ восстанавливает заголовок из имени. XML-фикстуры не изменять.

После точечных тестов выполнить `pnpm test` из корня проекта.

## Границы

Изменение касается только заголовков колонок реквизитов управляемой формы. Другие применения `excludeIfEqualNameYAML`, порядок XML-узлов и расхождения `Period`, `TopLevelParent`, `RowFilter` не входят в эту задачу.
