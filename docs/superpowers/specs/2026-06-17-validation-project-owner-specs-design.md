# Validation Project Owner Specs Design

## Контекст

После исправления прямых YAML-kind для `Обработка` и `ЖурналДокументов` из группы `Не найден владелец` остались 5 ошибок:

- `ОтчетОбъект.ОтчетыПоСотрудникам`
- `РегистрБухгалтерии.Международный`
- `РегистрБухгалтерии.МеждународныйБезКорреспонденции`
- `РегистрБухгалтерии.МСФО`
- `РегистрБухгалтерии.Хозрасчетный`

Причина отличается от предыдущей: `ownerCache` уже знает, что `ОтчетОбъект` живет в каталоге `Отчет`, а `РегистрБухгалтерии` - в каталоге `РегистрБухгалтерии`. Ошибка возникает дальше, потому что этих каталогов нет в `validationProjectSpecs`, и валидатор не умеет загрузить их `Свойства.yaml` как модель владельца.

## Решение

Добавляем в `validationProjectSpecs` только те корневые объекты, которые одновременно:

- уже есть в `KnownOwnerTypeKind` и `ownerDirByRefKind`;
- имеют готовые `Metadata*Rules`;
- могут быть владельцами `DataPath`-членов;
- не требуют исследования нового metadataItem с нуля.

В этот набор входят:

- `Отчет` -> `MetadataReportRules`
- `РегистрБухгалтерии` -> `MetadataAccountingRegisterRules`
- `РегистрРасчета` -> `MetadataCalculationRegisterRules`
- `ПланВидовРасчета` -> `MetadataChartOfCalculationTypesRules`
- `ПланВидовХарактеристик` -> `MetadataChartOfCharacteristicTypesRules`
- `БизнесПроцесс` -> `MetadataBusinessProcessRules`
- `Задача` -> `MetadataTaskRules`

Не подключаем все остальные YAML-каталоги проекта в этой задаче. Это расширило бы общий обход валидации и могло бы открыть большой несвязанный набор схемных сообщений.

## Проверка

Unit-тесты должны зафиксировать, что для каждого нового каталога есть `ValidationProjectSpec` и что `ownerCache` может загрузить `Свойства.yaml` через соответствующий тип владельца.

На реальном YAML-проекте `/home/nikita/git/temp-yaml` ожидаемый результат: текущие 5 ошибок `Не найден владелец` для `ОтчетОбъект` и `РегистрБухгалтерии` исчезают. Если после расширения обхода появятся новые ошибки схемы внутри этих файлов, они считаются отдельной диагностикой, а не провалом исправления поиска владельца.
