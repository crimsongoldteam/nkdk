# XML-default вида флажка

## Проблема

Импорт формы исключает `CheckBoxType=Auto` из YAML как
`implicitValueYAML`. При последующей синхронизации без reference значение не
восстанавливается, поэтому из XML исчезает `<CheckBoxType>Auto</CheckBoxType>`.

Исходный каталог задаёт однозначное условие:

- у обычного флажка `CheckBoxType=Auto` присутствует;
- у флажка с `ThreeState=true` `CheckBoxType` отсутствует.

Условие выполняется для всех 2 033 исследованных `CheckBoxField`: 1 963
обычных флажка содержат `Auto`, 34 трёхсостояния не содержат `CheckBoxType`,
остальные 36 явно задают другой вид.

## Решение

Общее правило `checkBoxType` для `CheckBoxField` и `TableCheckBoxField` получает
`defaultValueXML: "Auto"`. Условие `toXML` разрешает экспорт свойства, только
если соседнее YAML-свойство `threeState` не равно `true`.

Таким образом:

- отсутствующий в YAML вид обычного флажка превращается в
  `<CheckBoxType>Auto</CheckBoxType>`;
- при `ТриСостояния: true` тег `CheckBoxType` не создаётся;
- явно заданный вид флажка продолжает экспортироваться без изменений.

Решение остаётся рядом с конкретным объектом формы и не добавляет знаний о
флажках в общую orchestration. Reference и снимок конфигурации не используются.

## Отклонённые варианты

- Безусловный `defaultValueXML` неверен: он добавит `CheckBoxType` для
  трёхсостояния.
- Сохранение присутствия тега в снимке нарушит принятое правило восстановления
  известных defaults из `rules.ts`.
- Отдельные варианты правил для обычного и трёхсостояния избыточны: различие
  выражается одним локальным условием свойства.

## Проверка

Существующая проверка YAML → XML расширяется двумя границами общего договора:

- обычный `CheckBoxField` без `ВидФлажка` получает `CheckBoxType=Auto`;
- `CheckBoxField` с `ТриСостояния: true` не получает `CheckBoxType`.

Те же общие правила используются `TableCheckBoxField`, поэтому отдельный тест
нужен только при наличии отличающегося пути экспорта. После изменения
выполняются целевые тесты, mutation testing для изменённого production-файла,
`pnpm type-check` и `pnpm test`.
