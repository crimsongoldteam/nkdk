# Восстановление исключённого равного имени синонима через rules.ts

## Контекст

Свойство `excludeIfEqualNameYAML` исключает из YAML язык по умолчанию у
`I8nText` и `FormattedI8nText`, когда текст после нормализации совпадает с
именем объекта. После удаления `excludedEqualName` из снимка конфигурации 1.3
обратное преобразование перестало восстанавливать такое значение. В результате
XML → YAML → XML заменяет заполненный `<Synonym>` на `<Synonym/>`.

`excludedEqualName` не должен возвращаться в снимок: факт исключения полностью
определяется декларативным правилом и отсутствием соответствующего значения в
YAML.

## Целевой договор

`excludeIfEqualNameYAML: true` является симметричным договором:

- XML-текст языка по умолчанию, равный имени после нормализации, исключается из
  YAML;
- отсутствие YAML-значения восстанавливает язык по умолчанию из имени;
- переводы других языков сохраняются в YAML и при обратном преобразовании
  дополняются восстановленным языком по умолчанию;
- пустой XML-текст не равен имени и сохраняется в YAML явно;
- явное пустое YAML-значение восстанавливает пустой XML-узел.

Снимок конфигурации не участвует в принятии решения и не получает новых полей.

## Преобразование XML → YAML

Для `I8nText` пустое значение при `excludeIfEqualNameYAML: true` представляется
строкой `""`, даже если `preserveEmptyXML` не задан отдельно. Это необходимо,
чтобы отсутствие поля оставалось однозначным обозначением вычисляемого
синонима.

Общая оркестрация различает отсутствующий и присутствующий пустой XML-узел,
поэтому зарегистрированное поведение property-типа предоставляет нейтральный
переход от явно пустого XML к пустой модели. Оркестрация вызывает его только
при `presentInXML: true`; частных проверок `I8nText`, `FormattedI8nText` или
конкретных свойств в общем слое нет.

Для `FormattedI8nText` применяется тот же договор внутри поля `Текст`:

```yaml
Заголовок:
  Текст: ""
```

Флаг `Форматированный` сохраняется независимо от текста.

## Преобразование YAML → XML

Общая оркестрация передаёт `restoreExcludedEqualName: true`, когда одновременно
выполнены условия:

- правило содержит `excludeIfEqualNameYAML: true`;
- соответствующее значение отсутствует в YAML;
- известно имя объекта или элемента.

Проверка снимка конфигурации не выполняется.

`I8nText` восстанавливает язык по умолчанию функцией
`addDefaultLanguageNameToSynonym`. Явная пустая строка при этом преобразуется в
пустую модель `items: {}`, а не в перевод с пустым содержимым.

`FormattedI8nText` передаёт имя и признак восстановления во вложенное
преобразование `I8nText`, сохраняя признак форматирования.

## Границы изменения

- Формат `configuration-index.bin` 1.3 и его логическая модель не меняются.
- Новые частные условия по `itemType`, XML-корням и путям не добавляются.
- Представление явно пустого XML задаётся регистрацией property-типа, а не
  условием по имени типа в общей оркестрации.
- XML-фикстуры не изменяются.
- Существующий смысл `preserveEmptyXML` для правил без
  `excludeIfEqualNameYAML` остаётся прежним.
- Валидация продолжает запрещать явный текст, равный имени, поскольку такой
  текст должен быть исключён из YAML.

## Проверка

Модульные тесты должны подтвердить:

- восстановление отсутствующего `I8nText` из имени без снимка;
- сохранение переводов других языков;
- явный пустой `I8nText` в YAML и обратное получение пустого XML;
- то же поведение для `FormattedI8nText`;
- отсутствие `excludedEqualName` в собранном фрагменте снимка.

Интеграционная проверка выполняется повторным YAML round-trip каталога
`/Users/nikita/git/round-trip/cf/doc`. Группа расхождений, где заполненный
`<Synonym>` заменялся на `<Synonym/>`, должна исчезнуть; оставшиеся расхождения
анализируются отдельно.

Перед завершением выполняется полный `pnpm test` из корня worktree.
