# JSON Schema для nil-элементов массива ПравоеЗначение FilterItem

## Контекст

После исправления схемы `FilterItemPresentationValue` во свежей валидации `/home/nikita/git/temp-yaml` осталось 4 ошибки `Expected union value`.
Две из них относятся к DCS filter item с `ВидСравнения: ВСписке` и массивным `ПравоеЗначение`, где один элемент записан как пустой объект.

Примеры:

```yaml
- ЛевоеЗначение: .Тип
  ВидСравнения: ВСписке
  ПравоеЗначение:
    - {}
    - {}
```

```yaml
- ЛевоеЗначение: .Объект.Корректировки.Документ
  ВидСравнения: ВСписке
  ПравоеЗначение:
    - Документ.ВыбытиеИнвестиций.ПустаяСсылка
    - Документ.ПоступлениеИнвестиций.ПустаяСсылка
    - {}
```

## Наблюдение

`DcsMetadataTypedValue` уже поддерживает такую YAML-семантику при импорте:
пустой объект `{}` внутри массива трактуется как nil-элемент и восстанавливается в модели как `undefined`.

Текущее исправление для массивного `ПравоеЗначение` разрешило массив значений, но схема элементов массива использует только `DcsMetadataTypedValueJSONSchema`.
Эта схема не включает пустой объект, поэтому валидатор отклоняет уже поддержанный YAML.

## Решение

Локально расширить только JSON Schema для `FilterItemComparison.ПравоеЗначение`.

Массивная форма `ПравоеЗначение` должна принимать элементы двух видов:

- обычное `DcsMetadataTypedValueJSONSchema`;
- пустой объект `{}` как nil-элемент массива.

Одиночное `ПравоеЗначение` остается прежним и не принимает `{}`.
`ЛевоеЗначение` остается прежним и не принимает ни массив, ни `{}`.

## Границы

Не менять:

- YAML/XML-преобразование;
- общий `DcsMetadataTypedValueJSONSchema`;
- `FilterItemComparisonRules`;
- поведение `ЛевоеЗначение`;
- поведение одиночного `ПравоеЗначение`.

Изменение должно остаться локальным для JSON Schema `FilterItem`.

## Проверки

Добавить тесты в `filterItem/toJSONSchema.test.ts`:

- `ПравоеЗначение` принимает массив из строк и `{}`;
- `ПравоеЗначение` принимает массив только из `{}`;
- одиночное `ПравоеЗначение: {}` не принимается;
- `ЛевоеЗначение: {}` не принимается.

После реализации выполнить:

- точечный тест `filterItem/toJSONSchema.test.ts`;
- валидацию `/home/nikita/git/temp-yaml` и проверить, что две ошибки DCS filter item исчезли из группы `Expected union value`.
