# Результат оптимизации setup тестов core

## Изменение

Статические импорты полного metadata-графа удалены из `tests/registerCoreMetadata.ts`. Test-only функция `ensureCoreMetadataRegistered()` хранит в `globalThis` один Promise модуля и динамически загружает `metadata/composition/coreMetadata` один раз на общее окружение Vitest. После ожидания каждый setup-вызов вызывает идемпотентный `registerCoreMetadata()`, как и прежний setup. Production-композиция не менялась.

Поведенческий тест закрепляет два договора: повторные и параллельные setup-вызовы выполняют загрузку один раз и запрашивают регистрацию при каждом вызове; отклонённый Promise загрузки сохраняется и возвращает ту же исходную ошибку без повторного импорта.

## Три core-прогона

Все прогоны выполнены с `--no-isolate --sequence.shuffle`. В каждом запуске прошли 713 test files и 6176 tests. Точные lifecycle-значения получены повторным запуском тех же seed с тем же lifecycle reporter.

Штатный `run-test-duration-check.mjs` завершился кодом 0 на всех трёх seed. Пределы 3 с для setup и 1 с для test file соблюдены во всех запусках.

До изменения три последовательных прогона занимали 42,92–44,83 с, а setup — 6,46–7,02 с. После изменения диапазоны сократились до 16,67–17,81 с и 2,15–2,22 с соответственно.

## Покрытие договоров

Предметные проверки и XML-фикстуры не менялись. Полная metadata-композиция по-прежнему регистрируется до выполнения тестов; существующий тест композиции подтверждает доступность правил `I8nText` и `ClientApplicationForm`.

Два unit-теста прямого преобразования получили явные test-only импорты владельцев используемых реестров. До этого GanttChartFieldTable и FormAttribute проходили в полном наборе только при удачном порядке импорта других файлов; теперь оба файла проходят изолированно.

Два исследовательских теста изоляции удалены вместе с отвергнутым подходом разделения metadata-тестов на дополнительные проекты. Их удаление не сокращает предметное покрытие: они проверяли только экспериментальную конфигурацию Vitest, которая не вошла в итоговое решение.
