# Результат оптимизации setup тестов core

## Изменение

Статические импорты полного metadata-графа удалены из `tests/registerCoreMetadata.ts`. Test-only функция `ensureCoreMetadataRegistered()` хранит в `globalThis` один `Promise<void>`, динамически загружает `metadata/composition/coreMetadata` и выполняет полную регистрацию один раз на общее окружение Vitest. Production-композиция и `registerCoreMetadata()` не менялись.

Поведенческий тест закрепляет два договора: повторные и параллельные setup-вызовы выполняют загрузку и регистрацию один раз; отклонённый Promise сохраняется и возвращает ту же исходную ошибку без повторной регистрации.

## Три core-прогона

Все прогоны выполнены с `--no-isolate --sequence.shuffle`. В каждом запуске прошли 713 test files и 6176 tests. Точные lifecycle-значения получены повторным запуском тех же seed с тем же lifecycle reporter.

| Seed | Test files | Tests | Setup | Общая длительность Vitest | Максимальный test file |
| --- | ---: | ---: | ---: | ---: | --- |
| `20260730` | 713 | 6176 | 2,26 с | 17,17 с | `dynamicList/fromXMLToYAML.test.ts` — 823,64 мс |
| `20260731` | 713 | 6176 | 2,15 с | 16,43 с | `dynamicList/fromXMLToYAML.test.ts` — 827,31 мс |
| `20260810` | 713 | 6176 | 2,20 с | 16,65 с | `dynamicList/fromXMLToYAML.test.ts` — 833,99 мс |

Штатный `run-test-duration-check.mjs` отдельно завершился кодом 0 на всех трёх seed. Его длительность составила 17,42–17,58 с, setup — 2,30–2,46 с. Пределы 3 с для setup и 1 с для test file соблюдены во всех запусках.

До изменения три последовательных прогона занимали 42,92–44,83 с, а setup — 6,46–7,02 с. После изменения диапазоны сократились до 16,43–17,17 с и 2,15–2,26 с соответственно.

## Покрытие договоров

Предметные тесты и XML-фикстуры не менялись. Полная metadata-композиция по-прежнему регистрируется до выполнения тестов; существующий тест композиции подтверждает доступность правил `I8nText` и `ClientApplicationForm`.

Два исследовательских теста изоляции удалены вместе с отвергнутым подходом разделения metadata-тестов на дополнительные проекты. Их удаление не сокращает предметное покрытие: они проверяли только экспериментальную конфигурацию Vitest, которая не вошла в итоговое решение.
