# UserVisible: общий XML-элемент с атрибутом и текстом

В Rust-компиляторе разрешена декларативная запись, у которой атрибут и
скалярный текст лежат в одном XML-элементе. Чтение теперь открывает текстовое
поле при начале такого элемента, а запись использует уже открытый элемент с
атрибутом. Поддержка ограничена одним скалярным полем без добавочных
атрибутов; она не содержит условий по имени объекта или XML-тега.

Проверочная декларация `common.user-visible` описывает `xr:Common` и список
`xr:Value name="..."`; соответствия полного имени роли и ключа YAML передаются
таблицей на входе. Три существующих XML-образца `UserVisible` проверены в
обоих направлениях без XML-референса: одна роль, две роли и запрет без ролей.
Обычные образцы не требуют `!xml/raw`. Дополнительно для
`ChildSubsystemNames` проверены пустые XML-элементы, в том числе среди
непустых соседей: порядок и число позиций сохраняются без тега.

Флажок `UserVisible` не устанавливается. До подключения ко всем элементам
форм нужны: источник таблицы ролей из индекса конфигурации, проверка
существования роли и договор для редких пустых оболочек и пустого `xr:Value`.
Сейчас эти формы приводят к автоматически выведенному `!xml/raw`; новое
применение этого тега не включено в рабочие объекты. Кандидаты `rules.ts`
для `UserVisible` пока не выпускаются.
