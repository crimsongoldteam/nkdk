# DynamicList: все сохраняемые свойства в одном договоре

Исходный `DynamicListRules` автоматически собран целиком как локальное
значение:21 сохраняемое свойство. `settingsComposer` исключён по исходному
`runtimeOnly`, а `currentUserSettingsKey` остаётся только в YAML.
Три зарегистрированные коллекции переиспользуют готовые common-записи.
Предметных обработчиков Rust и новых возможностей языка не добавлено.

Общий сборщик sourceProjection теперь возвращает также зависимости,
которые переносчик создал при обработке выбранных свойств. Раньше они
оставались только в переданном изменяемом каталоге, и независимая публикация
теряла коллекцию параметров данных. Зависимости возвращаются без изменения
пространства имён: размещение внутри Form применяется к владельцу, не к
общей библиотеке. Отдельное воспроизведение ошибки RED→GREEN защищает этот
договор через проверку полноты графа зависимостей в существующей матрице.
Сборщик работает с локальной копией каталога: повторные независимые вызовы
не изменяют входной набор и каждый возвращает свои создаваемые зависимости.
Проверка этой повторяемости также прошла RED→GREEN.

Приняты три нативных примера с одним и тем же преобразователем:

- Полный `ПроизвольныйЗапрос` из настоящей формы, включая таблицу,
 10 полей, вычисляемое поле,7 параметров, QueryText и ListSettings целиком.
- `ПроизвольныйЗапросМинимум` из той же формы; ожидания взяты из его собственного
 YAML, включая присутствующие поля, основную таблицу и отдельный запрос.
- Полный список с неверным булевым значением параметра: аномалия сохранена,
 смысловые ключи соседних свойств и восстановление всего XML проверены.

XML-источник: e2e/fixtures/xml/cf/CommonForms/ДинамическийСписок/Ext/Form.xml.
Независимые смысловые ключи: e2e/fixtures/nkdk/cf/ОбщаяФорма/ДинамическийСписок/Свойства.yaml.
Текст запросов: существующие .query в соседнем ДинамическийСписок/.
Фикстуры не менялись. Совместная проверка не дублирует подробные матрицы
common: здесь проверяются подключения, ключи, внешний файл, валидация и
точное восстановление XML. Числа и значения внутри common защищены их
ранее принятыми независимыми примерами.

Публикация содержит15 локальных деклараций и43 случая семейства.
Новые3 нативных сценария прошли; остальные40 не являются новым результатом
этого запуска и сохраняют предыдущую отдельную приёмку.
Переносчик272/272, архитектура rules66/66, граф границ/циклов, Rust3/3
и поиск новых дублей прошли. Повторная публикация воспроизводима.

Адресный каталог включает218 деклараций и2641 подготовленный пакет.
Первая dev-сборка заняла7м25с; уже собранный запускатель проверил три новых
примера без повторной сборки. Наблюдались примерно0,7ГиБ генератора и0,16ГиБ
отдельного rustc; это отдельные наблюдения, не измеренный общий пик.
При нехватке места удалена часть устаревшего AOT-кеша с инвалидированием
его fingerprints; все зависимости текущего layout сохранены. Скорость
преобразования новым замером этого блока не измерялась; код Rust не менялся.

Граница приёмки: локальное значение готово к дальнейшему подключению.
Все восемь исходных требований `configurationIndexAddressing: yamlPath`
сохранены: calculatedFields, conditionalAppearance, dataParameters, fields,
filter, group, order и parameters. Ранее явный отчёт содержал только три
зарегистрированные коллекции, а пять подготовленных common-профилей
учитывали параметр лишь как эквивалентность. Общий сборщик проверочного
профиля теперь сохраняет также эти исходные обязанности; проверка потери
пяти требований прошла RED→GREEN. Профиль откладывает их, не исполняет.
Поэтому полную проектную операцию и
полный DynamicList здесь не отмечаем завершёнными. Следующий шаг — передать
полное значение владельцу и реализовать эти общие обязанности по исходным
регистрациям; подмена их строками или аномалиями недопустима.
