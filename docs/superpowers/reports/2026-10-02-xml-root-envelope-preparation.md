# XMLRoot: постоянная специализация и оболочки файлов

Общая подготовка `sourceRootEnvelope` получает из исходного XMLRoot путь,
пространства имён и атрибуты. Проверены все 62 применения существующего
извлечения, включая восемь корней отдельных файлов и два вычисляемых случая.
Отсутствующий, повторный или неверный договор явно отклоняется переносчиком.

Вычисляемые атрибуты PredefinedRules и ChartOfAccountsPredefinedRules
поддержаны общим ограниченным анализатором. Он проверяет исходный хеш,
положение и текст функции, затем специализирует её на постоянном контексте.
Исходный JavaScript не исполняется. В существующий анализатор добавлены
общие короткие &&/||; неизвестные функции и неподдержанный синтаксис
остаются ограничениями переноса. JSON-представление контекста проверяется
на отсутствие потерь, включая undefined, NaN и отрицательный ноль.

Четыре типа предопределённых данных дают существующие xsi:type;
неизвестный тип использует запасной вариант исходной функции. Отдельной
таблицы этих типов в компиляторе или оркестраторе Rust нет. Сборка
InputByString использует общую подготовку; генерация --check подтверждает
неизменённый результат существующих рабочих деклараций.

Сверка с десятью неизменёнными e2e XML-файлами проверяет путь оболочки,
URI пространства имён и атрибуты: документ, четыре предопределённых файла,
индексы, интерфейс, агрегаты, состав плана обмена и интерфейс главного раздела.
Это сверка подготовки оболочки, а не новый полный round-trip её содержимого.

Новые договоры прошли цикл ошибочная проверка → реализация → успешная
проверка. Итоговая затронутая матрица содержит девять тестов, в том числе
один общий набор реальных файлов. Проверки архитектуры и новых дублей прошли.
Полный `pnpm test` окончательной версии завершился с кодом 0.
Предупреждения о целевых 10 мс не считаются подтверждением скорости;
замеры 10× в этой работе не проводились.

XMLRoot остаётся без флажка. Для полной приёмки требуется включение оболочки
в рабочее преобразование отдельных файлов и проверка восстановления исходной
формы с неизвестными атрибутами и пространствами имён. Готовность полного
владельца учитывается отдельно. Сводка принятых common остаётся 56/90.
