# Приёмка OrderItemFields

`OrderItemFields` описан одной YAML-декларацией каталога: обычное поле порядка и `[Авто]` различаются по `xsi:type`, а последовательность сохраняет порядок и повторы. Поля `Использование`, `Поле`, `ТипУпорядочивания` и `РежимОтображения` используют общие типы и перечисления. Специального обработчика Rust для этого объекта нет.

Проверка `migration.dcs-order-item-fields` выполняет XML → YAML → XML без исходного XML-референса на прежней фикстуре с двумя элементами и трёх элементах реальной e2e-формы `ДинамическийСписок`. Она также проверяет `[Авто]`, экспорт новой YAML-коллекции, отсутствие свойства и сохранение неверного типа либо направления сортировки общей аномалией. Все три проверки пакета `nkdk-probe-dcs-lists`, Clippy, полный `pnpm test`, архитектурные проверки и поиск новых дублей прошли.

Принят самостоятельный common-объект. Полный `Order` и владельцы СКД остаются отдельными пунктами чеклиста.
