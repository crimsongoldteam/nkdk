# Приёмка DcsLocalStringType

`common.dcs-local-string-type` описан одной YAML-декларацией выбора между `xs:string` и `v8:LocalStringType`; локализованная ветвь повторно использует `common.i8n-text`. YAML-скаляр с `!xml/string` выбирает XML-строку, обычный скаляр и словарь языков — локализованную ветвь. Выбор и схема выводятся из декларации; отдельного обработчика `DcsLocalStringType` в Rust нет.

Проверены реальные `presentation` и `title` из e2e XML, оба направления без XML-референса, одно- и многоязычный ввод, отсутствие дублирования `v8:item`, XML без `xsi:type`, пустой элемент и неизвестный `xsi:type`. Аномальные формы автоматически получают `!xml/raw` и восстанавливаются. Для этого общий механизм XML-правок сопоставляет полные XML-имена атрибутов и при явной замене текста удаляет дочерние узлы прежней формы.

Проверки: 33 сценария пробных скаляров, 6 проверок XML-правок, 75 проверок связывания деклараций, 21 проверка схем, Clippy без предупреждений, `pnpm duplicates -- --base 2af2f299ed8241eac78d4db46b4a8421efe2f8f7` без новых дублей, обе архитектурные проверки и полный `pnpm test` прошли. Полные владельцы `CalculatedField` и DCS отмечаются отдельно.
