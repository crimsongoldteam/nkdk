# Повторное использование записей СКД

`common.dcs-parameter` опубликован из всех 12 свойств элемента прежней
регистрации DCSParameters. Подготовка имени выполняется существующим общим
механизмом ключевого поля: XML `name` восстанавливается из ключа YAML-словаря.
При публикации этот договор не подменяется постоянным значением или
потерей имени. Коллекция ссылается на общую запись.

Та же граница повторного использования установлена для CalculatedField и
DataCompositionSchemaDataSetField: коллекции ссылаются на опубликованные
common-библиотеки. Прежние внутренние полные записи удалены из графа
проверочного семейства. Пути элементов и YAML-имя коллекции остаются у
владельца, правила значений — в общей записи. Общие функции работы с
идентификаторами используются также публикацией рабочих семейств.

Имена common встречаются только в сборке конкретного семейства и данных
сопоставления. Rust-компилятор и исполняющий движок не изменены. Это
самопроверка универсальности, не независимое ревью.

## Проверки и границы

Прошли 14/14 договоров параметров, 6/6 вычисляемых полей и 13/13 полей
набора данных через общие AOT-пакеты. Прошли 90 проверок переноса/публикации,
30 проверок схем, архитектура правил/TypeScript/Rust и проверка новых дублей
относительно `91a01277cbd10ccebd70bb0b4e7a32886dcf090f`. Все шесть проверок
актуальности публикаций прошли. Используются прежние XML/YAML
ожидания: все разновидности параметров, две коллекции формы, полный список,
повторы и соседние элементы, пустые состояния и локальные аномалии. Новых
XML-фикстур и отдельных тестов для каждого свойства нет.

Полный DynamicList и XML-схема СКД не принимаются этим подключением.
В DynamicList отдельно остаются ссылка на основную таблицу, внешний текст
запроса и согласование сохраняемых только в YAML/исполнении свойств.
Корневой флажок СКД остаётся пустым; принятые вложенные части не откатываются.
Размер создаваемого Rust в пакете проверяется против 16 МиБ; это не измерение
потребления памяти или доказательство цели 10×.


Полный `pnpm test` в заключительном запуске завершился с кодом 0 без
параллельных Rust-сборок. Два первых запуска функционально прошли, но
ограничитель времени остановил их на разных прежних тестах: MCP 72,94 мс
при лимите 60 мс и подготовка фактов 220,62 мс при лимите 200 мс. Оба файла
отдельно прошли неизменные ограничители, затем прошёл полный запуск. Лимиты,
тесты и baseline не изменялись; мягкие предупреждения 10 мс и настроенные
пропуски сохранены. Изолированный MCP-тест занял 16,54 мс.

Размер Rust в отдельном пакете максимум 2 293 497 байт при пределе 16 МиБ.
Каталоги содержат 748/415/635 пакетов с общими входными пакетами соответственно.
Удаление внутренних дублирующих записей из графа не выдаётся за уменьшение
общего размера генерируемого кода, ускорение выполнения или замер RSS.
Исходные XML имеют пустой git diff.
