# XMLRoot: вычисляемые атрибуты и сохранение QName

## Что проверяется

При постоянном контексте владельца одна исходная регистрация PredefinedRules
даёт четыре оболочки: CatalogPredefinedItems, ChartOfAccountsPredefinedItems,
PlanOfCharacteristicKindPredefinedItems и CalculationTypePredefinedItems.
Переносчик специализирует исходное выражение при подготовке декларации;
Rust не выбирает тип по имени объекта при выполнении.

Подготовка оболочек сверяется с неизменными заголовками существующих XML.
Матрица компилятора отдельно проверяет общий договор QName-оболочки на
нейтральной коллекции. Это проверка механизма, а не полное преобразование
содержимого четырёх файлов Predefined.xml. Их самостоятельная приёмка остаётся
в плане; XMLRoot пока без флажка, принято 56 из 90 common.

## Исправления

1. Префиксы пространств имён связываются по URI. Если исходный префикс занят
   другим URI в декларации тела, используется существующий синоним либо
   свободный префикс. Пространства тела не перезаписываются.
2. При сохранении отклонения оболочки коллекции QName-текст захватывается как
   пара URI/имя, а не как текст с прежним префиксом. Исходный XML восстанавливается
   при смене префиксов. Все три захвата — исходного XML, обычного экспорта и
   основы для применения сохранённого отличия — используют один предикат,
   выведенный из декларации.
3. Неверный постоянный атрибут оболочки не должен уничтожать корректное
   смысловое содержимое коллекции. После ошибки атрибута повторно читается
   тело без атрибутов оболочки; допустимый xsi:nil учитывается по договору
   присутствия. Конечная проверка восстановления сохраняет отличия оболочки.
   Ошибки смысловых значений не скрываются этой повторной попыткой.
4. Генератор внешних оболочек создаёт новые выходные YAML. Проверка --check
   ничего не записывает; все выходные записи проверяются до первой записи.
   Повторный путь и отсутствующий выход отклоняются без изменения первого файла.
   Это не обещание атомарности нескольких файлов при сбое диска.
5. Выбор доступных Rust-записей остаётся статическим matches!: последовательные
   номера записываются диапазоном. Исправляется обнаруженное Clippy нарушение
   manual_range_patterns без отключения проверки и без линейного поиска.

## Защищённые различия

В существующей матрице QName добавлена оболочка с типом и версией. Проверены
нормальное значение с другими префиксами, неверный и отсутствующий тип,
неверная и отсутствующая версия, дополнительный атрибут. Сохраняются оба
читаемых значения коллекции; каждое отклонение проходит строгую проверку
XML → YAML → XML без референса. Отдельно проверен экспорт обычного YAML.
Матрицы не размножаются для каждого объекта, существующие проверки не удалены.

Обычный маршрут не получает дополнительного прохода по XML. Повторное чтение
тела выполняется после ошибки атрибутов; сохранение QName используется на
пути восстановления отклонений. Ускорение и цель 10× этим блоком не доказаны.

## Итоговая проверка

- Подготовка и привязка оболочек: 15 проверок; обе вычисляемые регистрации
  PredefinedRules и ChartOfAccountsPredefinedRules проверены.
- Полный набор проверок переносчика: 209 проверок.
- Компилятор: 16 внутренних проверок, 3 проверки матрицы коллекций и 4 QName;
  матрица коллекций также компилирует результат и запускает Clippy без предупреждений.
- Реальные common-коллекции: 26 проверок; сборка пакета заняла 41,02 с.
- Clippy компилятора, проверка типов, три архитектурные проверки и полный
  pnpm test завершились с кодом 0. Полный pnpm выполнялся после Rust-сборок.
- Новых дублей относительно 2af2f299ed8241eac78d4db46b4a8421efe2f8f7 нет;
  формат Rust и git diff --check прошли. XML-фикстуры не изменены.
- Рабочие генераторы AdditionalIndexes и журнала --check не изменили декларации.

В машинном поиске дублей охвачен Rust согласно текущему договору проекта.

не завышаются. Не запускалась широкая сборка всего кандидатного каталога.
