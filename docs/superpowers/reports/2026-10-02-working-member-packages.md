# Рабочие пакеты источников реквизитов

Все 24 источника восьми семейств — обычные, местные и наследуемые —
экспортируются через рабочий `nkdk-compiled-rules`. Полные преобразователи
владельцев остаются отдельно. Состав источников выводится из графа переноса.

Генератор хранит зависимости один раз в
`common/input-by-string-member-views.generated.yaml`, а источники — в
`objects/input-by-string-members-{0,1}.generated.yaml`. Прежний кандидатный
каталог больше не содержит этих деклараций. Идентификаторы сохранены;
проверяются полнота зависимостей и отсутствие повторных деклараций.

Один каталог создавал 9 694 989 байт Rust-кода и был остановлен ограничителем
8 МиБ. Бюджет не повышен: два независимых пакета создают около 4,7 МиБ каждый.
Основной пакет сохраняет бюджет 32 МиБ. Разделение определяется устойчивым
порядком идентификаторов; Rust не выбирает обработчики по имени объекта.
Рабочая граница проверяет сигнатуры всех четырёх пакетов и единственность
регистраций. Сборка выполняется с `-j 1`.

Цена разделения — два отдельных пакета и дополнительный выбор пакета на
границе операции. Конвертер выполняет готовые Rust-функции. Пик памяти и
скорость выполнения не измерены; цель 10× не подтверждена.

Проверка генератора сначала падала без рабочего раздела источников, затем
прошла. Вместе с генератором реквизитов документа прошли 8 проверок.
Независимая проверка приложения подтверждает регистрацию всех 24 источников,
изменение пригодности реквизита при замене строки ссылкой, перекрытие и
удаление местного реквизита расширения и пометку `!проверять`. Используются
рабочие пакеты и обычная подготовка фактов, без кандидатного запускателя.

Прошли 50 тестов приложения, Clippy приложения, рабочей границы и новых
пакетов, архитектурные проверки и поиск дублей. Полный `pnpm test` также прошёл
с кодом завершения 0.
Фикстуры не изменены. Самопроверка универсальности выполнена; это не
независимое ревью.

Автоматическая привязка к сохранённой идентичности владельца и полные
маршруты источников восьми семейств ещё не завершены. Флажок
`InputByStringFields` остаётся снят. Следующая приёмка должна использовать
изменённый первичный YAML через проектную операцию, сохраняя прежние
сведения о владельце.

Дополнительно устранена зависимость пути сохранённых сведений от полного
преобразователя. Маршрут первичного источника фактов позволяет читать и
публиковать прежний источник самостоятельно. Имя владельца определяется
общей функцией для полных маршрутов и источников; отдельного обработчика для
реквизитов нет. Компонент ограничивается `only`, неизвестное размещение или
неправильное имя вложенного файла не регистрируются.

Существующая интеграционная проверка усилена: полный маршрут владельца
удаляется, прежний источник остаётся, текущий YAML меняется. Проверены чтение,
публикация, ограничение компонента и повреждение/отсутствие источника. Проверка
сначала падала на отсутствии пути, затем прошла. Повторно прошли 50 тестов
приложения, полный `pnpm test`, Clippy, архитектурные проверки и поиск дублей.
Генерация конкретных маршрутов восьми семейств остаётся следующей задачей.
