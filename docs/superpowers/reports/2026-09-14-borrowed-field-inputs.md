# Заимствованные входы полей и коллекций

## Реализовано

Порядок чтения привязанных входов рассчитывается отдельно для XML и YAML
после связывания деклараций. Прямая привязка поля или входа создаёт зависимость
только там, где вызываемая декларация читает этот вход. Вычисляемые привязки
сохраняют консервативную зависимость, поскольку вычисляются при подготовке.
Настоящие циклы чтения по-прежнему запрещены.

Вычисляемое поле может читать коллекцию объявленных записей через заимствованное
представление. Сгенерированное хранилище предоставляет поля по числовым слотам;
контекст содержит ссылку на исходный вектор. Нет повторного XML/YAML-разбора,
копии строк или второго дерева значений. Представление использует динамическую
диспетчеризацию на границе заимствования; это не интерпретатор деклараций.

Предикаты `each`/`exists` читают скалярные поля записи. Проверка `present`
позволяет пропускать отсутствующее значение до сравнения. Получение значения
отсутствующего поля и ошибка его типа различаются. Составная запись направляет
обращение к тому же хранилищу своих частей.

## Проверки

Матрица направления привязок проверяет противоположные порядки XML/YAML,
генерацию обоих преобразований и отклонение настоящего цикла. Старый пример
цикла уточнён: объявленный вход теперь действительно участвует в восстановлении;
неиспользуемая прямая привязка сама по себе не требует чтения.

Матрица коллекции проверяет пустоту, отсутствие совпадения, совпадение после
соседней строки, повторы и отсутствие поля у соседней строки; независимые
ожидания YAML сопровождаются проверкой восстановления XML. Проверка ядра
подтверждает идентичность адресов текста и точного десятичного числа, чтение
boolean, порядок, отсутствие и ошибки типа. Дополнительный пример читает
скалярное поле составной строки с вложенной коллекцией и атрибутом: эти
соседние данные сохраняются, а неподдержанные проекции не проверяются заранее
для полей, к которым выражение не обращается. Общие scalar-тесты не размножаются
на свойства предметных объектов.

## Самопроверка архитектуры

В изменённых нейтральных слоях нет имён common, метаданных или XML-корней.
Типы скалярных слотов определяет существующий преобразователь, порядок —
связанные зависимости, составные записи используют обычную маршрутизацию.
Проверка универсальности выполнена самостоятельно, без независимого ревью.

## Оставшаяся граница

Это чтение коллекции, не её сокращение: выбор единственного вхождения,
обратное распределение записей общей коллекции и подключение настоящего
`PropertyState` ещё не завершены. Нескалярные поля записи не получают фиктивного
значения; неподдержанный доступ диагностируется при генерации. Флажки common
не меняются: полная приёмка остаётся обязательной.

- После уточнения доступа к полям повторно прошла генерация Rust, включая
  составную строку с вложенной коллекцией.
- Массовый перенос коллекций: 61 договор; инвентаризация: 26 проверок.
- Проверка зависимостей Rust прошла.
- Флажки приёмки common остаются 19/90; новый объект полностью не принят.
