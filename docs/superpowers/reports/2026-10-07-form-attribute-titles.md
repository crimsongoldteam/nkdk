# Общий заголовок реквизита формы и колонки

Дата: 2026-10-07.

Автоматический перенос распознаёт существующее общее правило заголовка в
`FormAttributeRules` и `FormAttributeColumnRules`. Условие старой функции
выражено данными: отсутствующий XML-заголовок означает пустой перевод на
основном языке; отсутствующий YAML использует уже готовое правило имени
из `common.i8n-text`. В Rust не добавлен обработчик заголовка или переключение
по операции. Проверяется точное соответствие функции текущему исходному файлу;
подмена её текста или изменение исходника возвращает случай в список блокировок.

Оба владельца получают один общий фрагмент по проверенному месту определения
функции. Совпадение места определения само по себе не объединяет разные правила:
идентификатор фрагмента также включает весь полученный декларативный договор.

Проверено шесть сценариев: отсутствие заголовка, совпадение с именем, другой
текст, пустой `<Title/>` и два заголовка из неизменённого `mixedColumns.xml`.
Пустой XML-элемент сохраняется общей автоматически обнаруженной аномалией.
Обратное преобразование выполняется без XML-референса. Проверка относится
к изолированному заголовку в явно указанной оболочке, а не ко всей форме.

Пакет: `tests/migration/batches/form-attribute-titles.json`.
Команда: `node tools/rules-migration/src/focused-check.mjs --batch tests/migration/batches/form-attribute-titles.json`.
Узкий запуск использует две декларации из 425, одну смысловую часть и шесть
сценариев: преобразования прошли за 3,43 с, Clippy — за 5,36 с.
Все проверки переносчика заголовка прошли; новых дублей нет.
Полный набор проекта записывается после завершения отдельного запуска.

Флажки FormAttribute и формы не меняются. Следующий блок — полная колонка:
её имя и числовой идентификатор должны подключаться декларативно вместе
с уже готовыми свойствами, а не собираться вручную для каждого владельца.


При обновлении каталога обнаружена ранее не обновлённая зависимая декларация
стандартных реквизитов: она ещё считала пустой TypeDescription отсутствующим.
Ранее согласованный договор требует сохранять пустой список, если rules.ts
не задаёт отдельный пустой XML-default. Декларация обновлена обычным генератором;
XML и эталонные результаты не изменялись. Проверка неизменённых 16 сценариев
семейств стандартных реквизитов прошла, как и проверка самого генератора.
Повторно прошли шесть сценариев заголовка, Clippy узкого корпуса и все 240
проверок переносчика. Полный итоговый набор проекта выполняется отдельно.


Итог: полный `pnpm test` завершился с кодом 0. Все исходные XML, эталонные результаты и ограничения времени сохранены. Проверки новых дублей, архитектуры Rust и `git diff --check` прошли. Флажки целых объектов не изменены.
