# Приёмка MetadataObjectRefCollection

Принят общий common отдельно от полной сборки `Catalog`. Его YAML-декларация
описывает список объектных ссылок и существование целей по подготовленным
индексам. Ограничение владельца `Catalog.Owners` записано в его YAML:
разрешены только Catalog, Document, ChartOfCharacteristicTypes и ExchangePlan.
Компилятор переносит ограничения поля-коллекции в область значения коллекции;
Rust-обработчик не содержит названий этих видов.

Проверка использует неизменённые старые XML-примеры с одной и двумя ссылками,
а также реальные `Owners` из справочников `СправочникСВладельцем` и
`ЗначенияХарактеристик` корпуса e2e. Дополнительно проверены отсутствие,
пустой XML-элемент, порядок и повторы, цель без записи в индексе, запрет вида
цели владельцем и несоответствующий `xsi:type`. Все XML-примеры проходят
XML → YAML → XML без XML-референса. Недопустимые значения сохраняются через
общий механизм аномалий, а проверка написанного вручную YAML выдаёт
`metadata.target-not-allowed`.

Полный `Catalog` и его проектная операция в эту приёмку не входят: им нужны
остальные свойства и внешние ресурсы владельца. Флажок common не означает
готовности владельца.
