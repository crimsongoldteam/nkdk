# Приёмка UserVisible

`common.user-visible` целиком выражен YAML-декларациями: общий признак, коллекция ролей и сопоставление внутренних имён ролей с видимыми именами. Boolean повторно используется как common-тип; отдельного обработчика UserVisible в Rust нет.

Проверены три исходные XML-фикстуры и `UserVisible` из реальной формы e2e, экспорт двух написанных вручную вариантов YAML без XML-референса, пустые элементы и отсутствие повторного вывода значений. Для неизвестной роли, UUID, пустого имени, повтора, неверного boolean и соседних корректных значений автоматически сохраняются аномалии; XML восстанавливается. Схема выводится из той же декларации и отклоняет неверное значение boolean.

Проверки: 24 сценария пакета коллекций, 22 проверки схем, Clippy без предупреждений, поиск новых дублей без находок. После этого слоя полный `pnpm test` прошёл; архитектурные проверки ранее прошли без новых нарушений. Полные владельцы форм принимаются отдельно.
