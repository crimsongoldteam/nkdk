# Именованные коллекции вариантов и файл расширения — 2026-10-02

## Полученный результат

Общий сборщик объявленной коллекции теперь принимает выбор записей, если
каждый вариант предоставляет один и тот же текстовый ключ в XML и YAML.
Имя сокращается в ключ YAML, смысловой тег применяется ко всему значению,
а чтение использует уже существующий выбор вариантов и читатели записей.
Сопоставление полей выполняется при генерации по именам: порядок смысловых
полей вариантов может различаться. Порядок XML задаёт существующий `xmlOrder`.
Компилятор отклоняет несовместимые границы ключа и недопустимую рекурсию
вариантов; неподдержанная проекция значения не подменяется частным обработчиком.

Контекст размещённого выбора хранится в отдельной локальной копии.
Исходное правило дочерних элементов сохраняется, поэтому имя родителя и
индекс UUID передаются заново на каждой глубине. Это устраняет повторное
применение привязок родительской записи к дочерней области.

## Реальный XML

Источник без изменений:
`e2e/fixtures/xml/cfe/all-extension/Catalogs/СправочникСПредопределенными/Ext/Predefined.xml`.
Полностью проверены три верхние записи и вложенная запись:

```yaml
Группа2: !проверять
  Код: "000000004"
  Наименование: Группа 2
  ЭтоГруппа: Истина
  Элементы:
    Предопределенный3:
      Код: "000000005"
      Наименование: Предопределенный 3
Группа: !проверять
  Код: "000000003"
  Наименование: Наименование
  ЭтоГруппа: Истина
Предопределенный2:
  Код: "000000002"
  Наименование: Наименование
```

Независимое ожидаемое YAML проверяется в обоих направлениях, экспорт работает
без XML-референса. UUID восстанавливаются из полного пути записи в индексе.
AdoptedNotify обозначается тегом; AdoptedCheck восстанавливается из входной
принадлежности владельца. Собственное состояние дополнительно проверяется
матрицей отдельных записей. Неправильное состояние вложенной записи,
добавочный атрибут имени и повтор имени сохраняются общими аномалиями;
соседние записи остаются доступными, обратный XML проверяется целиком.

Оболочка файла генерируется существующим `file-envelope-operation.mjs` из
зарегистрированного `PredefinedRules` по новому YAML-профилю расширения.
Содержимое и условия описаны декларациями, новых объектных функций Rust нет.
Проверка сохранённой генерации включена в существующую матрицу оболочек.

## Границы приёмки

Это приёмка содержимого файла расширения и общего механизма коллекции.
Получение принадлежности и индекса от настоящего проектного владельца
пока проверяется через подготовленные входы. Рабочую проектную привязку
нужно завершить отдельно. XMLRoot остаётся без флажка, common — 56/90.
Не заявляется достижение 10×: замеры преобразования всего проекта не выполнялись.
Проверочный каталог включает TypeDescription и рекурсивные варианты;
наблюдаемый процесс rustc при его сборке достигал около 3,3 ГБ. Сборка
выполнялась одним процессом, без всего каталога кандидатных правил.

## Проверки

Общий договор — существующий файл `rule-compiler/tests/contributions.rs`:
независимый XML/YAML, разные номера общего ключа в вариантах, сохранение
тега, повторы, неправильное состояние и атрибут ключа. Общая тестовая оболочка
именованной коллекции вынесена в один шаблон; новый дубль удалён.
Результаты итоговых проверок записываются в журнал выполнения плана.

Дополнительный пакет команд также проверен на реальном корпусе. Его
сборка сначала превысила прежний лимит 4 МБ. У обычных списков убрана
генерация неиспользуемого вывода именованного словаря: объём этого пакета
снизился с 4 206 890 до 4 185 000 байт, и проверка команд прошла. Лимит
не увеличивался, состав доступных операций не менялся. Общая проверка
заголовка тега вынесена в одну функцию, работающую с заимствованными строками.

Итоговые проверки: 95 проверок выбранного компилятора, 91 ядра, 26 коллекций
и 12 TypeDescription, дополнительная матрица команд — зелёные. Clippy
для всех целей компилятора и ядра, форматирование, архитектура Rust/rules/
проекта и проверка дублей прошли. Матрица генерации оболочек — 14/14.
Общий `pnpm test` вне песочницы завершился с кодом 0; два существующих
интеграционных случая MCP пропущены, остаются предупреждения о целевом
времени отдельных тестов. Самопроверка выполнена без субагентов.
