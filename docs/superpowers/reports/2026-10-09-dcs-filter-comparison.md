# Элемент сравнения отбора СКД

Рабочая декларация автоматически собирает все девять сериализуемых свойств
FilterItemComparisonRules. Десятая исходная регистрация parent имеет
runtimeOnly: true: её исключают исходные XML/YAML-операции и тип YAML.
Исключение записано в происхождении проверочных случаев, а не скрыто
за незавершённым правилом. Рекурсивная группа и полный Filter проверены отдельной общей матрицей.

## Общие изменения

Неявное скалярное значение выбора сопоставляется единственному подходящему
варианту из декларации. Переносчик выводит выражения отсутствия и сокращения
YAML; неоднозначное совпадение остаётся явно неподдержанным. Проверка
с переименованным типом подтверждает отсутствие зависимости от UserSettingsID.
Пока создаются явные missing/omitWhen: сокращённая запись default для такого
выбора требует отдельного расширения общей генерации выражений.

Полная проекция считывает постоянный xsiType исходного владельца и переносит
его в обычный with-attributes с пространствами имён. Непостоянный тип
не заменяется догадкой. Компилятор правильно извлекает bool из заимствованного
варианта. Общая XML-проекция списка разрешает элементы непосредственно
под корнем, сохраняя запрет на проекцию самого корня как члена списка.

## Независимые случаи

Шесть Rust-сценариев прошли: исходное полное сравнение, InList, отсутствующая
пользовательская настройка, явный режим применения, исходный InList с nil,
неверное use. Проверены оба направления и восстановление XML без референса.
Источники XML не изменялись. Старый смысловой пустой элемент {} по-прежнему
принимается; точная форма xsi:nil сохраняется через уже принятый договор
аномалий типизированных значений, с соседями и повторениями на прежних местах.

Нейтральная регрессия смешанного выбора использует существующую декларацию
choice-default с другим скаляром. Проекция списка отдельно проверяет повторы,
nil и чужого соседа. Исходная ошибка компиляции &bool/bool и отказ проекции
прямых дочерних элементов воспроизведены до исправления.
