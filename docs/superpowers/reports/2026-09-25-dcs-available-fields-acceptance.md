# Приёмка AvailableFields

`common.dcs-available-fields` описывает упорядоченный список. Строка без дополнительных свойств представлена именем поля; полная строка содержит `Поле` и необязательные `Использование`, `Заголовок`, `МногоязычныйЗаголовок`, `РежимОтображения`. Выбор форм, XML-пути и схема находятся в YAML-декларациях; булево, многоязычный текст и перечисление повторно используют общие декларации.

## Проверенные договоры

- Неизменённый `full.xml` и фрагмент настоящей e2e-формы `CommonForms/УсловноеОформление/Ext/Form.xml` дают два коротких имени в исходном порядке и восстанавливают XML.
- `selected-item.xml` сохраняет оба вхождения поля `Документ`, истинное и ложное использование, оба вида заголовка и режим `Обычный`; порядок XML соответствует исходному примеру.
- Новый YAML экспортируется без XML-референса. Полная запись с одним `Поле` при повторном чтении сокращается до строки. Пустое свойство также восстанавливается.
- Неверное булево значение и пустой элемент среди корректных элементов сохраняются автоматически выведенными аномалиями. Корректный сосед остаётся смысловым YAML; итоговый XML совпадает с исходным.
- Схема принимает строку и полную запись, требует `Поле`, отвергает неизвестный режим и лишние поля.

Исходные проверки `fromXML`, `toYAML`, `fromYAML`, `toXML` покрыты одной матрицей `rust/crates/compiled-rules/tests/dcs_lists.rs`; схема — отдельным договором в существующем `schema.rs`. Проверки `AvailableValues` объединены с ней без удаления защищаемых случаев. Общий помощник выполняет проверку ожидаемых фрагментов и round-trip, устраняя повторение.

## Общие исправления и границы

Событийное чтение скалярной проекции записи теперь использует уже сгенерированный читатель проекции, как отдельное чтение документа. Прежде вложенный путь ошибочно ожидал словарь. Второе исправление сохраняет корень пустой коллекции: отсутствие смысловых элементов больше не отменяет применение сохранённой XML-пометки. Регрессия дополнительно проверена на пустом корне `AvailableValues`.

Самопроверка универсальности: изменённые участки различают конструкции языка и наличие XML-пометки; имён `AvailableFields`, DCS, конкретных полей или их количества в этих условиях нет. Независимое ревью не проводилось. Структурированный выбор внутри списка подключён существующей записью с проекцией; прямая последовательность выбора без этой записи остаётся общим ограничением компилятора. Полные владельцы СКД и форм принимаются отдельно.

## Результаты проверок

Прошли 73 проверки связанных Rust-пакетов и 23 проверки схем; после исправления пустого корня повторены 29 проверок коллекций. Итоговые проверки DCS-списков также прошли с двумя заголовками в одной строке, включая английский перевод. Clippy без предупреждений, форматирование, `git diff --check`, `pnpm type-check`, `pnpm test:architecture:rust`, `pnpm test:architecture`, полный `pnpm test` и `pnpm duplicates -- --base 2af2f299ed8241eac78d4db46b4a8421efe2f8f7` прошли. Новых дублей нет. `AvailableFields` отмечен в чеклисте как завершённый common-объект.
