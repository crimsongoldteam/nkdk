# Автоматический перенос значений по умолчанию владельцев

Переносчик распознаёт 120 скрытых скалярных свойств и пустой неявный синоним
StandardAttributeDescriptionRules. Эти подключения используют существующий
язык деклараций; Rust-компилятор и производственный оркестратор не изменены.
[Уточнение спецификации](../specs/2026-09-14-owner-defaults.md).

Скрытая принадлежность команды проверена вместе с соседним свойством по
исходному e2e-файлу перечисления. Известное нестандартное и неизвестное значения
проверены как изменения этого примера: оба сохраняются без потери XML.
Синоним стандартного реквизита проверен по независимому YAML; пустой контейнер,
пустой основной и другой язык различаются. Пустые переводы используют отметку
у языка без сырой XML-поправки. Исходные XML-фикстуры не изменены.

## Проверки

- 87 сценариев коллекций: семь новых случаев включены в существующий запускатель.
- 127 общих сценариев переноса.
- 133 сценария подключений, включая файловые ресурсы.
- 30 проверок переносчика; расширены существующие проверки, новых функций
  unit-тестов не добавлено.
- Архитектура Rust и новые дубли относительно 34a3e11d6.

Общий прогон выявил два устаревших ожидания пустой XML-поправки. Для boolean
отображение до и после изменений идентично; старая форма `{}` проверена на
обратном чтении. Для пустого I8nText-контейнера исправлено смешение пустого
элемента с удалением. Конвертер ради этих ожиданий не менялся, строгая проверка
YAML не ослаблялась. В источники договора добавлена реализация XML-поправок.

Полные объекты этим блоком не принимаются: у родительского перечисления ещё
нет полного преобразования стандартных реквизитов, характеристик и команд.
Счётчики остаются 19/90 common и 1/57 прикладных объектов с вложенными частями;
флажок перечисления снят. Полный pnpm test и цели 10× этим блоком не проверялись.
