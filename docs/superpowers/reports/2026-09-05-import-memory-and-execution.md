Теперь подготовленное значение сбрасывается только у исключённого смыслового поля; договор подготовленных значений присутствующих полей не меняется. ## Отбор адресов зависимостей и служебных фактов

свойств. При отсутствии кандидатов его обход вообще не выполняется.

значениями proof. Они по-прежнему участвуют в восстановлении состава
значимого свойства. Представление соседних полей создаётся только при
наличии соответствующей зависимости metadataTarget.

свойств не расширяют чтение типов для 64 кандидатов; незапрошенное значение
не читается ради неиспользуемого представления соседей; служебный контейнер
не доступен как экспортное свойство, при этом составное значение сохранено.
