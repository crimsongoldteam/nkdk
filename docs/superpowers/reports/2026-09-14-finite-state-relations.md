# Одна таблица для обоих направлений

Реализована [форма `state-relations`](../specs/2026-09-14-finite-state-relations.md).
Проверочный пример больше не хранит два независимых дерева условий:
XML-распознавание и YAML-восстановление выводятся из одной таблицы.

## Реализация

Разбор декларации разворачивает таблицу в существующие типизированные
выражения и правила присутствия. Связывание дополнительно проверяет полный
домен импортированного перечисления и разделение XML/YAML-проекций.
Генератор Rust и механизм аномалий не получили обработчиков конкретного common.
Во время преобразования не разбираются строки состояний или таблица правил.

Обновлена также JSON Schema авторского формата: редактор проверяет структуру
новой записи. Полнота комбинаций, ссылки, типы и циклы проверяются компилятором.

## Проверки

- Прежняя матрица четырёх форм YAML выполняется для обычной и составной записи,
  включая независимое дополнительное поле и сохранение неизвестного XML-значения.
- В ту же исполняемую матрицу добавлены три источника и восемь состояний:
  оба направления имеют независимые проверки XML и YAML.
- Матрица связывания отвергает неполные сочетания, неоднозначность, неизвестные
  и повторные источники, ручное переопределение присутствия, конфликт проекций,
  несовпадающий тип, неполное перечисление и циклическое восстановление.
- Матрица JSON Schema расширена структурными ошибками. Повтор проверки мутации
  вынесен в общий помощник после замечания jscpd; сценарии не удалены.
- Полный набор тестов `nkdk-rule-compiler` прошёл. После последней правки тестов
  повторно прошли `declaration_schema` и `link` (60 тестов связывания).
- Clippy для компилятора со всеми целями, форматирование и проверка Rust-границ
  прошли. Проверка новых дублей относительно `37acdae1f` прошла.
- Проверка инвентаризации переноса: 26 сценариев прошли.
- Проверка переноса коллекций: 61 договор прошёл.

Самопроверка универсальности: предметных имён нет, число источников не
зафиксировано, имена и соответствия находятся в декларациях. Самопроверка
не заменяет независимое ревью; субагенты не запускались.

## Что ещё не завершено

Таблица сейчас связывает физические поля. Выделение строки настоящего
`PropertyState`, передача остатка коллекции, обратная вставка, контекст
базового UUID и применимость владельца остаются открытыми. Этот результат
не означает приёмку `ExtendedConfigurationObject` или EnumValue;
флажки объектов не менялись, цель 10× этим не измерялась.
