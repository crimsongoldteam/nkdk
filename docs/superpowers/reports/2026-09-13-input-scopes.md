# Заимствованные входы и порядок вычислений

Промежуточный результат блока 3
[плана](../plans/2026-09-13-unified-conversion-plan.md).

`PreparedInputs` владеет данными одной операции. `InputView` заимствует их:
строки, точные числа, списки, индексы и внешние XML-документы не копируются.
`rebind` получает массив слотов дочерней области; отсутствующий слот не
заменяется одноимённым или однономерным входом владельца. Проверка готовности
не создаёт диагностик и строк для отсутствующих слотов.

Публичные операции преобразования, проверки YAML и вклада в индексы сохраняют
`PreparedInputs` и проверку `EntryId`. Внутренние сгенерированные функции
получают `InputView`. Существующие тесты внутренних читателей и писателей
адаптированы к этой границе без изменения ожидаемых XML/YAML.

`RecordPlan.schedule` отделяет порядок вычислений от порядка представления.
Связывание и подготовка плана используют один обход зависимостей. Цикл
возвращает координаты участвующих полей. Ограничение, проверяющее уже
вычисленные поля, не создаёт дополнительную зависимость вычисления.

Полный Rust-прогон: 204 проверки прошли. Существующие матрицы дополнены
проверками адресов заимствованных списков, точных чисел, индексов и документов;
число ссылок `Arc` не растёт при создании дочерней области. Незавершённый индекс
остаётся технической диагностикой. Проверены порядок восстановления и
координаты цикла; число тестов не увеличено.

Архитектурная проверка Rust и поиск дублей относительно `37acdae1f` прошли.
Clippy прошёл; отдельный запуск коллекций подтвердил все 22 сценария.
Самопроверка универсальности: новые механизмы различают типы входов и
зависимости полей, предметных имён и отдельных обработчиков объектов нет.
Независимое ревью не запускалось.

Блок пока не завершён: создание привязок у произвольного дочернего значения
и отложенное завершение его состояния требуют общего пути записи из блока 4.
Не расширяем старые группы частными сочетаниями типов. Новых принятых
common-объектов нет; флажки объектного чеклиста не меняются.
