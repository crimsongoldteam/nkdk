# Приёмка common `FunctionalOptionsProperty`

[`common.functional-options-property`](../../../rust/declarations/common/functional-options-property.yaml) описывает список ссылок без отдельного обработчика Rust. Общий текстовый шаблон сокращает `FunctionalOption.Булево` в XML до `Булево` в YAML и восстанавливает префикс при экспорте. Пустой `<Item/>` задаётся второй декларативной формой; выбор форм компилируется заранее, без проверки имени объекта во время преобразования.

Проверка `functional_options_preserve_empty_items_duplicates_and_order` сопоставляет XML и независимые ожидаемые YAML-значения для трёх неизменённых файлов e2e (`cf` и `cfe`), повторов и пустой строки. Проверены оба направления без XML-референса, обязательное сокращение имени, обратное раскрытие, YAML-валидация и автоматическое сохранение неверного XML `Other.А` как аномалии. Отдельно проверены отсутствие и пустая коллекция. Неправильно записанное полное имя в обычном YAML отклоняется.

Это приёмка собственного common-договора. Полные владельцы форм и их остальные свойства принимаются отдельно.
