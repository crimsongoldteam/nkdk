# Семейства единого преобразования

## Реквизиты документа

Источник: `MetadataDocumentAttributeRules` из
`packages/rules/metadata/appliedObjects/metadataDocument/childRules.ts`.

Команда воспроизведения:

```sh
pnpm migration:families -- --family document-attributes
```

Исходный состав защищён отчётом вместе с параметрами переопределения:

- свойств: 31;
- готовых кандидатов: 26;
- связанных старых сценариев: 440;
- заблокированных свойств: 5.

Оставшиеся свойства сгруппированы по общим договорам:

| Договор | Свойства | Причина |
|---|---|---|
| Значение реквизита | `fillValue` | Нужна декларация `MetadataValue` с различением отсутствия, пустоты и `xsi:nil` |
| Параметры выбора | `choiceParameterLinks`, `choiceParameters` | Нужны декларации общих коллекций выбора |
| Ссылки на метаданные | `choiceForm`, `binaryDataStorageLocationUseField` | Нужны общие ограничения цели ссылки, выраженные данными декларации |

Имя, синоним и UUID больше не являются блокировками. Имя распознано как ключ
именованной коллекции, вычисляемый синоним совпал с общей декларацией I8nText,
а `evaluateWhenYAMLMissing` UUID сопоставлен с восстановлением из индекса.
Все три решения используют общие профили и применимы к другим семействам.

Этот отчёт фиксирует исходную границу семейства. Завершение семейства требует
рабочих YAML-деклараций, подключения коллекции к документу и полного
XML → YAML → XML без использования исходного XML как скрытого reference.
