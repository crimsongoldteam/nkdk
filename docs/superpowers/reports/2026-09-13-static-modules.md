# Статические модули: подключение и проверки

Перенесены файловые маршруты 57 статических вхождений Module. Это 15 точных
профилей исходных rules.ts и 11 видов маршрутов; расширять Rust-компилятор
не потребовалось. Используется существующий resources/oneOf: текстовый .bsl
и двоичный .bin — альтернативы одной группы, а не два независимых свойства.

Маршруты охватывают модули менеджера, объекта, набора записей, общего модуля,
управляемого/обычного приложения, сеанса, внешнего соединения, команды,
формы и менеджера значения. Фрагменты находятся в rust/declarations/fragments,
исполняемые файловые сборки — в rust/declarations/resources.
Четыре модуля конфигурации дополнительно объединены в одну сборку
resources.configuration-modules, общую для основы и расширения.

Все 57 привязок сверены с конкретными исходными параметрами и фактической
композицией. В общей группе готовых подключений теперь 100 вхождений,
65 привязок к исполняемым декларациям и 21 явная блокировка. Число привязок
включает отдельные файловые сборки и не означает 65 полных объектов метаданных.
20 вычисляемых путей и один syncArea не заменены приближениями.
Флажок Module остаётся пустым; итог common — 19/90.

## Проверки

Добавлен один общий Rust-тест по списку
[существующих файлов e2e](../../../tests/migration/module-resource-e2e.json):
213 файлов .bsl проверяются побайтово в обе стороны, включая пустые файлы.
Также проверяется группа модулей обеих конфигураций и отсутствие модуля
обычного приложения. Двоичных модулей в этом наборе e2e нет: их маршруты
проверены независимо по исходным правилам; сохранение непрозрачных байтов,
конфликты альтернатив и отмена записи покрыты прежней общей ресурсной матрицей.

Добавлен один тест инструмента миграции: точный статический профиль,
обе альтернативы и отклонение неизвестного маршрута/syncArea/вычисления.
Для каждого из 57 свойств добавлены только данные проверочного договора,
а не копия общей матрицы тестов. Запускатель проверяет не только пути,
но и принадлежность альтернатив одной группе.

Полный Rust-прогон — 200 тестов; отдельный набор кандидатов — 133 договора.
Проверки инструмента миграции — 20 тестов. Фикстуры XML не изменялись.
Clippy с --all-targets и -D warnings прошёл для всего Rust workspace и
запускателя кандидатов. Архитектура Rust, форматирование, git diff --check
и поиск новых дублей относительно 3ed62e9ecbe0089dcf625e1f190ad2688477f666
прошли. Пакет статических файловых маршрутов завершён; Module целиком не принят.

## Ускорение проверки

Два раздельных cargo test по пакетам заменены одним запуском с --workspace
и выбором целей path_lexicons/resources. Это сохраняет разрешение зависимостей
полного прогона. Два последовательных запуска прошли без строки Compiling;
подготовка Cargo во втором заняла 0,04 с. Время самих тестов учитывается отдельно.

У nkdk-compiled-rules нет тестов внутри сгенерированной библиотеки: все
проверки лежат в tests/*.rs. Отключена только пустая внутренняя тестовая
программа (lib.test=false). Ни одна проверка не удалена; doctest сохранён.
Полный прогон после изменений сохранил прежние 199 тестов и добавил один новый.
Холодное время и ускорение конвертера 10× этим измерением не подтверждаются.

## Следующий блок

При выборе следующей работы основной отчёт кандидатов объединён с готовыми
подключениями по исходному файлу, символу и свойству. Пересечений нет:
100 файловых свойств снимают 100 из 2508 блокировок основного отчёта; остаются
2408, а не 2508. Готовые файловые маршруты нельзя снова выбирать как отсутствующий common.

Следующий общий блок — собственная и базовая идентичность объектов.
В основном отчёте остаются 140 блокировок uuid. Небольшой первый потребитель —
MetadataEnumerationValue: готовые кандидаты четырёх свойств ещё не решают uuid
и extendedConfigurationObject. На e2e заимствованного значения обнаружены
оба идентификатора и служебная оболочка; их нельзя терять или подменять !xml.
Работы и условия полной приёмки внесены в план.

Самопроверка универсальности: предметные пути записаны только в декларациях
и профилях миграции. Общий Rust-механизм файлов не изменён. Изменение запускателя
кандидатов проверяет общий состав альтернатив и не содержит имён метаданных.
Независимое ревью не выполнялось; субагенты не использовались.
