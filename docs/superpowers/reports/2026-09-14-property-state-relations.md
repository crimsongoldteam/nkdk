# Связь таблицы состояний с общей коллекцией

## Реализовано

- `sources.from` подключает обычное выражение к источнику таблицы состояний.
  Физический XML-путь для вычисляемого источника запрещён; типы и зависимости
  проверяются до генерации Rust.
- В восстановлении объявленных коллекций `concat` соединяет типизированные
  последовательности, в том числе условные. Код наполняет один вектор;
  промежуточных векторов отдельных ветвей и промежуточного XML/YAML нет.
- Аномалии скрытой коллекции записываются на физической границе свойства,
  а не отдельным YAML-документом внутри записи владельца. Это исправляет
  обнаруженный сбой синтаксиса YAML при сохранении переставленных строк.

## Наблюдаемые договоры

Проверочный владелец использует `Properties/ExtendedConfigurationObject` и
`InternalInfo/xr:PropertyState` с пространством имён платформы. Одна таблица
выполняет оба направления для четырёх сочетаний базового идентификатора и
уведомления. Значение базового идентификатора пока передаётся готовым входом.

Дополнительный договор включает обычную соседнюю строку, её смысловое поле YAML
и восстановление коллекции из обоих полей. Проверяется независимое ожидание
обычного YAML без raw; повторные строки и изменённый порядок проходят обратную
проверку XML. Дубли не разрешаются произвольным выбором первой строки.

Существующая матрица связывания проверяет также конфликт физического и
вычисляемого источника, запрещённый YAML-ключ источника, цикл, неизвестное поле,
несовместимый тип и типы объединяемых последовательностей. XML-фикстуры e2e
не изменялись. Проверочные файлы компилятора не выдаются за полную e2e-приёмку.

## Граница приёмки

Нормальные источники каждого владельца должны все участвовать в декларативной
сборке. Неизвестную компилятору нормальную обработку нельзя прикрывать raw.
Примитив переноса выбранной записи остаётся доступным в ядре; этот проверенный
путь использует заимствованное чтение и восстановление строк из смысловых полей.

Полный `ExtendedConfigurationObject` ещё требует рабочего базового индекса,
проверки применимости full/adopted и подключения к полным владельцам. Поэтому
флажки не добавлены: 19/90 common. Предметных условий в компиляторе/ядре не
добавлено. Выполнена самостоятельная проверка кода, не независимое ревью.

сохранения обычного поля соседа и физической границы поправки также прошла
на сгенерированном Rust. Clippy всех целей двух пакетов завершился без замечаний;
