# Приёмка Order

`Order` полностью описан YAML-декларацией: упорядоченные элементы, режим отображения, идентификатор пользовательской настройки и её представление. Вложенные `OrderItemFields`, `UserSettingsID` и `DCSLocalStringType` переиспользуются без обработчика `Order` на Rust.

Проверка `migration.dcs-order` проводит XML → YAML → XML без XML-референса на двух старых фикстурах и восьми блоках `order` реальной формы `ДинамическийСписок`. Проверены оба вида представления настройки (`v8:LocalStringType` и `xs:string`), новая YAML-запись с `[Авто]` и направлением сортировки, отсутствие `Order`, сохранение неверного направления общей аномалией. Обнаруженный при вложении сбой семантического тега исправлен в общем механизме YAML-скаляров, а не частным условием объекта.

Четыре проверки пакета `nkdk-probe-dcs-lists`, семь проверок YAML-узлов, Clippy, полный `pnpm test`, 236 договоров переноса, архитектура и поиск новых дублей прошли. Полные владельцы форм и СКД остаются самостоятельными пунктами чеклиста.
