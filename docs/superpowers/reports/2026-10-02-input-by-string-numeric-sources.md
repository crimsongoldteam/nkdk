# Состояния и текущие числовые источники InputByString

Состояния восьми семейств и числовые значения CF/основы CFE подключены
автоматически одним генератором. Дополнений частных обработчиков в Rust нет.
Каталог содержит 48 рабочих источников и 56 маршрутов: 24 источника
реквизитов, 8 сохранённых UUID, 8 состояний и 8 текущих числовых проекций.

## Договор первого импорта

Зависимый источник получает UUID из текущего XML до публикации сохранённых
файлов, независимо от порядка записей каталога. Проверены первый импорт,
обновлённый UUID при повторном импорте, цикл, отсутствующая зависимость и
невыбранная ветвь. Используется общий механизм привязки источников; старый
YAML не служит заменой текущему XML. Кэш содержит только запрошенные
компактные зависимости, а не копии всех материалов проекта.

## Проверки реальных данных

Одна матрица охватывает 8 CF и 16 CFE. После импорта исходный XML удаляется.
Состояния сравниваются с ранее принятым прямым источником XML. Числовые
значения сравниваются с прямой проекцией текущего YAML CF; для CFE поиск
основы идёт по сохранённому UUID. Правка ДлинаКода с 11 на 12 в копии
YAML основы должна сразу изменять подготовленный источник расширения.
Файлы e2e/fixtures не изменяются.

## Состояние приёмки

Генератор: 12 проверок прошли; воспроизводимость --check подтверждена.
Рабочее приложение: 54 проверки прошли (44 подготовки фактов, 1 CLI,
9 ресурсов). Матрица 24 объектов подтвердила состояния и базовые числа
после удаления XML; изменение ДлинаКода 11 → 12 видно расширению.
Clippy, type-check, три проверки архитектуры и поиск дублей прошли.
Полный pnpm test завершился с кодом 0 после уточнения проверки полноты
генерации: она включает восемь новых рабочих числовых проекций.
Существующие пропуски тестов и ограничения времени не менялись. Приёмка источников не равна подключению
потребителя InputByStringFields: флажок common остаётся снятым, 54/90.
Цель 10× и пик памяти выполнения этим блоком не измеряются.


## Проверка разделения областей

Один источник может иметь разные маршруты для непересекающихся компонентов
CF и CFE. Проверка каталога запрещает пересекающиеся области, в том числе
неограниченную область вместе с отдельным компонентом. Проверено чтение
одного каталога и объединение каталогов. Это общий договор регистрации,
без условий по именам метаданных.

Генерация: основной пакет 29,69 МиБ при лимите 32 МиБ, пакеты источников
5,08/5,09 МиБ при лимитах 8 МиБ. Лимиты не повышались.
