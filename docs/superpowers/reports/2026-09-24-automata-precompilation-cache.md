# Повторное использование предварительно скомпилированных автоматов

Дата: 24 сентября 2026 года. Каталог: `probes`, 262 YAML-файла и 1814
деклараций. Rust 1.98.1, одна и та же машина, `CARGO_BUILD_JOBS=1`,
`CARGO_INCREMENTAL=0`, `CARGO_PROFILE_DEV_DEBUG=0`.

До изменения готовые двоичные таблицы одинаковых автоматов объединялись,
но построение и проверка автомата повторялись для каждого применения.
Кэш теперь хранит результат построения в пределах одной генерации. Ключ
включает полный набор выражений или частей, запасной вариант и ограничения
по состояниям и байтам. Ошибки продолжают проверяться обычным путём.

| Показатель | До | После |
|---|---:|---:|
| Генерация | 46,68 с | 3,03 с |
| Общее время примера `profile` | 47,18 с | 3,53 с |
| Пик RSS процесса генератора | 272 МБ | 295 МБ |
| Созданные файлы | 154 | 154 |
| Общий размер файлов | 46 920 703 байта | 46 920 703 байта |

Для каждого файла сравнен устойчивый 64-разрядный контрольный хеш: все
154 совпали, как и отчёт размеров. Время — один исходный и один новый
прогон; это большая разница, но не измерение разброса. Пик памяти кэша
выше на 23 МБ; память `rustc` этим изменением не затронута. Поскольку
созданные файлы побайтово одинаковы, путь выполнения XML ↔ YAML не изменён.
Это не уменьшает 31,4 МБ Rust-исходника и не закрывает задачу сокращения
работы `rustc`.

`cargo test --offline --workspace --no-run` с указанными выше настройками
после изменения прошёл за 417,7 с; максимальная память одного дочернего
процесса составила 5,85 ГБ. Исходного замера **этой же команды** на том же
состоянии каталогов нет, поэтому эти числа нельзя выдавать за выигрыш
полной сборки. Они показывают, что после устранения повторного построения
автоматов главным ограничением остаётся компиляция большого Rust-каталога.

По решению пользователя сокращение самого Rust-исходника пока не является
приоритетом; этот отчёт закрывает только повторную компиляцию автоматов.

Проверки: `cargo test --offline --workspace`, Clippy для
`nkdk-rule-compiler`, `pnpm test`, правила архитектуры и поиск новых дублей
прошли.
