# Значения по умолчанию и сохранение присутствующего XML

## Сделано

Переносчик распознаёт постоянный defaultValue обычного скаляра, когда он
совпадает с уже проверенным смыслом implicitValueYAML. Поддержка общая для
boolean, string и number; переименование поля не меняет результат.
Разные defaults, функции, null и конфликтующие XML-параметры остаются
заблокированными. Для чисел сохраняется требование безопасного исходного
целого: нет перехода через округление JavaScript.

Это разблокирует autofill из AutoCommandBarRules. Его true соответствует
сокращённому YAML-значению Истина. XML/YAML-поведение задаётся обычными
правилами присутствия; отдельного обработчика панели в Rust нет.

## Найденная потеря XML и исправление

`<AutoCommandBar/>` и
`<AutoCommandBar><Autofill>true</Autofill></AutoCommandBar>` сокращаются
до одинакового обычного YAML. Канонический экспорт опускает Autofill.
Существующая дополнительная проверка записи принимала потерю явно
присутствующего поля как разрешённое каноническое сокращение.

Эта поблажка удалена из общего генератора записей. После строгого сравнения
применяется уже существующее сохранение разницы XML. Явно записанное
сокращаемое значение получает !xml/raw; отсутствующее поле обходится без
пометки. Смысловое значение сохраняется. Никаких дополнительных параметров
аномалии в декларации и проверок имени autofill в компиляторе не добавлено.

Матрица проверяет булево, строку и точное число, отсутствие и обычное
значение, явно записанное сокращаемое значение, а также композицию двух
фрагментов с независимым соседним полем. Последняя проверка защищает работу
в собранном объекте, а не только в отдельной декларации.

## Воспроизводимые проверки

- `pnpm test:migration-family --family scalar-fallbacks`: 12 сценариев.
- `pnpm test:migration-family --family form-parameters`: 12 сценариев CF/CFE.
- `pnpm test:migration-family --family enum-values`: 16 сценариев.
- Compiler lib: 20 проверок; generate: 11 проверок, существующий тест размера
  проигнорирован, большой монолитный запуск не выполнялся. Исполнение нового
  договора проверяется небольшими AOT-каталогами вместо монолитной сборки.
- Полный `pnpm test` вне песочницы, включая 227 проверок переносчика,
  type-check, три проверки архитектуры, Clippy и новые дубли — прошли.
- Рабочий пакет `nkdk --test facts`: 46 проверок прошли, включая создание
  владельцев и реальные CF/CFE. Последовательная пересборка после изменения
  генератора заняла 6 минут 25 секунд; сами проверки — 18,78 секунды.
  Это длительность этого запуска, не замер холодной сборки или пика памяти.

У проверки перечисления исправлено противоречивое ожидание: один сценарий
одновременно требовал !xml/invalid и запрещал любые !xml-теги. Теперь он
сравнивает полный независимо составленный YAML, сохраняя проверку неверного
режима совместимости и соседних значений. Пересоздан только его проверочный
JSON; исходные XML и старые YAML-фикстуры не изменялись.

## Границы

Автоматически распознаются 3 из 5 свойств AutoCommandBarRules.
Name и ChildItems остаются заблокированными. Панель и формы в чеклисте
не отмечены завершёнными: ещё нужны декларативный договор имени/id из
регистрации элемента, вложенные кнопки и группы и полная файловая операция.

Самопроверка выполнена по .agents/declarative-review.md; независимое ревью
не проводилось по указанию работать без субагентов. Замеры исполнения и
пиков памяти в этот блок не входят; цели 10× не объявляются достигнутыми.
