# Приёмка CommonAttributeContent

`CommonAttributeContent` перенесён в [YAML-декларацию](../../../rust/declarations/common/common-attribute-content.yaml). Она описывает коллекцию `Content/xr:Item`, русские имена свойств, перечисление `CommonAttributeUse`, пустые формы и пути объектов. Два особых русских корня пути заданы проекцией общей таблицы корней без копирования остальных значений. Rust-компилятор и исполнитель не содержат условий по имени `CommonAttributeContent`.

[Проверки](../../../rust/crates/compiled-rules/tests/common_attribute_content.rs) охватывают неизменённый e2e XML общего реквизита, старые структурные примеры, повторные строки, отсутствие и пустоту коллекции, один пустой `xr:Item`, неизвестный текст ссылки, неверное значение перечисления и построение XML из YAML без референса. Для исходных XML проверено восстановление формы. Неизвестный текст ссылки остаётся обычным YAML; неверное перечисление сохраняется автоматически выведенной аномалией. [Схема](../../../rust/crates/rule-compiler/tests/schema.rs) строится из той же декларации.

Договор `ownerFactRole: commonAttributeOwnerLinks` относится к сборке полного владельца `MetadataCommonAttribute` и проверяется при его отдельной приёмке. Это не меняет семантику и обратимость самого common-значения.
