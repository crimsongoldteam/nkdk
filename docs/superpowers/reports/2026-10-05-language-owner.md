# Полный владелец языка

### 2026-10-05 — автоматическое подключение языка

Профиль MetadataLanguageRules создаёт полную декларацию metadata.language:
8 исходных свойств, без pending и blockers. Общий построитель маршрута получил
параметр yamlFile: null для плоского YAML; прежнее размещение Свойства.yaml
остаётся значением по умолчанию. Параметр применяется одинаково к маршруту
владельца и его источников фактов, без условий по виду метаданных в Rust.

Проверка параметра сначала упала, затем прошла после изменения построителя.
Язык добавлен строкой в существующую матрицу владельцев; она проверяет четыре
неизменных XML CF/CFE, обратное преобразование без исходного XML, создание
нового языка и устойчивую идентичность. Проверка прошла в небольшом AOT-наборе;
также прошли 222 проверки переносчика. Полная приёмка штатного приложения
ещё выполняется; флажок языка пока снят. Исходные XML не менялись.

### 2026-10-05 — язык принят полностью

Штатное приложение прошло 46 проверок фактов и владельцев, 11 проверок ресурсов
и одну проверку CLI. Полный проект содержит 19 владельцев CF и 22 владельца CFE;
результаты сравниваются с независимыми YAML-эталонами и неизменным исходным XML.
Общая матрица проверяет 14 реальных XML XDTO, WebSocket и языка, экспорт после
удаления XML и создание новых объектов со стабильными UUID. Прошли также
222 проверки переносчика, небольшая файловая проверка (3 теста), Clippy,
полный pnpm test, проверки архитектуры и отсутствие новых дублей.

Все 8 свойств языка подключены автоматически, флажок metadataLanguage выставлен.
Компилятор и исполнение деклараций Rust не менялись; настройка размещения YAML
остаётся данными профиля. Цель 10× не измерялась этим блоком, весь проект ещё
не переведён. Следующий пакет требует проверки зависимостей стиля и элемента
стиля, а не добавления частных обработчиков в общий механизм.
