# Прямое создание строк коллекции

Реализована следующая часть [договора создания записей](../specs/2026-09-14-declared-record-construction.md):
существующие `sequence`/`record`/`if` в правилах отсутствия создают строки
скалярного генератора напрямую. Генератор записи формирует типизированное
хранилище из смысловых слотов; XML и YAML не используются как промежуточное
представление. Вложенные и составные конструкторы пока не объявлены готовыми.

Проверки содержат запись из трёх текстовых полей, включая XML-атрибут,
и запись из четырёх полей: перечисление, вычисляемый текст, boolean и точное
десятичное число. Значение перечисления `tagged` экспортируется как `Tagged`,
а число `9007199254740993` не округляется. Условие
использует подготовленный вход. Независимые XML-ожидания проверяют создание,
отсутствие и приоритет явно заданного пустого списка над правилом отсутствия.
Прежние проверки обеих сторон преобразования сохранены.

Самопроверка универсальности: нет предметных имён или условий по числу полей;
слоты и типы выводятся из декларации, граница поддержки определяется общим
скалярным генератором. Это самостоятельная проверка, не независимое ревью.

Полная связь таблицы состояний с общей коллекцией `PropertyState` остаётся
открытой: требуются выбор вхождения, обратное распределение строк и сохранение
остатка. Флажки common остаются 19/90; промежуточный механизм не закрывает объект.

## Результаты

- Полный набор компилятора прошёл; после добавления перечисления повторно
  прошли генерация и выполнение обоих направлений.
- Clippy всех целей компилятора, форматирование и проверка изменений прошли.
- Массовый перенос коллекций: 61 договор; инвентаризация: 26 проверок.
- Проверка зависимостей Rust прошла; новых дублей относительно `37acdae1f` нет.
- Нормальные записи строятся напрямую; полная приёмка предметных объектов
  и подтверждение цели 10× этим результатом не заявляются.
