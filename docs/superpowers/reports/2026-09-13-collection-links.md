# Автоматическое извлечение связей коллекций

Генератор читает регистрации рядом с rules.ts и включает связи в manifest
кандидатов. Команда `pnpm migration:collections` сохраняет тот же граф отдельно
в `tests/migration/collection-links.json`. Исполнение модулей метаданных для
построения графа не требуется.

Поддержаны прямые вызовы фабрики, импортированные алиасы, семейства map над
статическим массивом, строковые и парные элементы такого массива. Статический
разбор понимает typeof, индекс массива и замену строки литеральным регулярным
выражением. Переопределение itemRule у свойства разрешается по происхождению
исходного объявления, а не по совпадению содержимого объектов.

| Свойство | Найденное правило элемента |
|---|---|
| MetadataEnumerationRules.enumValues | MetadataEnumerationValueRules |
| MetadataDocumentRules.attributes | MetadataDocumentAttributeRules |

Для реквизитов документа общий MetadataAttributeRules из регистрации не
подменяет переопределённое правило свойства. Граф сохраняет XML/YAML-пути,
ключ элемента и объявленные сведения о владельце.

Получено 78 регистраций, 142 связи, из них 109 без структурных блокировок.
33 связи заблокированы; ещё 15 регистраций не разобраны. Неизвестные выражения,
неоднозначные регистрации и неразрешённые переопределения остаются в данных.

Проверки: 21 тест инструментов, 133 договора кандидатов, отсутствие новых
дублей относительно 37acdae1f. После повторного извлечения 224 набора правил
совпали по ключам с собранными TS-правилами; один набор является фрагментом.
Основные счётчики кандидатов не изменились: 3369 свойств, 2508 блокировок.

Это автоматизация распознавания связей и их передачи в результат генератора.
Исполняемые YAML-декларации коллекций по этому графу пока не выпускаются.
linked-structure не означает перенос семантики коллекции, проверку всего
XML или приёмку объекта. Ни одного нового флажка готовности не выставлено.
Rust и его нейтральный компилятор в этом блоке не менялись; новых обработчиков
предметных объектов нет. Самопроверка не является независимым ревью.


Следующий этап выполнен для массивов записей без контекста: добавлен выпуск
трёх связанных деклараций и проверка через Rust. См. collection-emission.md.
Все реальные коллекции пока блокируются по перечисленным там причинам;
первоначальный статус linked-structure по-прежнему не означает приёмку.
