# Приёмка GroupItemAuto

`GroupItemAuto` полностью описан декларациями
[`common.group-item-auto-use` и `common.group-item-auto`](../../../rust/declarations/common/group-item-auto.yaml).
Единственный смысловой признак — использование — имеет два обратимых
представления: отсутствующий `dcsset:use` даёт `[Авто]`, явное `false` даёт
`([Авто])`. `xsi:type` задаётся декларацией, а не обработчиком объекта.

Проверка [`migration.group-item-auto`](../../../rust/declarations/probes/group-item-auto.yaml)
выполняет XML → YAML → XML на обеих исходных фикстурах и двух вхождениях
реальной формы `ДинамическийСписок`, экспорт из нового YAML без XML-референса
и восстановление неверного `dcsset:use` либо чужого `xsi:type` через общую
аномалию. 33 проверки пробных скаляров, полный набор тестов компилятора и
Clippy прошли.

Приёмка относится к самостоятельному common-объекту. Коллекция группировок
`StructureItemGroup` и её владелец остаются отдельными незавершёнными
пунктами чеклиста.
