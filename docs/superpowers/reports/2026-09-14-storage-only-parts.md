# Части составного владельца без XML-маршрутов

Завершена поддержка вычисляемого скалярного поля непосредственно среди
разнородных частей владельца. Разделитель больше не требует фиктивного XML-пути.
Каждое такое поле получает часть с пустым списком XML-маршрутов; его смысловое
значение, зависимости, YAML и проверки работают через прежние общие интерфейсы.

XML-корень выбирается по первой физически размещённой части. XML-события,
проверки пересечения маршрутов и подсчёт физических контейнеров не включают
части без XML. При сборке результата они не добавляют узлы. Привязки входов
и отдельные порядки восстановления XML/YAML используются без изменений.

## Проверки

Расширена существующая матрица исполнения сгенерированного Rust:
вычисляемое поле, обычное поле и соседний вложенный объект; независимые ожидания
обоих направлений; смысловая аномалия вычисляемого поля и обратная проверка XML.
Декларация ставит вычисляемое поле первым, чтобы проверить выбор настоящего
XML-корня. Существующие фикстуры не изменялись.

Полный набор тестов компилятора, Clippy и архитектурная проверка Rust пройдены.
Все 61 сценарий коллекций пройдены; новых дублей относительно `37acdae1f` нет.
После уточнения ветвления по наличию XML повторена матрица сгенерированного Rust.

## Самопроверка

Изменены разделитель частей, генератор записи, переходник значения и сборщик
владельца. Все условия относятся к наличию XML-размещения; имён конкретных
объектов, свойств и common нет. Частный обработчик не добавлен. Это самопроверка,
не независимое ревью. Самостоятельный документ без XML-корня и вычисляемые
составные значения не объявляются поддержанными.

Полных новых common/владельцев этот блок не принимает: флажки чеклиста не меняются
(19/90 common). Следующая зависимость первого семейства — совместное описание
состояния расширенного объекта и коллекции PropertyState общими декларациями.
