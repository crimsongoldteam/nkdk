# Приёмка CalculatedFieldUseRestriction

`CalculatedFieldUseRestriction` — вложенная часть DCS. Четыре свойства
`field`, `condition`, `group`, `order` описаны одной YAML-декларацией
[`common.calculated-field-use-restriction`](../../../rust/declarations/common/calculated-field-use-restriction.yaml).
Каждое поле использует общую декларацию `common.boolean`; прежнее значение
по умолчанию `false` и порядок XML-полей заданы данными, без обработчика этого
объекта в Rust. Объект формы-владельца описан отдельной проверочной
декларацией, поэтому готовность всей DCS или формы этим пунктом не объявляется.

Проверка `calculated_field_use_restriction_round_trips_real_sparse_values`
использует три вложенные записи из неизменённой e2e-формы `ДинамическийСписок`.
Для каждой выполнены XML → YAML → XML без XML-референса и доказательство
исходной формы. YAML, записанный вручную со всеми четырьмя значениями,
восстанавливает XML. Тем же тестом проверены пустой элемент, явно записанное
`false` и неверное значение: общий механизм сохраняет различия и регистрирует
неверное значение как аномалию. Проверка схемы подтверждает допустимые русские
значения boolean и запрет неизвестного поля.

Первые прогоны схемы обнаружили ограничение компилятора для записи с отдельным
договором присутствия на уровне проверочного владельца. Перенос обычного
отсутствия в саму общую декларацию выразил тот же договор существующим языком;
новой ветви в компиляторе не потребовалось.

Приёмка этой вложенной части не засчитывает родительский
`DataCompositionSystem`, `CalculatedField` или их проектные маршруты.
