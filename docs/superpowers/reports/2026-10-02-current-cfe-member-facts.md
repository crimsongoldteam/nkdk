# Реквизиты из текущего YAML расширения

## Результат

Подготовка фактов для `InputByStringFields` читает первичный YAML основы и
расширения. Обычные типы и типы с пометками `!изменять` / `!проверять`
используют одну декларативную проекцию. Исходные XML- и сохранённые
YAML-источники остаются отдельными входными формами и не подменяют текущий
YAML в новых проверках.

## Причина сбоя и исправление

Значение текстового шаблона внутри выбора вариантов читалось правильно,
но зависимое выражение не получало его смысловые поля. Оно завершалось
ошибкой `Record field 0 is absent`. Сообщение о неизвестном `Синониме`
возникало позже, при запасной попытке прочитать исходную строку, и не было
первичной причиной.

Компилятор теперь предоставляет заимствованный доступ к полям текстового
шаблона через общий `RecordInput`. Выбор вариантов пользуется существующим
общим переходником. В компиляторе нет условий для конкретного объекта,
типов 1С или пометок расширения. Независимая проверка использует произвольные
текстовые поля и точное число `9007199254740993`.

Для чтения фактов параметры канонической декларации связываются с её
постоянными значениями по умолчанию. Условия сохраняются; отсутствующее
значение по умолчанию считается ошибкой сборки профиля. Внутренняя XML-форма
такой проекции служит чтению фактов и не заменяет публичное преобразование
`TypeDescription`.

## Проверяемые договоры

- Все восемь CF-владельцев используют полные неизменённые YAML-фикстуры.
- Все восемь семейств CFE проверяются для собственного и заимствованного
  объекта — всего 16 первичных CFE-примеров.
- Местный реквизит ссылочного типа перекрывает подходящий реквизит основы;
  `ВводПоСтроке` регистрирует аномалию и сохраняет XML.
- После удаления местного реквизита подходящий реквизит основы снова виден.
- Пометка `!проверять` сохраняет пригодность скалярного типа.
- Изменения выполняются в копиях входов; файлы фикстур не изменяются.

## Проверки

Независимая проверка компилятора наблюдалась сначала падающей, затем
проходящей. Прошли 15 проверок `contributions`, 6 проверок текстовых
шаблонов и 8 проверок генераторов/проекций. Отдельно прошли два реальных
контракта расширения: исходный справочник и перекрытие ссылочным типом.

Полный корпус из 93 контрактов прошёл. Также прошли 89 проверок ядра,
3 проверки выбора семейства, проверка типов TypeScript, Clippy ядра и
компилятора, архитектурные проверки Rust и TypeScript, проверка актуальности
обоих генераторов и поиск новых дублей относительно
`2af2f299ed8241eac78d4db46b4a8421efe2f8f7`.

Все 39 проверок проектных операций и полный `pnpm test` прошли. Полный запуск
выполнен вне песочницы после Rust-сборок. Существующие пропуски тестов остаются
пропусками и не учитываются как выполненные проверки. Сообщение запускателя
о превышении цели 10 мс не является доказательством производительности
конвертера.

Выполнена самопроверка изменённого механизма по
[правилам универсальности](../../../.agents/declarative-review.md): имена
метаданных остаются в декларациях и генераторе переноса; общий Rust-код
различает виды смысловых значений. Самопроверка не является независимым ревью.

## Границы приёмки

Это проверка источников реквизитов и типов. Источники состояний и числовых
свойств в этих случаях ещё могут использовать XML. Рабочее подключение
источников к проектным маршрутам остаётся следующим блоком; кандидатный
запускатель не доказывает его готовность.

Флажок `InputByStringFields` остаётся снят. Количество принятых common не
меняется. Скорость преобразования и пик памяти этим блоком не измерялись;
цель 10× не считается подтверждённой.


## Подготовка рабочих маршрутов: файл свойств внутри каталога

Внешние источники фактов теперь поддерживают `yamlFile` с тем же смыслом,
что обычные маршруты: например, `Справочник/Имя/Свойства.yaml`. Без этого
параметра сохраняется плоский вариант `Справочник/Имя.yaml`. Импорт XML
и размещение сохранённых внешних источников не меняются.

Прежде новая проверка получала ноль источников вместо одного. После изменения
прошли оба размещения, чтение изменённого первичного файла, загрузка
неизменяемой идентичности из сохранённых сведений и проектное обновление
фактов основы без повторного импорта XML. Усилены существующие проверки;
новых функций тестов для этих случаев не добавлено.

Прошли все 49 тестов Rust-приложения, Clippy приложения, архитектурные проверки
и поиск дублей. Полный `pnpm test` после изменения маршрутов прошёл.
Компилятор и декларации преобразования в этом блоке не менялись. Выполнена
самопроверка маршрутизатора: обработчик различает размещения, имена конкретных
объектов и common остаются в данных маршрутов.

Регистрация источников восьми семейств ещё не выполнена. Следующий пакет
источников должен сохранять общий договор индексов и отдельный ограничитель
объёма; основной пакет уже создаёт около 30 МиБ кода при бюджете 32 МиБ.
Этот замер не показывает пик памяти и не подтверждает цель 10×.
