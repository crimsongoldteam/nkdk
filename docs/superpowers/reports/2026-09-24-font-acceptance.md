# Common `Font`: проверка переноса

Дата: 2026-09-24. Граница приёмки — общий тип шрифта XML ↔ YAML; полные владельцы форм принимаются отдельно.

## Договор

- [`common.font`](../../../rust/declarations/common/font-reference.yaml) описывает стандартные шрифты стиля, элементы стиля, системные шрифты Windows и обычные параметры записи одной декларацией. Для ссылок на элементы стиля требуется подготовленный индекс с типом `Font`.
- Отсутствие `Font` отличается от пустого `<Font/>`, пустого имени и явно записанного `false`. `kind` и `ref` запасного варианта допускают отсутствие; исходная форма пустого элемента восстанавливается общей пометкой аномалии.
- Неверные булево значение, число и вид шрифта не прерывают импорт. Общий механизм сохраняет исходный XML и корректные соседние атрибуты. Структурный выбор при чтении пометки определяет вариант по её смысловой части; предметной ветки для `Font` в исполнителе нет.

## Проверка

- В неизменённом e2e-корпусе проверены все 28 вхождений `<Font>` в 15 XML-файлах: импорт, контрольное восстановление и экспорт без референса.
- Таблица Rust-проверок покрывает формы исходных TS-примеров, ожидаемый YAML, параметры, стандартные и собственные ссылки, неверный индекс, пустой элемент, три класса неверных атрибутов и сохранение соседних значений.
- Генератор схемы использует ту же декларацию. Переносчик распознаёт все 85 исходных применений `Font` в `rules.ts` как кандидатов; полная приёмка владельцев остаётся отдельной задачей.

## Результаты

Целевой пакет `nkdk-compiled-rules-font`, полный Rust workspace и `pnpm test`
прошли. Проверка типов, архитектурные ограничения и поиск новых дублей также
прошли. Все 236 договоров массового переноса прошли в 11 пакетах. По их
результату исправлена доступность вынесенных XML-путей для вложенного
проверочного модуля; обычный код преобразования не изменился.

Машинный реестр покрытия обновлён для XML/YAML и схемы; Enterprise оставлен вне
приёмки. Флажок common установлен, а полные владельцы форм остаются отдельной
задачей.
