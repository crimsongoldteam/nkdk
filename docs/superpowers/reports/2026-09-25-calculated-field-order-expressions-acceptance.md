# Приёмка CalculatedFieldOrderExpression

Один элемент описан в
[`common.calculated-field-order-expression`](../../../rust/declarations/common/calculated-field-order-expressions.yaml):
текст выражения, системное перечисление направления и общий boolean.
Та же декларация содержит список элементов, поэтому повторения и порядок
передаются общим механизмом коллекции. Имена XML, YAML, области имён и
отсутствие `orderType`/`autoOrder` задаются декларацией; частного Rust-кода
для этого объекта нет.

Rust-проверка берёт пару соседних `<dcssch:orderExpression>` из неизменённой
e2e-формы `ДинамическийСписок`. XML → YAML → XML восстанавливает оба элемента
в исходном порядке без XML-референса и без `!xml` для нормальных значений.
Проверены создание XML из нового YAML, отсутствие направления упорядочивания,
пустой элемент и неверный `orderType` с автоматической регистрацией аномалии.
Схема YAML выводится из тех же деклараций и допускает только значения
`Возр`/`Убыв` общего системного перечисления.

`CalculatedField` и весь `DataCompositionSystem` остаются отдельными
незавершёнными объектами; их полный маршрут этой приёмкой не объявляется.
