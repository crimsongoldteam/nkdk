# Коллекции плана видов характеристик

Подключены реквизиты и табличные части: собрано 64 из 65 исходных свойств.
Полная приёмка объекта не выполнена; флажок остаётся пустым.

## Изменения

Общий адаптер sourceOwnerCollections использует граф связей rules.ts,
существующий перенос обычных коллекций и составных элементов. Пути монтируются
в корень зарегистрированного владельца, без новых обработчиков Rust.
Табличные части сохраняют вложенные реквизиты, стандартные реквизиты,
внутренние типы, UUID и общие входы. Тип индексного входа восстанавливается
из уже типизированных частей составной декларации.

Исправлена общая граница индексных входов: поставщик остаётся на объекте
операции, вложенные значения получают типизированный вход без поставщика.
Нарушение области индекса воспроизведено и устранено.
Проверочные объекты содержат настоящий заголовок Name и коллекцию.
Генерация одиночной коллекции под with-attributes сейчас ограничена формой
declared-items; этот отдельный случай не объявлен исправленным.
