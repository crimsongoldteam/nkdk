# Приёмка common `Picture`

Декларации `rust/declarations/common/picture.yaml` и `picture-reference.yaml` описывают стандартную и общую картинки, файловый путь, ссылку `0`, ссылку по UUID, настройки прозрачности и прозрачный пиксель. Rust-компилятор выбирает вариант и восстанавливает XML из смыслового YAML без исходного XML-референса. Для неверной XML-формы общий механизм сохраняет аномалию `!xml`; соседнее свойство владельца остаётся доступным.

В `rust/crates/compiled-rules-picture/tests/picture.rs` проходят 13 проверок, включая все 154 значения `<Picture>` из неизменённых e2e-каталогов `cf` и `cfe`. Проверены оба направления, точные сокращённые YAML-формы, расширенные записи, отсутствие, пустой элемент, неверная прозрачность, неверная координата и неизвестная ссылка. `rust/crates/rule-compiler/tests/schema.rs` проверяет вывод схемы для краткой и расширенной YAML-формы.

Завершение относится к XML ↔ YAML. Enterprise-проекция исключена из согласованной цели проекта. Подключение полных владельцев учитывается их отдельными флажками.
