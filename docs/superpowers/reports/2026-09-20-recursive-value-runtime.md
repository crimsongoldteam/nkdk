# Исполняемая рекурсия значений — 20 сентября

## Результат

Рекурсивная YAML-декларация теперь компилируется в конечные Rust-типы и работает
в обоих направлениях. Повторное использование записи ссылается на один
канонический модуль, а значение на рекурсивной границе хранится через `Box`.

Физическое XML-поддерево временно переносится на виртуальный корень декларации.
Общий преобразователь читает или записывает его без знания имени владельца,
после чего корень возвращается на исходный путь. Код не содержит условий по
`MetadataValue`, именам свойств или тестовому типу дерева.

## Границы

- рекурсивный цикл обязан проходить через коллекцию;
- прямая обязательная рекурсия остаётся ошибкой связывания;
- конечное множество QName вычисляется с отсечением повторного рекурсивного
  ребра, поэтому вложенная декларация не вызывает переполнение стека;
- отсутствие коллекции и пустая коллекция определяются её декларацией;
- этот блок не завершает ни один common-объект и не меняет бинарный чеклист.

## Проверка

Синтетический объект содержит соседние узлы и вложенный лист. Для него проверены
XML → YAML, контрольное восстановление исходного XML, YAML → XML и повторный
импорт. Полностью прошли тесты `nkdk-conversion-core` и
`nkdk-rule-compiler`, а также Clippy этих пакетов с `-D warnings`.

Следующий шаг: выразить полный рекурсивный договор `MetadataValue` декларациями,
затем проверить использующий его `ChoiceParameters` и только после полной
приёмки обновить пользовательский чеклист.
