# Проверка единственного совпадения в декларациях

Реализовано выражение [one](../specs/2026-09-14-single-match-expression.md):
синтаксис, схема JSON, связывание типов и переменной элемента, генерация Rust.
Компилятор использует общий `select_matching`, который также обслуживает
заимствованный `select_unique`. Промежуточная коллекция не создаётся; второй
результат завершает поиск как неоднозначный.

Проверены пустота, отсутствие совпадения, совпадение после соседней строки,
повторы и отсутствующее поле соседней строки. Во всех примерах исходный XML
восстанавливается. Отдельно проверены ошибки типа входа, неизвестной переменной,
небулева условия и неполной записи YAML. Проверка ядра подтверждает передачу
ошибки условия и остановку после второго совпадения. Прежняя матрица позиций,
порядка и идентичности адресов сохранена.

Самопроверка архитектуры: предметных имён, условий по числу полей и копирования
контекста нет. Выбор варианта скалярного элемента общий для `each`, `exists`
и `one`; обнаруженный jscpd повтор устранён без исключений. Самопроверка не
заменяет независимое ревью.

Полные наборы ядра и компилятора прошли. После устранения повтора повторно
прошли генерация и выполнение Rust. Clippy всех целей, схема, ограничения
зависимостей Rust и проверка дублей прошли. Флажки common остаются 19/90:
булево условие не закрывает извлечение значения, распределение остатка или
полную интеграцию `PropertyState`.
