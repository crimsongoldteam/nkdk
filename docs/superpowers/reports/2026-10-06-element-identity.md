# Имя и идентификатор элемента из декларации

## Результат

Из всех семи проверенных регистраций `defineElementAsType` автоматически
собираются 14 YAML-фрагментов: преобразование имени/id и источник их индексов.
Файл: `rust/declarations/fragments/form-element-identities.generated.yaml`.
Команды: `pnpm migration:form-element-identities` и та же команда с `--check`.
Пути фрагментов относительные: при подключении их размещают внутри элемента.

Панель формы получает фиксированное имя `ФормаКоманднаяПанель` и id `-1`.
Панель таблицы получает имя таблицы плюс `КоманднаяПанель`; id восстанавливается
из индекса. Зарегистрированный вариант `CommandBar` сохраняется через индекс.
Неизвестное имя остаётся видимым:

```yaml
Имя: !xml/name СвояПанель
```

В Rust нет функций для AutoCommandBar и условий по именам элементов.
Имена, варианты и постоянные id взяты из регистрации; вычисления используют
обычные выражения декларации. Индексы разделены по компоненту, владельцу формы
и каноническому имени элемента. Источник читает XML-атрибуты, а сохранённый
снимок YAML позволяет подготовить тот же индекс без исходного XML.

## Общие исправления компилятора

- Конструктор записи внутри выбранного варианта теперь восстанавливает
  все её поля из объявленных выражений. Проверена запись из текста и точного
  числа. Частичных конструкторов и скрытых полей для конкретного класса нет.
- Вложенный скалярный путь получает проверки для своего фактического способа
  хранения; проверки внешнего владельца не подставляются вместо них.
- Объявленный скалярный тег записывается и выбирает вариант при чтении.
  Неверный или отсутствующий тег отклоняется. Вариант без тега продолжает
  работать в том же выборе; известный тег не требует повторного поиска по тексту.

Имена тегов не зашиты в компилятор: проверены `xml/name` и независимый
`договор`. Новый исполнитель деклараций во время преобразования не добавлен.
Необязательные/сокращённые поля записи в новом конструкторе остаются явно
неподдержанным сочетанием; это не скрывается под аномалией данных.

## Аномалии

Нормальный договор имени задаёт существующий common.metadata-name. Нарушение
само порождает `!xml/invalid`, сохраняя смысл и исходный атрибут.
Нормальный id должен быть целым текстовым числом; постоянный id также должен
совпадать с регистрацией. Отдельных обработчиков нарушений нет.

Отсутствующие атрибуты сохраняются общим механизмом `!xml/raw` с null.
Когда смыслового свойства нет, существующий механизм использует физические
XML-ключи `name`/`id`. Проверено восстановление обоих отсутствующих атрибутов,
а также отсутствие индексируемого id у панели таблицы; преобразование не падает.

## Проверки и границы

19 AOT-сценариев: реальные минимальные XML панели формы, панели таблицы и
контекстного меню; канонические/альтернативные/явные имена; неправильное имя,
неправильный и отличный от постоянного id; отсутствующие атрибуты; индекс из
сохранённого YAML; разделение владельцев и компонентов; независимая запись
из двух полей и соседний вариант без тега. Все сценарии проверяют восстановление
XML свежим преобразованием. Старые XML-фикстуры не менялись.

Регрессии: 12 скалярных сценариев, 12 сценариев параметров формы и
16 сценариев перечисления прошли. Node: 231 проверка. Compiler lib: 20;
generate: 11, существующий тест размера игнорируется, монолитный запуск
исполнения не выполнялся. Полный pnpm test вне песочницы, типы, три проверки
архитектуры, актуальность генерации и новые дубли прошли.
Рабочий `nkdk --test facts`: 46 проверок прошли; пересборка после изменения
генератора заняла 6 минут 45 секунд, исполнение проверок — 18,78 секунды.
Focused Clippy с `-D warnings` прошёл. Это не замер холодной сборки, пика
памяти или ускорения преобразования; цели 10× не объявляются достигнутыми.

Это приёмка общего договора, не полной панели или формы. Рабочее подключение
81 связи, общая нумерация новых элементов, дочерние коллекции и полная файловая
операция формы остаются задачами плана. Новые флажки завершённых объектов
не поставлены. Независимое ревью не выполнялось по запрету на субагентов;
самопроверка проведена по `.agents/declarative-review.md`.

кнопки в нейтральном Rust-коде или принимать только пустые группы.
