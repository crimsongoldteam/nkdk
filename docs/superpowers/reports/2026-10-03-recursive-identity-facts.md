# Сбор индекса из рекурсивных коллекций

## Результат

Общий компилятор собирает объявленные факты каждой строки, включая строки
вложенной рекурсивной коллекции. Вычисляемый родительский путь передаётся
через существующие привязки входов. Отдельного обработчика UUID, имени объекта
или XML-корня в компиляторе нет.

Если запись содержит собственный вклад в индекс и дочернюю коллекцию,
сборщик публикует собственный вклад и проходит дочерние строки. Явный обход
коллекции уже включает вклады строк; дополнительный автоматический обход
той же коллекции не создаётся. Существующая структура хранилища используется
повторно: новая стадия не парсит XML отдельно и не строит второй контекст.

## Проверка договора

Добавлена одна проверка в существующий набор `contributions.rs`:
`recursive_collection_contributes_each_path_once_with_bound_parent_context`.
Она защищает самостоятельный договор рекурсивного индекса:

- независимые XML и YAML содержат четыре записи на трёх уровнях;
- ожидаются именно `Root.A`, `Root.A.B`, `Root.A.B.C`, `Root.D` с заданными UUID;
- бюджет — четыре строки, поэтому повторная публикация обнаруживается;
- отсутствие UUID внутри дерева не позволяет публиковать индекс как готовый.
- оболочка с собственным текстовым полем и вложенными строками не теряет
  вклады потомков, даже если сама не публикует фактов.

Первый запуск упал при генерации: коллекция с вкладами строк ошибочно
направлялась в скалярный механизм. После исправления выбора общего механизма,
передачи привязок рекурсивного договора и обхода вложенных коллекций проверка
прошла. Во время проверки исправлен бюджет тестового словаря: он учитывает
отдельно ключ и значение, а не только число строк. XML-фикстуры не изменялись.

## Границы

Это готовность общего механизма, а не приёмка рабочего проектного маршрута.
Декларации Predefined ещё нужно связать с объявленным индексом, проверить
сбор UUID из настоящих файлов вместо заполнения тестового входа и подключить
подготовку фактов проекта. Автоматический обход вариантов выбора этой проверкой
не подтверждён. Он не объявляется поддержанным.

XMLRoot и другие объекты не отмечены завершёнными; счётчик common остаётся
56/90. Самопроверка универсальности выполнена; независимое ревью не выполнялось
по инструкции пользователя работать без субагентов.
