# Автоматическое извлечение состояний владельцев

`pnpm migration:extract` теперь сохраняет в `rules-extraction.json` не только
свойства из rules.ts, но и дополнительные регистрации PropertyState.

Проверены 224 объявления: их ключи, порядок и itemType совпадают с загруженными
правилами. Для 135 объявлений найдены дополнительные состояния. Сохранены
исходный порядок, связанные профили и относящиеся к типу изменения по версиям.
Например, у MetadataEnumerationValue переносчик видит базовую ссылку и синоним
с версии 8.3.8, а уведомление — с 8.3.15. Выбор текущей версии при извлечении
не выполняется: сведения о ранних версиях остаются доступными.

Регистрация читается из той же сборки propertyStateRules, которую подключает
metadataRules. Импорт TS выполняется только инструментом переноса; вызовов
преобразования и новых зависимостей Rust от TypeScript нет. Снимок хешей
исходников по-прежнему проверяется до чтения.

Генератор полного элемента коллекции блокирует неподключённую сборку состояний
и старые сведения без её инвентаризации. Кандидаты отдельных обычных свойств
сохраняются; результат не выдаётся за готового владельца.

## Проверки

- 27 проверок инструмента переноса: в том числе приоритет, сохранение изменений
  версий, чужие типы, отсутствующий профиль, дубли и запрет функций в данных.
- Полное извлечение: 224 keys-match, один fragment-without-properties.
- 61 проверка сгенерированных коллекций прошла.
- Проверка границ Rust прошла; новых дублей относительно `37acdae1f` нет.
