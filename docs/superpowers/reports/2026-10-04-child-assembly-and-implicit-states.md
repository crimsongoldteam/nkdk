# Вложенный реквизит и сокращённая история

## Проверенный результат

Общий `assembleSourceOwner` собирает вложенный объект без файлового XMLRoot.
Все33 свойства MetadataCatalogAttributeRules, включая UUID, проходят разбор,
связывание и генерацию Rust. Проверка использует настоящую выгрузку rules.ts
и общие зависимости, без подмены свойств коротким перечнем.

Пространство имён передаёт родитель. Подготовленные индексы сохраняют типы,
но вложенный объект не запускает их источники повторно. Файловая сборка
сохраняет источники. Это исправление проверено после воспроизведения
`index_missing`; имена и пространство имён ребёнка также изменены в матрице.

В двух исходных MultiState-примерах YAML содержит обычный `Тип`, без ключа
`Состояния`. Декларативный default восстанавливает Type → MultiState при
публикации индекса из YAML; обычная конверсия использует подготовленный индекс.
Нестандартная явно указанная история остаётся в YAML. Ожидаемые типы взяты
из существующих YAML-фикстур, исходные файлы не менялись.

Построитель истории принимает пары вариант/состояние из данных. Компилятор
распознаёт grouped-sequence как список; конфликт обычных селекторов списка
по-прежнему отклоняется. Сравнение истории с условным одноэлементным default
не создаёт промежуточную коллекцию. Избыточные блоки Rust исправлены в общем
генераторе, предупреждения не отключались.

## Граница приёмки

33 обычных свойства скомпилированы, а Type/история двух примеров проверены
нативно. Полный XML-реквизит с этими33 свойствами и профилем расширения
вместе ещё не принят. Следующий шаг — связать сборку со всеми состояниями,
основной конфигурацией и родительской коллекцией, затем проверить полный XML.
Канонический источник этого проверочного профиля не разрешает считать любой
обычный список типов MultiState: нужно учитывать контекст и явную историю.

Самопроверка универсальности выполнена; это не независимое ревью.
