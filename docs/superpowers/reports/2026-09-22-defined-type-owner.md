# Приёмка MetadataDefinedType

`MetadataDefinedType` преобразуется рабочей операцией Rust по YAML-декларации.
Обычный и расширенный профили выбираются общим маршрутом без ветки по имени
объекта. Источники UUID и `InternalInfo` извлекаются из XML при импорте,
сохраняются как YAML-снимок в корне компонента и используются при экспорте
после повторного открытия проекта. Исходный XML на экспорт не передаётся.

Проверены оба объекта из `e2e/fixtures/xml/cf/DefinedTypes` и оба из
`e2e/fixtures/xml/cfe/all-extension/DefinedTypes`. Созданные YAML-документы
совпадают по данным с неизменёнными e2e-эталонами. После обратного экспорта
полные XML-деревья совпадают по пространствам имён, атрибутам, значениям и
порядку; различаются только префиксы пространств имён и форматирующие пробелы.
Незарегистрированный язык синонима сохраняется автоматически как аномалия и
восстанавливается обратно в исходное XML-дерево. Отсутствующий снимок не
заменяется молча пустыми индексами и не приводит к частичной публикации.

Проверки: `cargo +1.98.1 test --workspace --quiet`, строгий Clippy для
`nkdk`, `pnpm test`, 165 договоров переноса, 133 подключения, 87 коллекций,
архитектурные проверки и `pnpm duplicates -- --base 9c6028729`.
Критерий 10× для всего проекта этот результат не подтверждает.
