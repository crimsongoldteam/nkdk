# Значение перечисления: приёмка рабочей операции Rust

Дата: 14 сентября 2026 года. Граница: `MetadataEnumerationValueRules` в полной
коллекции `ChildObjects/EnumValue`, включая основную конфигурацию, собственные
и заимствованные значения расширения. Родительское перечисление и обнаружение
всех файлов проекта в CLI остаются отдельными задачами.

## Что подключено

`rules.ts` автоматически преобразуется в три связанные YAML-декларации;
рабочий вход — `metadata.enumeration-values`. Выпуск выполняет
`tools/rules-migration/src/enum-values-operation.mjs`; режим `--check` входит
в проверку переноса и обнаруживает устаревшие правила, декларации и ожидания.

Проверяются целые коллекции из исходных e2e XML и целые блоки «Значения»
из независимых YAML-фикстур. Исходные пространства имён MDClasses сохраняются;
XML-фикстуры не изменены. Имя, UUID, синоним, комментарий, базовая ссылка,
InternalInfo и PropertyState включены в оба направления преобразования.
Сокращения сохраняют соседние строки, повторы и порядок; экспорт выполняется
без XML-референса и с независимо подготовленным контекстом.

`nkdk::facts::prepare` подготавливает собственные и базовые идентификаторы,
а также объявленные индексы имён и UUID членов владельца. Их содержимое
проверяется по отдельному перечню XML-идентичностей с контролем хешей.
`nkdk::conversion::prepare` выполняет преобразование через рабочий каталог.
Неизвестная роль владельца блокирует автоматический выпуск.

## Совместимость и аномалии

Режим совместимости читается из исходного Configuration.xml. Ограничения
выводятся из существующих таблиц режимов и последовательности изменений
регистрации свойств; специальных проверок версий в Rust нет. Проверены границы
8.3.7/8.3.8 для заимствования и 8.3.14/8.3.15 для Notify, русское имя режима,
DontUse и собственный объект на старом режиме.

Неподдержанное состояние сохраняется как выведенная из ограничения аномалия.
Если у значения уже есть смысловой тег, общий механизм использует оболочку
`!xml/invalid` с единственным `$значение`, сохраняя исходный тег внутри.
Это не `$xml` и не обработчик конкретного объекта. Проверены отсутствие значения,
пустая строка, обычный текст, ошибочная оболочка и избыточная отметка аномалии.
[Договор](../specs/2026-09-14-compatibility-and-scalar-annotations.md).

Синоним EnumValue зарегистрирован как `plain`, поэтому обычный синоним
не получает `!изменять`. Избыточная служебная строка сохраняется существующим
механизмом исходной XML-формы. Для существующего тега `!проверять` применяется
ранее внесённая локальная поправка yaml-rust2 с сохранёнными лицензиями.

системного линковщика о размере таблицы разворачивания стека.
