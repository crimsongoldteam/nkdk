# Приёмка StandardAttributeDescription

`StandardAttributeDescription` полностью перенесён в YAML-декларации и рабочую
Rust-сборку. Для всех владельцев используется одна декларация
`metadata.standard-attribute-owner`; списки членов, YAML-имена, имена в путях,
форма пустого значения и политика `FillValue` передаются строками профиля.
Предметных веток по виду владельца в Rust-компиляторе нет.

Полная запись собирается из 27 исходных свойств. Именованная коллекция переводит
ключ YAML и XML-атрибут `name` по одной таблице, сохраняет порядок и повторы,
восстанавливает сокращённые канонические строки и отличает `{}` от `null` по
данным профиля. `LinkByType` использует тот же профиль для имён стандартных
реквизитов в пути; `ChoiceParameterLinks` сохраняет буквальное написание пути.
Неизвестные или недопустимые значения проходят общий механизм аномалий и не
останавливают преобразование.

Переносчик статически извлекает правила из `standardMembers.ts`, включая
`Array.from`, целочисленные выражения и `flat`. Получены профили для 14 семейств
и 22 видов владельцев, в том числе 50 пар субконто регистра бухгалтерии.
Из проверенного каталога автоматически выпускается одна рабочая декларация в
[`standard-attributes.generated.yaml`](../../../rust/declarations/candidates/standard-attributes.generated.yaml).

Приёмочная матрица содержит по одному неизменённому e2e-владельцу каждого
семейства: задача, регистр сведений, план обмена, перечисление, журнал
документов, документ, планы видов характеристик и расчёта, план счетов,
справочник, регистр расчёта, бизнес-процесс, регистры накопления и бухгалтерии.
Для всех 14 случаев проверены XML → YAML, YAML → XML без XML-референса и точное
совпадение независимых YAML-событий. Отдельный тест рабочего каталога повторяет
эти случаи через `metadata.standard-attribute-owner`; проверка генератора
подтверждает, что отдельных деклараций справочника и документа больше нет.

Полные владельцы принимаются отдельно: завершение этого common означает, что
их коллекция стандартных реквизитов уже исполняется единым Rust-договором, но
не означает готовность всех остальных свойств документа, справочника или
регистра.
