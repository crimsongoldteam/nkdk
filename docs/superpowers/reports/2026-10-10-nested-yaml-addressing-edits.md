# Адресация: аудит состояния и проверка правок YAML

Проверочный запускатель теперь поддерживает `yamlEdits`: точные замены в
полученном YAML и независимые ожидаемые замены в исходном XML. Число вхождений
задаётся явно; отсутствие или неожиданное повторение текста завершает проверку
ошибкой. Это код проверки, он не выполняется в рабочем преобразователе.

При каждой правке XML экспортируется обычным Rust-кодом; готовые внешние файлы
передаются существующим переходником. Сравнение XML остаётся строгим, включая
QName, соседние узлы, значения и служебные UUID. Ожидаемый результат не получают
из самого экспорта. Контекст индексов готовится один раз для группы правок.

## Что проверено

Три прежних реальных примера FormAttributeRules.dynamicList получили19 правок:
восемь границ и обычный сосед у полного списка и списка с неверным булевым
значением; отдельная правка ManualQuery у минимального списка. Декларации и
число примеров46 остаются прежними; дополнительные функции тестов для каждого
свойства не создавались.

| Граница | Изменение |
|---|---|
| Поля | ПутьКДанным первого поля |
| ВычисляемыеПоля | Текст выражения |
| Параметры | Заголовок именованного параметра |
| УсловноеОформление | UUID пользовательской настройки |
| ПараметрыДанных | UUID пользовательской настройки параметра |
| Отбор | Представление пользовательской настройки |
| Группировка | Поле первого элемента, сохраняя последующие элементы |
| Порядок | Поле второго элемента, сохраняя первого соседа |

В полном и повреждённом примерах также меняется АвтоЗаполнениеДоступныхПолей.
В соответствии с прежним договором значение по умолчанию задаётся отсутствием
поля YAML; каноническая XML-запись такого изменённого поля также может исчезнуть.
Это не потеря соседнего XML-состояния. Первоначальная ошибочная ожидаемая форма
с явным true была отвергнута строгой проверкой; преобразователь не ослаблялся.

## Аудит старого индекса

DCS-правила не содержат свойств `_id`/`_uuid`, автоматически собираемых старым
collectConfigurationIndexIdentityFromXML. Единственный собственный DCS-описатель
configurationIndexValueFromXML (MetadataDcsMetadataValue) пуст.
UserSettingsID сохраняется как смысловая строка. Для этих сведений второй индекс
не добавлен; проверены две разные UUID в разных поддеревьях.

Зависимые импортируемые свойства регистрируются отдельным набором. Для
FormAttribute найден valueType, относящийся к СписокЗначений; это не регистрация
внутренних DCS-свойств. Идентичность самого FormAttribute и состояние полной
формы остаются отдельной границей. По этому аудиту нельзя объявить весь снимок
проекта ненужным или удалить восемь исходных требований из отчёта.

## Проверки

- Нейтральный проверочный переходник: RED→GREEN, точные замены и отрицательные
  границы; rustc -Dwarnings,1/1.
- Проверка семейства: RED без yamlEdits → GREEN;71 тест переносчика прошёл.
- AOT: три реальных договора и все19 правок прошли. Новый код только в общем
  запускателе и данных проверки; рабочий компилятор/конвертер не изменены.
  Повторная сборка запускателя заняла12,66 с, каталог повторно не генерировался.
- Общий Rust-код адресов и компилятор выражений проверены существующими тестами.
- Публикация воспроизводима:17 деклараций/46 сценариев,6 библиотечных деклараций.
- Архитектурные проверки и поиск новых дублей прошли; XML-фикстуры не изменены.
- Полный pnpm test вне песочницы завершился с кодом0 отдельно от Rust-сборок;
  журнал /tmp/nkdk-address-full-test.log. Два прежних MCP-сценария с внешней
  инфобазой штатно пропущены, ограничения времени не менялись.

## Остаток

Это приёмка поведения после редактирования YAML и аудит источников состояния.
Автоматическая передача адресов через compose/projection/choice к потребителям
сохранённых снимков ещё не реализована и не объявляется готовой.
Общий механизм для оставшихся потребителей, проверка повторного открытия полной
операции и её приёмка остаются в плане. Флажок DynamicList не поставлен;
счётчик common56/90 не изменён. Замера ускорения либо цели10× этот блок не даёт.

Самопроверка: предметные изменения записаны только в данных реального примера.
Общий Rust-запускатель знает точные замены и строгое сравнение XML; имён свойств
DynamicList и отдельных common в нём нет. Независимого ревью не было.
