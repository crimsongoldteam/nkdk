# Приёмка поля набора данных СКД

Принят DataCompositionSchemaDataSetField в границах common: все 15 исходных
свойств, обычное поле, папка и вложенный набор данных. Полная схема СКД
и её коллекции принимаются отдельно. Чеклист по флажкам разделов: 56/90 common, 23/27 вложенных частей.

## Декларация и общие исправления

Переносчик переводит проверенные по хешу условия rules.ts в существующие
выражения равенства и «или». Условие коллекции получает её собственное
описание отсутствия; исполнение Rust не знает названий видов СКД.
Рабочие YAML и проверочные случаи воспроизводятся из исходной регистрации.

Исправлены три общих механизма:

- Схема строки со словарём XML QName перечисляет допустимые смысловые значения.
- Отсутствующая коллекция без отдельного контейнера не захватывает корень
  владельца и его соседние поля как собственную пустую XML-форму.
- Проекция атрибутов сохраняет пространства имён значений QName; восстановление
  порядка не теряет тип при изменении XML-префикса.

Последние два исправления проверены нейтральной записью с коллекцией и QName
как в обычной генерации, так и через общие AOT-модули. Тест использует
существующие декларации строки и списка вместо копирования их YAML.
Специальные обработчики аномалий поля набора данных не добавлены.

## Проверки

Исходная проверка полноты обнаружила 12 вместо 15 свойств. После переноса
условий все 15 собираются. Отдельно воспроизведены ошибка восстановления
QName после перестановки и принятие неизвестного вида схемой; исправления
закрывают эти расхождения.

Приняты 12 независимых случаев: три вида, YAML без вида, доступные значения,
оформление, все свойства, переставленные XML-соседи, неверное булево,
отсутствующий и неизвестный XML-вид, лишнее поле папки. Проверены оба
направления без XML-референса и восстановление аномалий с читаемыми соседями.
Исходные XML-фикстуры не изменены; дополнительные свойства проверяются в копии.
Порядок ключей старых ожидаемых объектов согласован с порядком регистрации
rules.ts; значения и порядок списков сохранены.

- Рабочая Rust-матрица: 12/12.
- Общая регрессия, вложенные аномалии и схемы: 32 теста, из них 30 схем.
- Тесты переносчика: 50; семейные проверки включены также в полный pnpm test.
- Полный pnpm test завершился с кодом 0; имеющиеся пропуски тестов сохранены.
- Clippy с запретом предупреждений, обе проверки архитектуры, проверка новых
  дублей относительно 91a01277cbd10ccebd70bb0b4e7a32886dcf090f и diff --check прошли.
- Повторная публикация рабочих файлов не обнаружила отличий.

## Скорость и границы результата

Пять чередующихся групп по 500 вызовов обычного полного поля, без параллельной
сборки: XML → YAML до 0,226063 мс, после 0,226473 мс; YAML → XML до
0,043585 мс, после 0,043749 мс. Диапазоны перекрываются. Сравнение проверяет
последнее исправление проекции QName, а не весь перенос с TypeScript.
Это debug-замер; цель 10× и производительность release им не подтверждены.

Самопроверка: предметные условия остались в декларациях и проверяемом
переносчике. Общий компилятор работает с присутствием коллекций, проекциями
и QName без условий по именам объектов. Область сохранения аномалии выбирает
общий механизм: отдельное поле либо весь владелец при перестановке соседей.
