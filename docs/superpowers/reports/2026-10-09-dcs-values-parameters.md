# Проверка значений и параметров СКД

Пакет принят в границах трёх common-договоров; все три флажка установлены.
Итог: **59/90 common**, **19/27 вложенных частей**. Полные формы и их индексы
принимаются отдельно. Нижние разделы фиксируют последующие проверки;
ранние разделы сохраняют историю выявленных ошибок.

## Подтверждённый результат

- Один генератор переносит 11 неизменённых исходных XML/YAML-примеров
  `dcsMetadataValue`, охватывающих девять профилей. Все 11 прошли
  XML → YAML → XML без лишних аномалий через подготовленные общие AOT-модули.
- Исправлен выбор договора Field: используется готовый
  `common.dcs-parameter-field-value`. Поле `Реквизит1` остаётся в YAML
  `Реквизит1`; `.Реквизит1` относится к отдельному договору поля фильтра.
  Проверка выбора воспроизвела ошибку и прошла после исправления.
- Источники индексов оформления и системных перечислений общие с рабочим
  каталогом. Проверочные генераторы используют один вспомогательный источник.
- Подготовлены 14 случаев параметров. Два свойства, отсутствующие в e2e,
  добавляются в копию примера в памяти: `functionalOptionsParameter`
  и `denyIncompleteValues`. Обычные случаи и эти свойства проходят.
- Отдельная диагностическая матрица из 14 случаев подтверждает сохранение
  исходного XML, если разрешить существующую внешнюю границу raw.
  Это **не** выполнение строгих требований к локальности аномалий.

## Что остаётся исправить

Строгая матрица параметров обнаружила два случая расширения границы аномалии:
лишний параметр выбора и неверное вложенное число. Вместо пометки значения
используется raw всей коллекции параметров. XML восстанавливается, но смысловая
часть YAML получается менее полной и читаемой. Опубликованные проверки требуют
локальную границу; их ожидания не заменены текущим поведением.

Временная диагностика выполнена только в игнорируемых подготовленных исходниках
и затем удалена. Для неверного вложенного числа причина установлена: восстановление строки
искало её от корня YAML вместо положения текущей вложенной коллекции.
Общий читатель теперь сохраняет это положение (16 байт на читатель), а дерево
выбранного значения строится только при восстановлении аномалии. На реальной
матрице первые 13 случаев, включая неверное число, прошли.

Лишний параметр выбора выявил дополнительный дефект: уточнение соседнего
отсутствующего поля создавало для него конверт и меняло условные атрибуты
родителя. Исправлена общая обработка отсутствующего варианта; тест сначала
воспроизвёл ошибку, затем прошёл с обычной и общей AOT-генерацией. Пустой
присутствующий XML-элемент не смешивается с отсутствием.

Третья причина также исправлена: подготовка дочернего варианта удаляла
атрибут выбора даже тогда, когда его принимает сама дочерняя декларация.
Теперь применяется уже имеющаяся проверка владения атрибутом.

Чистая строгая матрица параметров прошла **14/14** через общие AOT-модули.
Для лишнего параметра выбора используется явный элемент списка `- !xml/raw`:
он сохраняет первое смысловое значение, второй XML-элемент, соседние поля
и исходный порядок. Проверки требуют точную границу и читаемых соседей;
внешним конвертом их заменить нельзя. Приёмка всего пакета ещё не завершена:
остаётся typedValue и дополнительные состояния профилей.

Для `dscMetadataTypedValue` 11 независимых исходных примеров перенесены без
исполнения TypeScript и прошли Rust AOT в обе стороны, без аномалий.
Поддержаны обычные варианты, строки с апострофами и пустая строка, пустой
список значений, Order и стандартная дата начала. Замкнутый каталог содержит
17 деклараций и создаёт 10 общих пакетов; локальная пересборка заняла 1,34 с.
Остаются альтернативная XML-ссылка, отсутствие, Undefined, массивы и отклонения.
Поэтому флажок полного перехода не установлен.
Также остаются дополнительные примеры чтения `dcsMetadataValue`, пустые
состояния, неверные значения и включение всего пакета в рабочий реестр.

### 9 октября: ссылки и обычные последовательности typedValue

Общая AOT-проверка прошла **15/15**: 11 неизменяемых исходных примеров,
старый `xr:DesignTimeRef`, каноническая ссылка, последовательность из трёх
значений с повтором и отсутствие всего свойства рядом с сохранённым соседом.
Последовательности используют отдельные декларации атома и списка; их
подключение проверяется на объекте с соседним полем. Это ещё не полная
приёмка `dscMetadataTypedValue`.

Ссылки имеют один смысловой договор. Общий словарь корней программно
проецируется в русскую каноническую XML-запись; прежние английские корни и
`EmptyRef` входят в существующий `accept`. Старый тип и написание остаются
в локальном `!xml/raw`; смысловое значение проверяется отдельной точной
строкой, а обратное восстановление — независимой проверкой XML. Варианты
с пересекающимися бесконечными языками не добавлялись.

Исправлены общие сочетания:

- автомат вложенного текстового выбора учитывает принимаемые XML-написания
  словаря; нейтральный случай `off` сначала воспроизводил неверный выбор;
- текстовый шаблон читает и записывает часть, которая сама является выбором;
  запись возвращает текстовую часть без повторного оформления YAML;
- проверки вложенных вариантов используют имя реально созданного типа,
  а доступ к полю сохраняет его смысловой тип вместо приведения к строке;
- текстовый доступ возвращает ошибку типа для нетекстового поля, при этом
  общий доступ к смысловому полю сохраняет вложенный выбор и его ограничения.

Нейтральная проверка дополнена шаблоном с вложенным словарём и резервным
ограниченным именем. Обычная генерация прошла; реальные 15 случаев прошли
через общие AOT-пакеты. Проверка вложенных аномалий остаётся зелёной на обоих
способах генерации. Clippy без предупреждений, проверки архитектуры и дублей
прошли. Полная проверка проекта выполняется отдельно без Cargo.

Остаются пустые позиции `{}`/`xsi:nil`, QName `Undefined` с произвольным
префиксом, дополнительные отклонения профилей и общая рабочая публикация.
Пустой искусственный XML-контейнер нельзя считать отсутствующим свойством:
проверка отсутствия теперь сохраняет отдельный сосед и исключает только
само необязательное свойство. XML-фикстуры не менялись. Все три флажка пакета
остаются снятыми; общий чеклист **56/90** и **19/27** не изменён.


Финальный повтор полного `pnpm test` завершился с кодом 0
(`/tmp/nkdk-dcs-slots-full-pnpm-final.log`). Первая попытка этого повтора
загрузила прежнюю проверку генератора, требующую `<value>` во всех случаях;
она исправлена: требование относится к исходным значениям, а отсутствие
проверяется отдельно вместе с сохранённым соседом. Все девять проверок
источников прошли. Нейтральный тест также подтверждает раннее отклонение
недопустимого атрибутного выбора внутри текстовой части существующей проверкой
языка; повторного обработчика или проверки для объекта СКД не добавлено.


### 9 октября: пустые позиции, Undefined и рабочее подключение typedValue

Матрица typedValue расширена до **22 случаев** и прошла через общие
AOT-модули. Добавлены `xsi:nil` между соседями, экспорт `{}` без выдуманного
XML-узла, `Undefined` с двумя префиксами, составная последовательность и два
составных одиночных значения. Пустая смысловая позиция внутри raw-конверта
подразумевается, поэтому отдельное `$значение: {}` не записывается.
Независимый XML-контроль проверяет восстановление исходной формы.

Компилятор поддерживает пустую проекцию и выбор значения внутри элемента
списка общими механизмами. Числовой, строковый и составной варианты больше
не требуют разных способов включения в коллекцию. Для повторяемого элемента
поддержан существующий `xml.path: []`: граница элемента выводится из пути
свойства. Попытка переноса до исправлений воспроизводила ошибки генерации
пустой проекции и открытого списка; после исправлений матрица прошла.

Рабочее имя `DcsMetadataTypedValue` зарегистрировано как
`common.dcs-typed-values`. Проверочный владелец теперь получает тип и XML-путь
через обычный `mapProperty`, поэтому проверяются и автоматический перенос,
и фактическое преобразование Rust. YAML-проверочный каталог и матрица
обновлены генератором. Новых обработчиков по имени класса в Rust нет.

После этих общих изменений повторно прошли 14 случаев параметров и 11
случаев девяти профилей значений. Нейтральный тест локальных аномалий дополнен
пустой проекцией и прошёл с обычной и общей AOT-генерацией. Повторяющиеся части
его YAML-описания вынесены в два общих шаблона; новых дублей нет. Clippy и
проверки архитектуры прошли. Полная проверка проекта выполняется перед
изменением флажка typedValue. Весь пакет из трёх common ещё не объявлен готовым.


Повторный замер без параллельной сборки: пять чередующихся групп по 500
преобразований теми же исполняемыми файлами и тем же реальным параметром.
Медианы debug-сборок XML → YAML: 1,929 → 1,937 мс; YAML → XML:
0,376 → 0,374 мс. Различия меньше 0,5%, диапазоны групп пересекаются.
Замер не подтверждает отсутствие замедления в release и не подтверждает 10×.
Результат сохранён в рабочем журнале проверки исполнения плана.


Финальная полная проверка завершилась с кодом 0
(`/tmp/nkdk-dcs-typed-complete-pnpm.log`). Clippy без предупреждений, обе
архитектурные проверки и проверка новых дублей прошли. `dscMetadataTypedValue`
принят и отмечен в двоичном чеклисте: **57/90 common**, **19/27 вложенных частей**.
Два других common пакета остаются неотмеченными; приёмка typedValue не означает
полной приёмки их владельцев, всего проекта или достижения цели 10×.


### 9 октября: дополнительные состояния metadataValue

Общая матрица расширена с 11 до **21** случая. Включены все 17 исходных
XML-примеров `dcsMetadataValueFromXMLFixtures`, форматированная строка из
существующих тестов, число в профиле Field, неверное булево и лишний параметр
выбора. Изменённые примеры создаются в памяти; исходные XML не редактируются.

Пустой LocalStringType выявил ошибку `yaml.choice-form`: вложенная декларация
писала пустое значение, которое её выбор не мог прочитать. В существующей
ссылке на I8nText включён `preserveEmptyXML`; нормализация и сохранение исходной
формы выполняются уже имеющимися общими механизмами. Новый обработчик Rust
и новые условия по именам common не добавлены. До поправки неизменённая
фикстура падала; после поправки вся матрица **21/21** восстанавливает XML.

Ожидания дополнительных примеров учитывают принятые common-договоры:
неразрешённая ссылка Color остаётся явным текстом; написание `v8:UUID`,
пустой LocalStringType и исходный Type/Undefined сохраняются локальным
`value: !xml/raw`. Для UUID и Undefined отдельно проверено читаемое смысловое
значение. Это не замена отсутствующего преобразователя сохранённым XML.

Обновлены воспроизводимые рабочие декларации и матрицы metadataValue и
параметров. Проверки архитектуры и новых дублей прошли; полная повторная
приёмка параметров и полный набор проекта ещё выполняются. Проверочный
исполняемый файл параметров после Cargo оказался неисполняемым файлом данных;
результат компиляции не засчитан как выполненный тест.
