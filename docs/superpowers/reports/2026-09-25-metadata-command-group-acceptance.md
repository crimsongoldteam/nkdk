# Приёмка common `MetadataCommandGroup`

[`common.metadata-command-group`](../../../rust/declarations/common/metadata-command-group.yaml) объединяет системные группы команд из общего перечисления и ссылку `CommandGroup.<имя>` на объявленную группу. Декларация задаёт XML/YAML-представления, а индекс корней проверяет существование пользовательской группы. Отдельного обработчика конкретной группы в Rust нет.

В матрице `path_lexicons_preserve_the_existing_bidirectional_vocabulary` 11 неизменённых XML/YAML-пар из `cf` и `cfe` проверяются на ожидаемое русское имя `Группа`, XML → YAML, YAML → XML без XML-референса и восстановление исходной формы. Они охватывают системную и пользовательскую группу, обычные и заимствованные команды. Отсутствие, пустой элемент и неизвестная группа также проходят обратную проверку; неизвестная ссылка автоматически сохраняется как аномалия. YAML-ссылка на несуществующую группу получает диагностику `metadata.target-missing`.

Полная сборка владельца `MetadataCommand` с остальными его свойствами остаётся отдельной задачей. Приёмка относится к собственному common-договору.
