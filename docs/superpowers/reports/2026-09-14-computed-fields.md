# Вычисляемые поля без XML-узла

Декларация может описывать смысловое поле без XML-пути. Например, `left`
при импорте берётся из `right`, в YAML присутствуют оба значения, а XML
содержит только `Right`. При чтении YAML `right` может восстанавливаться
из `left` по своему правилу. Новая конструкция языка не добавлялась.

Генератор использует общий порядок вычислений и обычные преобразователи
скаляров. Отсутствие XML-размещения явно хранится как `None`. Для такого поля
не создаются XML-маршрут, состояние чтения XML и ячейка подготовки XML-дерева.
Обычная смысловая отметка `!xml/invalid` выводится из ограничения, без `$xml`.

## Проверенная область

Расширена существующая матрица `rule-compiler/tests/generate.rs`:

- обычная запись: независимые ожидания обоих направлений;
- коллекция с ключами: два элемента, восстановление от ключа, обратная проверка;
- вложенная запись составного владельца: независимый сосед сохраняется;
- недопустимое вычисленное значение: отметка из ограничения и восстановление XML.

Существующие XML-фикстуры и тесты не удалялись и не менялись. Полный набор
тестов компилятора прошёл; после сокращения XML-состояния повторена матрица
исполнения сгенерированного Rust. Clippy, архитектурная проверка Rust и поиск
новых дублей относительно `37acdae1f` пройдены.

## Самопроверка универсальности и ограничения

Изменён генератор записей и его читатель XML. Условие относится только к
наличию XML-размещения; имена common, объектов и свойств не проверяются.
Коллекция и составной владелец используют тот же преобразователь записи.
Это самопроверка, не независимое ревью.

Следующим блоком реализована также отдельная часть только со смысловыми полями
непосредственно в разнородном владельце; см. [отчёт о частях без XML](2026-09-14-storage-only-parts.md). Полностью вычисляемый самостоятельный XML-документ без
объявленного корня также не поддерживается.

Новый common или владелец полностью не принят: бинарный чеклист остаётся
без новых флажков, 19/90 common. Это не завершение всего перехода на Rust
и не подтверждение цели 10×.
