# Группа команд, общий модуль и бот: полная приёмка

Приняты `MetadataCommandGroupRules`, `MetadataCommonModuleRules` и
`MetadataBotRules`: 11, 16 и 10 свойств автоматически перенесены из
`rules.ts` в YAML-декларации и подключены к рабочему каталогу Rust.
Неподдержанных свойств и недостающих индексов нет. Обработчики этих
объектов в компилятор или оркестратор не добавлялись.

Общая матрица файловых объектов проверяет 75 неизменённых XML CF/CFE,
включая 26 новых: группа команд — 2/4, общий модуль — 6/10, бот — 2/2.
Проверены независимые YAML, восстановление XML после удаления источника,
контекст основы и расширения, создание новых объектов и стабильность UUID.
Для модулей копируются реальные файлы фикстур; обратный экспорт сохраняет
как их содержимое, так и отсутствие. Общий маршрут приложения проверяет
41 файл CF и 61 файл CFE с обратным восстановлением XML.

Пустые картинки сохраняют существующий договор. Явный пустой XML-default
передаёт декларативный параметр `allowEmpty`; смысловой пустой вариант
находится по описанию декларации, без жёстко заданного имени. Основной
объект сокращает default, расширение сохраняет явную пустую картинку.
Компилятор применяет сокращение на уровне выбора один раз, без повторного
сокращения внутри выбранного значения. Общая проверка использует также
другие имена полей/вариантов и постоянное непустое текстовое представление.

В неизменённой фикстуре `БотВсеСвойства` расширение указывает изменение
модуля, но файла модуля нет. Общий договор ресурса автоматически сохраняет
это отклонение как `!xml/invalid`; старый YAML не содержал этой пометки.
Ожидание строится из исходной истории XML и доказанного отсутствия файла,
независимо от конвертера. Тест сравнивает все остальные поля, всю историю,
исходный XML и отсутствие файла. Проверка ресурса не ослаблена. Её тестовые
ожидания объединены с уже существующими случаями WebSocket и XDTO.

Новые декларации принадлежат отдельному пакету `compiled-rules-owners-3`.
Настройка `declarationFile` определяет только размещение; одинаковые общие
декларации выпускаются один раз, несовместимые повторы отклоняются.
Пакет создаёт 5 227 525 байт Rust-кода при неизменном лимите 8 МиБ.
Точечная проверка выбирает текущие операции и их зависимости: около
6,8 МБ вместо 13,9 МБ при включении всех файловых объектов. Это размеры
исходников, а не замер пика памяти или подтверждение цели 10×.
