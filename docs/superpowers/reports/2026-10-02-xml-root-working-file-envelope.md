# XMLRoot: рабочая привязка оболочки

## Выполнено

Общий переносчик получает корень, пространства имён и постоянные атрибуты
из исходного XMLRoot и соединяет их со смысловой декларацией. Он не содержит
перечня типов метаданных. Для AdditionalIndexes профиль описывает список
и его владельца; корень и версия выводятся из rules.ts. Полученные рабочие
декларации семантически совпадают с прежними принятыми декларациями.

Обычная оболочка подключена тем же способом к генератору DocumentJournal.
Выходная декларация журнала не изменилась; изменение исходного атрибута
проверено отдельным случаем привязки. Квалифицированный xsi:type передаётся
как QName, а не как строка, зависящая от XML-префикса.

## Проверки

- Пять проверок переносчика: реальные исходные правила, изменения корня и
  версии, неизменность шаблонов, отказ для неподдержанных соединений,
  пространства имён и QName, актуальность полученных файлов.
- Рабочая декларация AdditionalIndexes: 29 существующих e2e-файлов и четыре
  изменения оболочки (неизвестный атрибут, квалифицированный атрибут,
  другая версия, отсутствующая версия). XML восстановлен без референса.
- Проверка обычного журнала CF/CFE расширена теми же четырьмя изменениями.
  Она обнаружила остановку подготовки фактов при изменении версии.
- Исправлен общий читатель проекции: постоянный атрибут представления не
  является фактом. Обычный читатель преобразования остаётся строгим;
  исходную оболочку сохраняет существующий механизм аномалий.
- Существующая проверка сохранённого скалярного источника защищает разделение
  режимов и сохранение неверного смыслового значения как `!xml/invalid`.

Для CF/CFE восстановлены восемь отклонений оболочки через полный маршрут
приложения. Целевой тест прошёл за 7,86 с; 11 проверок переносчика прошли.
Итоговые проверки блока прошли: 45 тестов приложения, 17 тестов
подготовки фактов, Clippy компилятора, pnpm test, проверка типов,
архитектура, поиск новых дублей и проверка формата.

## Отдельно обнаруженные ограничения

Расширенный проверочный пакет коллекций дал 22 успешные проверки из 26.
Контрольный запуск с прежними двумя декларациями воспроизвёл те же четыре
сбоя: UserVisible, рекурсивная запись, сокращение одиночного списка,
представление ссылки ChoiceParameterLinks. Они не вызваны новой привязкой
оболочки. Ожидания не ослаблялись, широкая Rust-проверка не объявляется зелёной.

XMLRoot остаётся без флажка: рабочая привязка отдельного файла и журнала
не равна полной приёмке всех форм оболочки. Счётчик common остаётся 56/90.
Исходные e2e-фикстуры не изменялись.

В следующем блоке четыре обнаруженных сбоя исправлены. Пакет коллекций
теперь проходит все 26 проверок; [подробности](2026-10-02-common-collection-regressions.md).
Ранее приведённый результат 22/26 относится к исходному контрольному запуску.

## Составные декларации и пространства имён

Привязка обычной оболочки поддерживает содержание, целиком заданное compose.
Граф передаётся переносчику явно. Пути сравниваются по URI, поэтому разные
префиксы общих фрагментов не меняют результат. В существующей проекции
InternalInfo журнала пространства имён находятся в общем фрагменте,
а не в самом объекте; этот случай также проверен. Отсутствующая ссылка
и цикл compose отклоняются при переносе.

Неуказанный префикс xsi:type получает пространство имён исходной оболочки.
Префиксы владельца отдельного файла и его значения могут различаться,
если их URI совпадают. Дополнительные синонимы одного URI не считаются
разными типами. Рабочие генераторы AdditionalIndexes и журнала --check
выдают прежние декларации; новые возможности не изменили рабочий Rust-код.

Итоговая матрица подготовки и привязки содержит 12 успешных проверок.
XMLRoot остаётся без флажка: приёмка подготовленной оболочки не объявляется
приёмкой всех внешних файлов с вычисляемым типом. Счётчик common — 56/90.
