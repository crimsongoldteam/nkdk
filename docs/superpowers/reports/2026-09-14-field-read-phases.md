# Порядок восстановления полей по направлению

XML и YAML могут задавать противоположные зависимости восстановления. Например,
при импорте отсутствующее `left` берётся из `right`, а при чтении YAML отсутствующее
`right` берётся из `left`. Объединение этих зависимостей ошибочно давало цикл.

Компилятор строит два порядка вычисления при сборке. Обычная запись и составной
объект используют соответствующий порядок. Физический порядок XML не меняется.
Привязки входов сохраняют прежние строгие зависимости: они вычисляются заранее.
Настоящий цикл в одном направлении по-прежнему отклоняется с координатами полей.

При обратной проверке выявлен и исправлен связанный случай: если отсутствующий
XML-узел восстановлен в смысловое значение, удаляющая поправка должна убрать
узел при экспорте. Обработка общая, без имён объектов или отдельных обработчиков.

Проверены существующие матрицы связывания и исполнения с новым примером
`directional-fields.yaml`, весь набор тестов компилятора, архитектура Rust и
отсутствие новых дублей относительно `37acdae1f`. XML-фикстуры не менялись.

Это готовность механизма, а не полная приёмка нового common или владельца.
Флажки объектов не добавлены. Поля без XML-размещения остаются следующим шагом.
