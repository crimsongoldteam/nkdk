# Предопределённые виды расчёта: содержимое XML ↔ YAML

Исходный файл: `e2e/fixtures/xml/cf/ChartsOfCalculationTypes/ПланРасчетаВсеСвойства/Ext/Predefined.xml`.
Декларация содержит имя, код, наименование, период действия, базовые, ведущие и вытесняющие ссылки, UUID через индекс владельца. Оболочка создаётся из `PredefinedRules` профилем `predefined-calculation-envelope.yaml`.

Три коллекции используют `common.metadata-value-path`. Смысловая запись ссылки имеет текстовое представление. Компилятор выбирает способ по XML-декларации, без условий по именам типов. Структурное размещение применяется только к XML-записям.

Ожидаемый YAML и индекс UUID заданы независимо от импорта. Обратный экспорт выполняется без XML-референса; структура и QName проверяются отдельно. Матрица содержит девять случаев справочников, характеристик и видов расчёта, по пять отклонений оболочки/булева значения для каждого. Дополнительно проверяются повторы ссылок, неверная ссылка, пустая коллекция, отсутствие булева поля и его сокращение в YAML.

Отсутствующее булево поле означает «Ложь». Явная «Ложь» остаётся в YAML; исходное отсутствие XML сохраняется механизмом аномалий. Повтор допустимой ссылки остаётся без пометок. Неверная ссылка не прерывает файл: общий механизм удерживает строку по точному смещению исходного XML, соседние элементы преобразуются. Ошибки входов и конвертера не перехватываются.

Это приёмка содержимого проверочного файла, а не полного владельца и проверки всех допустимых целей ссылок по индексу проекта. Рабочее подключение и проверка целей остаются отдельными этапами.

Расширению нужен общий тег значения целой записи `!проверять`. Нельзя заменять эту нормальную форму raw. Этот зависимый участок не мешает приёмке видов расчёта. Планы счетов также впереди. XMLRoot не отмечен; common56/90.

Проверки завершены: 90 Rust-тестов выбранных пакетов, 12 проверок профилей,
строгий Clippy компилятора со всеми целями, типы, архитектура Rust и обе
проверки архитектуры TypeScript, форматирование и поиск новых дублей.
Полный `pnpm test` завершился с кодом 0 после Rust-прогонов. Последнее
расширение той же матрицы проверяет неверное булево значение в последней
строке, чтобы защитить сохранение точного вхождения XML; повторный прогон
прошёл. Лимит 8 МиБ пакета общих коллекций не ослаблялся.
Журналы: `/tmp/nkdk-calculation-*.log`.

Самопроверка универсальности: генератор различает XML-маршруты записи и
текстовое представление, вложенные коллекции и варианты. Он не содержит
условий по виду расчёта, имени свойства или имени common. Сохранение ошибок
данных использует общий договор диагностик; ошибки `input.*` и `fact.*`
не маскируются. Независимое ревью всей ветки здесь не проводилось.
Измерения скорости выполнения и цели 10× этим прогоном не подтверждаются.
