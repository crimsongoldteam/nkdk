# Подготовка создания полного нумератора — 2026-10-01

Реализована необязательная часть шаблона: optional пропускает только своё
поле при отсутствии внешнего снимка и сохраняет сам источник фактов.
Проверено настоящее materialize_sources: отсутствие основы, существующая
ссылка и повреждённый снимок. Прежний обязательный шаблон не изменён.

Источник принадлежности теперь восстанавливается из YAML без XML: ссылка
base означает заимствованный объект; без неё — собственный. Вывод записан
выражением декларации, новых специальных условий в Rust нет. Проверочные
источники создаются из независимых UUID реальных XML-примеров; полный объект
по-прежнему сравнивается с исходным XML и ранее проверенным YAML.

Исправлена ошибка в производном примере отсутствующего boolean: источник
был клонирован с UUID расширения вместо UUID основы. Один отсутствующий
boolean не обнаруживал ошибку; соседний существующий Год давал ложную
диагностику. Усиленный пример сначала упал, после исправления сохранил
соседнее поле и диагностирует только действительно отсутствующее.

Приёмка включает 23 сценария numeric-owners (20 прежних и три источника
из YAML), 13 проверок Node и 32 проверки проектных операций. Источников
фактов — 30, общий набор с InputByString — 85. XML-фикстуры не менялись. Полный pnpm test, Clippy изменённого приложения,
архитектура TypeScript/Rust, проверка генерации и поиск новых дублей прошли.

Рабочий маршрут ещё не подключён. Осталось включить полные декларации
в рабочий каталог, связать актуальные источники значений основы и отдельное
представление проектной проверки, затем принять создание нового владельца.
При экспорте текущий оркестратор читает снимки источников. Для редактируемых
чисел и переключателей этого недостаточно: проверка должна учитывать
актуальное YAML-значение основы. Этот случай добавлен в условия приёмки,
флажок нумератора остаётся пустым.

Самопроверка универсальности: Rust знает только необязательный узел шаблона;
в нём нет нумератора, принадлежности и имён свойств. Существующее поведение
обязательных шаблонов проверено отдельно. Независимое ревью не проводилось
согласно запрету на субагентов.
