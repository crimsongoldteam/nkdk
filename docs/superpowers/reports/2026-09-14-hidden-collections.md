# Коллекция, восстанавливаемая без отдельного ключа YAML

## Результат

Генератор объявленных коллекций больше не обращается к несуществующему первому
полю YAML. Пустое `yaml.fields` означает отсутствие отдельного ключа; чтение
использует обычное `presence.yaml.missing.denotes`, запись не добавляет ключ.
Язык не расширен, предметных условий и второго дерева данных нет.

Проверены два договора: фиксированная запись восстанавливается из пустого YAML;
`select` читает режим строки в `Found`, а конструктор возвращает его в XML.
Для двух разных режимов получен независимый ожидаемый YAML без `!xml` и проверен
обратный XML. Имя и идентификатор здесь заданы самой проверочной декларацией.

Неизвестный XML-атрибут проверен отдельно. Раньше скрытый читатель пропускал
сохранённую аномалию, поскольку обычное чтение не завершалось ошибкой. Теперь
существующая оболочка читается явно; её смысловая часть по-прежнему проходит
обычное восстановление. Нет специального обработчика для конкретного атрибута.

## Проверки

До исправления воспроизведены выход за границы списка при генерации и затем
потеря XML-атрибута при проверке кандидата. После исправлений прошли полные
наборы ядра и компилятора, включая выполнение сгенерированного Rust, Clippy всех
целей, 26 проверок инвентаризации, 61 договор коллекций массового переноса
и проверка архитектуры Rust. Новых дублей
относительно `37acdae1f` нет; baseline и исключения не изменялись.

## Граница результата

Это восстановление объявленной строки, не готовое распределение всех строк
`PropertyState`. Соседи, дубли и остаток должны подключаться общим обратимым
механизмом; прятать недостающую нормальную обработку за raw нельзя.
`ExtendedConfigurationObject` и владельцы остаются непринятыми. Чеклист остаётся
19/90 common, новых флажков нет. Проверка универсальности выполнена самостоятельно,
без независимого ревью и без субагентов.
