# Полная строка колонки формы: имя и номер

Переносчик собирает все восемь свойств FormAttributeColumnRules, включая общий
заголовок, тип, просмотр, редактирование, проверку заполнения и функциональные
опции. Имя служит ключом коллекции YAML; скрытый id восстанавливается обычным
выражением из индекса номеров с ключом компонента, владельца и полного адреса.
Связь описана в tools/rules-migration/profiles/form-column-identity.yaml.
Для пустых и повторяющихся имён есть позиционный адрес. Подготовка использует
существующие декларации source.form-column-row-data и source.form-column-identities.

## Проверки

Пакет tests/migration/batches/form-columns.json содержит восемь случаев:

- два неизменных полных Column из mixedColumns.xml, ожидаемые типы Строка и
  Число(10, 2), отсутствие аномалий на нормальных данных;
- отличие, отсутствие, пустота и некорректное значение id;
- повторяющиеся и пустые имена с исходными номерами и порядком.

Для случаев повреждённого id индекс взят из исходных корректных строк: проверено
сохранение XML, отличающегося от подготовленного номера. Получение пригодного
индекса из повреждённой формы целиком этим пакетом не проверяется.

Все восемь прошли через скомпилированный Rust в обе стороны; аномалии сохраняются
общим механизмом. Проверены 27 выбранных деклараций, остальные не собирались.
Первый пересмотренный запуск занял 5,81 с, повторный 0,58 с; это ограниченный
проверочный пакет, а не время холодной сборки проекта. Clippy проверяет этот
пакет и рукописный исполнитель; старый долг предупреждений полного каталога
этим не закрыт.

## Что остаётся

Коллекция имеет явно проверочное место Columns. Это не полная сборка реквизита
формы: его fromYAML:false, значения по умолчанию, размещение дополнительных
колонок и подготовка живого индекса ещё должны быть связаны с настоящим
владельцем. Массовый перенос пока должен сохранять эти блокировки. Ни один
флажок полного объекта этим блоком не установлен. XML-фикстуры не изменены.

Полный pnpm test завершился успешно. Также прошли все 240 проверок переносчика,
проверка зависимостей Rust и контроль новых дублей (0). Существующие пропуски
тестов и ограничения времени не изменены.

## Подключение к массовому переносу и контейнеру

Профиль теперь использует обычная команда массовой генерации. Она сверяет
точные исходные параметры свойства и регистрации и учитывает пространство
имён XML. Готовую декларацию элемента сохраняет даже при блокировке владельца;
эти блокировки видны в отчёте и не заменены успешным статусом.

Добавлены два случая: неизменная группа AdditionalColumns и целый Columns из
mixedColumns.xml. Переносчик получает группу из её rules.ts: имя таблицы —
ключ YAML, коллекция колонок — его значение. Обычные и дополнительные колонки
восстанавливаются вместе в исходном XML-контейнере. Частный обработчик в Rust
не понадобился; использованы ссылки на значения и record-mapping.value.

Теперь пакет содержит 10 проверок и 31 выбранную декларацию. Проверка группы
касается единственного непустого имени таблицы. Повторы и пустые имена групп,
живая подготовка индекса и полная сборка formAttribute остаются отдельной
работой; ни один флажок полного объекта не установлен.

Финальная проверка этого продолжения: полный pnpm test прошёл; все 240
проверок переносчика, 10 случаев Rust, Clippy выбранного исполнителя и контроль
дублей прошли. Проверочная строка и строка массового переносчика имеют один
идентификатор декларации; проверяется один и тот же результат генерации.
Профиль учитывается в хешах деклараций. Новых пропусков проверок нет.
