# Обратимые шаблоны коллекций — дополнение к этапу А

> Выполнять через superpowers:executing-plans, без субагентов; часть согласованного основного плана.

**Goal:** Выразить сокращение коллекции через одно отношение фиксированных частей и единственного остатка.

**Architecture:** Строгая синтаксическая модель хранит шаблон. Связывание разрешает типы, проверяет контекст фиксированных частей и непересечение форм. Генератор А6 использует тот же шаблон для обоих направлений.

**Tech Stack:** существующие Rust workspace, YAML-загрузчик и независимый корпус.

**Spec:** раздел 6.5 [единой спецификации](../specs/2026-09-10-declaration-language-design.md).
