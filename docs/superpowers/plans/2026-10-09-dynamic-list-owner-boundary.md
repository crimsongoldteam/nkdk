# DynamicList: граница владельца

Продолжение основного плана Rust/YAML. Конвертер остаётся заранее скомпилированным; предметных ветвлений в Rust не добавляем.

- [x] Переносчик учитывает как QName с префиксом, так и локальное имя `xsi:type`. Для локального имени используется объявленное пространство XML по умолчанию; без него — пустое пространство. Неизвестные префиксы и неверные имена остаются ошибками декларации.
- [x] Расширить существующую проверку переноса и семейство DynamicList: совместный импорт/экспорт пяти булевых свойств внутри Settings, исходный тип владельца, значения по умолчанию и сохранение соседей при неверном значении. XML-фикстуры не менять; подмножество полей извлекать только в памяти. Независимые ожидания — из существующего data.ts.
- [x] Опубликовать проверенную проекцию; проверить нативное семейство, повторную генерацию и отсутствие новых дублей. Обновить основной план и чеклист без отметки полной готовности DynamicList.

## Исследованные оставшиеся границы

Основная таблица допускает корень, вложенные объекты, табличные части и завершающую виртуальную таблицу. Существующий договор обычной ссылки на объект не заменяет этот язык. Текст запроса переносится из XML в отдельный текстовый файл; `common.external-file` описывает копирование файлов, а не извлечение текста XML. Эти зависимости не подменяем строкой или аномалией.

Приёмка этого блока защищает границу владельца, но не означает полной готовности списка. Следующий блок — полноценная ссылка на таблицу, затем XML-текст ↔ внешний файл и сборка всех свойств.

Завершено: 13 нативных сценариев, 67 проверок переносчика, 12 общих проверок компилятора и два прежних примера через обычный и общий AOT. Clippy, архитектура, повторная генерация, дубли и заключительный `pnpm test` прошли. Общая регрессия порядка сначала воспроизведена без исправления, затем прошла с ним.
