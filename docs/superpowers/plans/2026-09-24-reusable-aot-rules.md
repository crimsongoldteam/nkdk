# Повторное использование скомпилированных правил: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** сократить повторный выпуск Rust-кода для общих деклараций, не замедлив XML ↔ YAML.

**Architecture:** в `ConversionPlan` различаются подготовленное определение и его подключение к владельцу. Генератор использует доказанное структурное тождество определений и выпускает общую реализацию лишь там, где размещение не меняет код; путь, входы и адрес диагностики остаются в подключении. Время работы проверяется до принятия каждого общего пути.

**Tech Stack:** Rust 1.98.1, Cargo, nkdk-rule-compiler, nkdk-conversion-core, YAML-декларации.

**Spec:** [2026-09-24-reusable-aot-rules-design.md](../specs/2026-09-24-reusable-aot-rules-design.md)

**Текущий приоритет:** пользователь поручил устранить остаточный пик памяти
при сборке двух кандидатных пакетов. Уменьшение повторяющегося Rust-кода в
задачах 1–4 снова является текущей работой; кэш автоматов уже завершён.

## Global Constraints

- Декларации YAML компилируются заранее; во время преобразования они не разбираются.
- Любое воспроизводимое замедление XML → YAML или YAML → XML отклоняет соответствующий общий путь.
- Аномалии, порядок, контекст, проверка и восстановление XML должны остаться прежними.
- Не объединять готовые строки Rust без предварительного доказательства тождества подготовленных правил.
- Не добавлять условия по именам объектов или свойств в общий компилятор.
- Существующие XML-фикстуры не изменять; новые применения `!xml` не вводить.

## Review Focus

- Одинаковое правило в разных XML-путях и с разными YAML-ключами использует независимые подключения; проверить в задаче 2.
- Разные статические параметры не сливаются в одно определение; проверить в задаче 2.
- Две строки коллекции не делят изменяемое состояние и адрес ошибки; проверить в задаче 3.
- Неверное значение и сохраняемая форма XML переживают оба преобразования; проверить в задаче 3.
- Малый выигрыш размера при замедлении конвертера отклоняется; проверить в задаче 4.

## Карта файлов

- `rust/crates/rule-compiler/src/plan/definitions.rs`: ключ структурного тождества и подготовленные подключения.
- `rust/crates/rule-compiler/src/plan.rs`: доступ к определениям из общего плана.
- `rust/crates/rule-compiler/src/generate/value_adapters.rs` и `choice_value.rs`: выпуск общих определений и тонких подключений.
- `rust/crates/rule-compiler/src/generate.rs`: учёт размера определений и подключений.
- `rust/crates/rule-compiler/tests/generate.rs`: проверки структуры генерации.
- `rust/crates/compiled-rules/tests/`: работа обоих направлений, проверка и аномалии.
- `docs/superpowers/reports/`: сравнение генерации, сборки и работы конвертера.
