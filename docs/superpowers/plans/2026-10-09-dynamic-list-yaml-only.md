# DynamicList: поля без XML-маршрута

Независимая часть согласованного переноса DynamicList. Язык и Rust уже умеют
поле записи без XML-маршрута; расширяется только автоматическое распознавание
этого договора в rules.ts.

- [x] Переносить простые скалярные поля с fromXML=false и toXML=false в YAML,
  не создавая XML-пути. Неподдержанные сочетания флагов не пропускать молча.
- [x] Проверить подключение currentUserSettingsKey с читаемым булевым соседом:
  отсутствие, значение и пустая строка; экспорт в XML не создаёт этот элемент.
- [x] Зафиксировать исключение runtimeOnly settingsComposer в данных приёмки,
  следуя исходному порядку сериализации, без особого условия в Rust.
- [x] Опубликовать семейство, проверить переносчик, архитектуру, дубли и полный
  pnpm test; обновить чеклист без флажка полного DynamicList.

Новый QueryText-договор не заменяется простым string; для него подготовлена
отдельная спецификация текстового поля во внешнем файле.

Завершено: 33 нативных сценария, 69 Node-проверок, архитектура и дубли прошли; полный pnpm test вне песочницы завершился с кодом0. Журналы /tmp/nkdk-list-yaml-only-*.log.
