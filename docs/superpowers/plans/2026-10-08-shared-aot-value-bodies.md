# План реализации общих AOT-модулей

> **Для исполнителя:** обязательный навык `superpowers:executing-plans`. Выполнение в текущей сессии без субагентов; шаги отмечаются флажками после проверки.

**Цель:** подключить семейство параметров к производственному Rust-каталогу, создавая общие преобразователи один раз и сохраняя лимит 16 МиБ на пакет без замедления XML ↔ YAML.

**Архитектура:** генератор формирует явный граф создаваемых модулей и символов. Взаимозависимые модули остаются вместе; остальные размещаются в пакетах по зависимости и фактическому размеру. Между пакетами — статические Rust-вызовы и заимствованные входы; размещение не меняет язык деклараций.

**Технологии:** Rust 1.98.1, Cargo, существующие `rule-compiler`, `conversion-core`, средства измерения сборки и проверочный запускатель миграции. Новые сторонние зависимости не планируются.

**Спецификация:** [общие AOT-модули](../specs/2026-10-08-shared-aot-value-bodies.md).

## Общие ограничения

- Вариант А — предварительная компиляция деклараций в Rust. Интерпретатор деклараций при выполнении не вводится.
- Предел каждого нового производственного пакета — **16 × 1024 × 1024 байт Rust**, включая переходники. Существующие меньшие ограничения других пакетов не повышаются.
- Новых преобразований данных, обходов деклараций и копирования контекста при выполнении не добавляется.
- При устойчивом замедлении выше разброса замеров новый способ не принимается.
- XML-фикстуры и исходные ожидания TypeScript не изменяются. Аномалии и исходная форма XML сохраняются.
- Никаких списков имён common, свойств или владельцев для разбиения компилятора.
- Внешние функции каталога, идентификаторы входов и раскладка входных параметров остаются прежними.
- Чеклист бинарный. `ParameterValue` и `SettingsParameterValueCollection` остаются неотмеченными до полной отдельной приёмки; полная приёмка владельцев — отдельная работа.
- Один процесс Cargo за раз, отдельный target. По решению журнала от 9 октября оптимизированный проверочный каталог собирается с `-j2` и измерением одновременной памяти; при росте памяти возвращаться к `-j1`. Не очищать существующие результаты ради замера и не собирать холодный полный workspace на каждом шаге.
- Не изменять `.agents/architecture.md`, baseline зависимостей или посторонние накопленные изменения.

## Особое внимание при проверке

1. Взаимная рекурсия не превращается в цикл зависимостей Cargo — проверка задачи 2.
2. Похожие тела с разными XML-путями, входными позициями или строками не объединяются — задачи 1 и 3.
3. Переименование потребителя не пересоздаёт общий модуль; изменение общего договора затрагивает его потребителей — задачи 2 и 4.
4. Смешанные пакеты от разных каталогов отклоняются при сборке, а не при преобразовании данных — задача 4.
5. Неверные значения, пустые состояния, порядок и повторы детей сохраняются в обе стороны — задачи 3 и 5, независимый корпус из 30 случаев.

- `tools/rules-migration/src/shared-aot-cli.mjs` — подготовка пакетов до Cargo, режим записи и `--check`.
- `tools/rules-migration/test/shared-aot.test.mjs` — полнота файлов, повторяемость и отсутствие лишней перезаписи.
- `rust/build-support/production.rs`, `rust/crates/compiled-rules-bodies-5/{Cargo.toml,build.rs,src/lib.rs}`, `rust/crates/compiled-rules/{Cargo.toml,src/lib.rs}` и `rust/Cargo.toml` — подключение принятых пакетов и сохранение интерфейса каталога.
- `tools/rust-architecture/policy.mjs` — разрешённые зависимости новых пакетов, без исключений для конкретных метаданных.
- `tools/rust-build-profile/build.py`, `tools/rust-build-profile/test_build.py`, `package.json` — подготовка перед производственной сборкой, проверка её порядка.
- `tools/rules-migration/runtime/{Cargo.toml,build.rs,src/main.rs}` — подключение разделённого проверочного каталога; существующий режим измерений переиспользовать.
- `docs/superpowers/reports/2026-10-08-shared-aot-value-bodies.md`, текущий план миграции, чеклист и журнал выполнения — доказательства и итог приёмки.

## Общие интерфейсы задач

Добавить в `shared_catalog.rs` и экспортировать из `lib.rs`:

```rust
pub struct SharedCatalogOptions { pub max_rust_bytes: usize }
pub struct GeneratedPackage {
    pub name: String,
    pub generated: GeneratedSources,
    pub package_dependencies: Vec<String>,
    pub rust_bytes: usize,
}
pub struct GeneratedSharedCatalog {
    pub packages: Vec<GeneratedPackage>,
    pub facade: GeneratedSources,
    pub catalog_signature: String,
    pub layout_manifest: Vec<u8>,
}
pub fn compile_shared_catalog(
    sources: &[SourceFile<'_>],
    export: impl Fn(&Module) -> bool,
    options: SharedCatalogOptions,
) -> Result<GeneratedSharedCatalog, Vec<Diagnostic>>;
```

Имена пакетов относятся к результату генерации, не к типам метаданных. `generated.dependencies` сохраняет существующий смысл исходных зависимостей; зависимости Cargo записываются отдельно в `package_dependencies`. Манифест размещения содержит версию формата, подпись каталога, владельцев модулей/данных, зависимости и фактические байты Rust. Фасад тоже проверяется по `max_rust_bytes`.

**Результат:** старый способ работает без изменений, а генератор знает реальные границы модулей и ссылки между ними.

- [x] Добавить тест `shared_units_preserve_symbol_identity`: одинаковые локальные названия не стирают разные внешние цели, XML-пути, строковые литералы и позиции входов. Использовать уже существующие проверки `record_bodies` вместо второго одинакового набора.

Первые команды требуют соответствующей реализованной задачи. Ожидается код 0; для корпуса — 30 успешных независимых случаев. `pnpm test` запускать вне песочницы. Для сравнения скорости старый и новый файл собирать с одинаковым `--release`; профилировщик сборки применять к выбранному каталогу, не ко всему workspace.

## Условие остановки и порядок продолжения

Если неделимая группа превышает 16 МиБ либо выполнение устойчиво замедляется, сохранить старый производственный путь и доказательства причины; не повышать предел и не подменять AOT интерпретатором. Продолжать независимые проверки, пока зависимое решение требует обсуждения.

Задачи 1–5 выполнены для семейства параметров в существующем рабочем дереве без субагентов. Производственное подключение и проверка скорости приняты; [отчёт](../reports/2026-10-08-shared-aot-value-bodies.md) сохраняет измеренные ограничения. Генерация сравнивалась в двух режимах текущего компилятора на одинаковых сохранённых исходниках; старый режим воспроизвёл архивный код байт в байт. Локальный замер относится к правке Rust-фасада; устойчивость после правок YAML отдельно защищена нативной матрицей. Общее ускорение 10×, остальные семейства и удаление TypeScript остаются в основном плане.
