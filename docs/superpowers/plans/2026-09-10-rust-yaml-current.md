# Текущее состояние перехода на Rust и YAML-декларации

Обновлять после завершения семейства; заменять сведения, не дописывать историю.

- Рабочая ветка: `codex/common-declarative-spec`, worktree `.worktrees/common-declarative-spec`.
- Приняты девять common: I8nText, FormattedI8nText, MetadataName, StringOrNumber, PredefinedCode, MinMaxValue, boolean, number, dateTime. [Бинарный чеклист](2026-09-10-rust-yaml-object-checklist.md) содержит доказательства.
- Последний пакет: **М3 — вложенная скалярная запись**. standardPeriod и standartBeginningDate описаны декларациями, работают оба преобразования, календарные секунды, схемы и аномалии полей/оболочки. Нормальный YAML читается одним потоком событий. Пять реальных StandardBeginningDate проходят e2e; для StandardPeriod реальных значений в корпусе нет. У обоих объектов остаются договоры dataPathRules для М6, поэтому их флажки полного переноса не установлены.
- Следующий независимый пакет: **М4 — коллекции** по карте механизмов. При М6 вернуться к путям данных обоих календарных common; не считать готовое преобразование полной приёмкой объекта. Каталог 678 системных перечислений остаётся принятым целиком.
- Строковый common остаётся без галочки: обычный текст работает, ссылочные профили/metadataTarget требуют подготовленных индексов М6. Общие открытые границы: смешанный XML, повтор свойства, неизвестный контейнер, повреждённый синтаксис. Не маскировать отсутствие нормального преобразования raw-оболочкой.
- Договоры: XML ↔ YAML; полный отказ от TS в итоге; Enterprise исключён; точные десятичные числа; время как записано; аномалии выводятся из нормальной декларации; только e2e-источники, без изменения XML-фикстур; без субагентов.
- Проверки М3: 153 Rust-теста workspace, целевые проверки календарных записей и схем, Clippy, отсутствие новых дублей; пять записей неизменённого e2e. [Журнал](../reports/2026-09-10-rust-yaml-progress.md) содержит детали и ограничения. Это не измерение 10× и не преобразование целого проекта.
- Локальные повторные проверки большого каталога: `CARGO_INCREMENTAL=0 CARGO_PROFILE_DEV_DEBUG=0 CARGO_PROFILE_TEST_DEBUG=0`. Это параметры запуска для экономии места, настройки проекта не менялись; измерения производительности выполняются отдельно в release.
