# Снижение памяти rustc: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** уменьшить пик памяти сборки Rust-каталога правил ниже 2 ГБ на процесс без потери правил и скорости XML ↔ YAML.

**Architecture:** корневые правила разбиваются на независимые пакеты с замыканием импортов. Созданный компилятором фасад сохраняет общий интерфейс и единый каталог фактов. Каждый пакет содержит готовый Rust-код, а не интерпретатор YAML.

**Tech Stack:** Rust 1.98.1, Cargo, `nkdk-rule-compiler`, `nkdk-conversion-core`.

**Spec:** [2026-09-24-rustc-memory-sharding-design.md](../specs/2026-09-24-rustc-memory-sharding-design.md)

## Global Constraints

- Не удалять принятые правила ради уменьшения сборки.
- Не вводить исполнение деклараций во время преобразования.
- Сохранить общий `EntryId`, факты, аномалии и обе стороны преобразования.
- Не менять XML-фикстуры и не вводить новые применения `!xml`.
- При воспроизводимом замедлении конвертера вернуть соответствующее изменение.

## Review Focus

- Два семейства импортируют один common с разными входами: результат остаётся независимым.
- Источник и потребитель фактов разнесены между пакетами: индексы и поколение совпадают.
- Неизвестный `EntryId`: прежняя диагностика, а не неверный пакет.
- Аномалия вложенной коллекции проходит туда и обратно после разделения.
- Правка одного YAML пересобирает только его семейство и фасад, если его метаданные изменились.

## Карта файлов

- `rust/build-support/family.rs`: выбор замыкания деклараций по корням.
- `rust/crates/rule-compiler/src/generate.rs` и новые модули рядом: метаданные пакетов и фасад.
- `rust/crates/compiled-rules-*/`: пакеты семейств правил.
- `rust/crates/compiled-rules/src/lib.rs`: публичная точка входа без предметных условий.
- `rust/crates/conversion-core/src/facts/`: общий контракт идентификаторов индексов.
- `rust/crates/compiled-rules/tests/`, `rust/apps/nkdk/tests/`, `rust/tools/dev/tests/`: прежние проверки после переноса пакетов.
- `docs/superpowers/reports/`: сопоставимые замеры памяти, сборки и конвертера.

## Задача 3: производственные пакеты и фасад

Текущий результат: основной каталог уменьшен до 1727 МБ, проверочный — до
293 МБ. Кандидатные семейства проверяются отдельно и остаются крупнее
предела (3237 и 4710 МБ). Они доступны в прежнем общем каталоге через
`NKDK_FULL_PRODUCTION=1`; фасад без изменения интерфейса ещё не создан.

заменяет декларации интерпретатором и не меняет настройки оптимизации конвертера.
