# План точного XML round-trip оставшихся различий

> **Для Codex:** обязательный навык исполнения — `superpowers:executing-plans`. Реализацию вести по TDD и завершать каждый слой `pnpm duplicates -- --base 9cdcb73b9`.

**Цель:** устранить все 696 расхождений `XML -> YAML -> XML` для `cf/doc` без списков исключений в e2e.

**Архитектура:** предметные rules остаются источником обычного XML. Непредметное присутствие полностью стандартного блока хранится отдельным тегом формы XML; частичные raw-поправки меняют порядок только через явный `#order`; planned absence и служебные метаданные YAML сохраняются общими механизмами import proof.

**Стек:** TypeScript, Vitest, YAML runtime metadata, metadata rules, XML raw merge, e2e.

---

3. Реализовать зарегистрированный тег формы XML без предметного значения и без участия `!xml/raw`.
4. Добавить падающие интеграционные тесты: отсутствующий блок не создаёт поле; полностью стандартный присутствующий блок создаёт тег; непустой блок остаётся обычным YAML.

6. Запустить целевые тесты и `pnpm duplicates -- --base 9cdcb73b9`.
