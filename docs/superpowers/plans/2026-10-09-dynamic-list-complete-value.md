# DynamicList: совместная проверка всех сохраняемых свойств

Продолжение принятого переноса Rust/YAML, без субагентов и коммитов.
Ранее принятые common и коллекции переиспользуются; новый язык и предметные
обработчики Rust не добавляются.

- [x] Автоматически собрать все сохраняемые свойства исходного DynamicListRules.
  settingsComposer исключать только по исходному runtimeOnly; сохранить
  все исходные требования yamlPath и не выдавать их отсрочку за готовую операцию.
- [x] Добавить полный реальный Settings из неизменной e2e-формы:
  QueryText, три коллекции, таблица и все ListSettings вместе.
  Проверить смысловые ключи по независимому YAML, точное восстановление XML,
  внешний файл и валидацию. Частные матрицы common не дублировать.
- [x] Проверить минимальную форму тем же полным договором и неверного соседа.
  Неподдержанные сочетания исправлять общими механизмами, не обработчиками
  по именам свойств. Для новых договоров независимая ошибка RED→GREEN.
- [x] Выполнить адресные нативные проверки с общим AOT-кешем и лимитом16МиБ,
  публикацию/воспроизводимость, архитектуру, дубли и полный pnpm test.
  Обновить отчёт и бинарный чеклист; полный объект не принимать до завершения
  проектных обязанностей yamlPath.
