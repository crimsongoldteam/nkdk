# Небольшая сборка пакета миграции

Цель: проверить пакет из 48 свойств без сборки всего рабочего каталога тем же
компилятором и прежним запускателем независимых ожиданий. Решение согласовано
пользователем; работаем в существующем worktree без субагентов.

- [x] Добавить выбор случаев и замыкание imports в `focused-catalog.mjs`;
  переиспользовать `dependencyFiles`, включать источники фактов только когда
  нужны выбранным случаям. Проверить неизвестные случаи, пропущенные зависимости,
  несколько корней, общие зависимости, циклы и отсутствие мутаций исходников.
- [x] Добавить CLI `focused-check.mjs`, JSON-пакет Document/DocumentJournal и
  `migration:check:focused`. Проверять актуальность исходников, сохранять только
  изменившиеся файлы в target, выводить состав и времена run/Clippy.
- [x] Разрешить существующему runtime/build.rs получать каталог через переменную
  окружения; по умолчанию оставить полный каталог. Отслеживать изменение выбора.
  Не добавлять альтернативный генератор, сравнение YAML или обработчик объектов.
- [x] Обновить кандидаты и независимые случаи, запустить JS-проверки, малую
  сборку с Clippy и повторный запуск; проверить 48 свойств/4 случая.
- [x] Выполнить полный набор проверок кандидатов и обязательные проверки слоя;
  записать измерения, новые подключения отдельно от проверенных свойств,
  обновить текущий план. Флажки объектов от инструмента не менять.

Полнота проверки: весь набор XML/YAML-ожиданий выбранного случая сохраняется,
а не заменяется лишь round-trip. Результаты не записываются в рабочие декларации.
Крупные препятствия переноса владельцев фиксируются отдельно; не расширять
язык деклараций ради прохождения пробного пакета.


Результат: пакет 48 свойств, 4 случая, 38 из 207 деклараций. Первый запуск
run — 13,71 с, Clippy — 5,74 с; повторные запуски целиком — 1,02 и 1,54 с.
Полные 127 случаев прошли, как и 9 JS-проверок и 2 теста сравнения runtime.
Архитектура, форматирование и новые дубли проверены. [Отчёт](../reports/2026-09-13-focused-migration-checks.md).

Новых подключений свойств: 0. Следующая задача массового переноса — определить
готовые, но ещё не подключённые свойства и проверять их такими пакетами.
Проверенные здесь проекции уже существовали; полные владельцы не приняты.

По повторной сверке manifest: AdditionalIndexes и Help у обоих владельцев всё
ещё помечены генератором кандидатов как unsupported-common, хотя их рабочие
декларации уже приняты. Следующий аудит должен отделить такие отсутствующие
соответствия готовым фрагментам от действительно отсутствующих механизмов.
Не начинать новое расширение движка по одной метке unsupported-common.
