# Вычисляемые поля СКД: завершение автоматического переноса

Продолжение согласованного общего плана. Элемент с девятью свойствами и
коллекция собираются из `rules-extraction.json` и `collection-links.json`,
без вручную переписанных правил и без изменений XML-фикстур.

- [x] Добавить семейство общего запускателя; проверить наличие всех девяти
  свойств и двух независимых XML/YAML-примеров из динамического списка.
- [x] Проверить оба направления преобразования, соседей, повтор элемента,
  неверное булево значение с сохранением остальных свойств.
- [x] Включить оформление и доступные значения: исходные два XML-примера
  не покрывают эти свойства; использовать существующие проверенные ожидания.
- [x] Подготовить рабочую декларацию общим переносчиком и проверить каталог,
  схему, индексы и экспорт без XML-референса.
- [x] Проверить дубли, обновить покрытие и двоичный чеклист только после
  полной приёмки; полную сборку формы учитывать отдельно.

Общие Rust-механизмы остаются независимыми от имён объектов. Проверочный
каталог собирается через общие AOT-пакеты с прежним пределом 16 МиБ,
без возврата к большому монолиту. Число одновременно работающих rustc
ограничено; время и память преобразования нельзя ухудшать ради сборки.

Проверка перед приёмкой: адресная матрица, проверки переносчика, архитектура
при изменении зависимостей, `pnpm duplicates -- --base 91a01277`, `pnpm test`.

Принято 2026-10-09: шесть случаев через полный рабочий реестр, независимые
положительные и отрицательные проверки схемы, 30 Rust-проверок схем, Clippy,
252 проверки переносчика в составе полного `pnpm test`, три архитектурные
проверки и отсутствие новых дублей. Расширенный общий Rust-прогон остановлен
на старых монолитных каталогах из-за расхода места; он не объявляется пройденным.
