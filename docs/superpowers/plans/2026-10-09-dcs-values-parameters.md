Продолжение принятого плана переноса; исполнение здесь, без субагентов.

- [x] Сверить девять профилей `dcsMetadataValue` с прежними примерами,
  проверить ограничение одного параметра выбора и сохранение отклонений.
- [x] Перенести полный договор `dscMetadataTypedValue`: варианты, строки,
  даты, ссылки, отсутствие и последовательности. Противоречия исследовать
  по исходным тестам; частные обработчики Rust не добавлять.
- [x] Проверить все 12 свойств `dcsParameter`, вложенные параметры,
  соседей, повторы и аномалии на рабочих источниках индексов.
- [x] Один раз подключить готовые декларации к общему рабочему реестру;
  проверить преобразования, схемы, архитектуру и новые дубли.
- [x] После полной приёмки обновить двоичный чеклист и покрытие исходников.

Полные владельцы форм и СКД принимаются отдельно. XML-фикстуры не менять.
Предел 16 МиБ сохраняется; общие тела Rust переиспользуются. Незавершённый
договор не получает флажок. Полный `pnpm test` выполняется перед приёмкой.


Уточнение исполнения: нормальные typedValue проверяются отдельно от полной
приёмки. Ссылки используют один смысловой договор и принимаемые написания
общего словаря; пересекающихся вариантов ссылки не вводить. Последовательность
проверять с повтором, порядком и соседним свойством; отсутствие коллекции —
с отсутствием её XML-свойства при сохранённом владельце. Следующий обязательный
случай — пустая позиция `{}` и `xsi:nil`, затем QName `Undefined` с разными
префиксами. Флажок typedValue до этих проверок не ставить.


Приёмка typedValue: 22 случая прошли через рабочий автоматический перенос и
общие Rust-модули. Зарегистрировано рабочее имя `DcsMetadataTypedValue`;
проверены отсутствие, локальные аномалии, две формы QName-префикса, одиночные
и составные списки. Полный `pnpm test`, Clippy, архитектура и новые дубли
прошли. Отмечен только этот common; два других пункта пакета остаются открытыми.
