# NKDK Round-Trip YAML Parse Errors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make NKDK parse the two real round-trip-yaml cases: `?ПолеДиаграммы` and `Имя(1/0:uuid):`.

**Architecture:** Extend the Langium grammar with one missing `OTHERFIELD` value and one narrow raw data path terminal. Keep ordinary dotted `DataPath` behavior unchanged, and adapt the NKDK import helper to return either dotted paths or raw platform paths.

**Tech Stack:** TypeScript, Langium, Vitest, pnpm, existing `@nakidka/core` and `nkdk-language` test helpers.

```ts
type NKDKDataPathSource = {
  dataPath?: string[]
  rawDataPath?: string
}
```

- [ ] **Step 2: Update `importDataPathFromNKDK`**

In `packages/core/metadata/orchestration/formElement/fromNKDK/helpers.ts`, replace:

```ts
export const importDataPathFromNKDK = (source: { dataPath: string[] }): string => {
  return source.dataPath.join(".")
}
```

with:

```ts
export const importDataPathFromNKDK = (source: NKDKDataPathSource): string => {
  if (source.rawDataPath !== undefined) return source.rawDataPath

  if (source.dataPath === undefined) throw new Error("Data path is required")
  return source.dataPath.join(".")
}
```
