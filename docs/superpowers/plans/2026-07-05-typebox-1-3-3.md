# TypeBox 1.3.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перевести `packages/core` с `@sinclair/typebox@0.34.49` на `typebox@1.3.3` без изменения пользовательского поведения YAML-валидации.

**Architecture:** Миграция выполняется прямым переходом на новый пакет `typebox`, `Schema.Compile` и формат ошибок `typebox/error`. Общие metadata-слои остаются нейтральными: меняются только импорты, компиляция схем и адаптация ошибок в validation-слое.

**Tech Stack:** TypeScript, pnpm, Vitest, TypeBox 1.3.3, `typebox/schema`, `typebox/error`.

- [ ] **Step 4: Replace typeboxErrorsToDiagnostics**

Rewrite `typeboxErrorsToDiagnostics.ts` around `ValidationError` from `discriminatedUnionErrors.ts`. The implementation must include these helpers:

```ts
function requiredPropertyNames(error: ValidationError): string[] {
  const required = (error.params as { requiredProperties?: unknown }).requiredProperties
  return Array.isArray(required) ? required.filter((item): item is string => typeof item === "string") : []
}

function additionalPropertyNames(error: ValidationError): string[] {
  const additional = (error.params as { additionalProperties?: unknown }).additionalProperties
  return Array.isArray(additional) ? additional.filter((item): item is string => typeof item === "string") : []
}

function normalizedErrors(errors: ValidationError[]): ValidationError[] {
  const result: ValidationError[] = []

  for (const error of errors) {
    if (error.keyword === "required") {
      const names = requiredPropertyNames(error)
      for (const name of names.length === 0 ? [""] : names) {
        result.push(name === "" ? error : { ...error, instancePath: `${error.instancePath}/${escapeJsonPointerSegment(name)}` })
      }
      continue
    }

    if (error.keyword === "additionalProperties") {
      const names = additionalPropertyNames(error)
      for (const name of names.length === 0 ? [""] : names) {
        result.push(name === "" ? error : { ...error, instancePath: `${error.instancePath}/${escapeJsonPointerSegment(name)}` })
      }
      continue
    }

    result.push(error)
  }

  return result
}
```

The main loop must read `error.instancePath`, compare `error.keyword === "required"`, and use `error.diagnosticLocation === "key"` for key diagnostics.
