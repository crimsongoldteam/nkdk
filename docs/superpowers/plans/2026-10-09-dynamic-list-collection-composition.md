# Подключение коллекций DynamicList к декларативной сборке

Продолжение согласованного автоматического переноса и плана внешних текстов.
Выполнять здесь без субагентов. Rust-обработчики по именам объектов не добавлять.

- [x] Через существующий mapCollectionReference подключать подготовленные
  коллекционные декларации к обычному emitCandidates/sourceProjection.
  Входы, импорты, привязки и XML-пространства передавать существующим способом.
  Проверить независимое переименование и сохранение входов двух коллекций.
- [x] Не терять configurationIndexAddressing: yamlPath. Требование владения
  сохранять в отчёте; без его выполнения полную сборку блокировать.
  Проверочный профиль может явно отложить обязанности операции, как существующий
  emitCollections; такой профиль не означает полную проектную приёмку.
- [x] Собрать совместный пример трёх коллекций из существующих регистраций,
  переиспользуя common-библиотеки элементов и независимые XML/YAML-ожидания
  старых семейств. Проверить соседние свойства и QueryText, оба направления,
  аномалии и отсутствие коллекций. Ничего не менять в XML-фикстурах.
- [x] Опубликовать проверенный договор существующим инструментом, обновить
  отчёт/чеклист, выполнить затронутые проверки, архитектуру, дубли и pnpm test.
  Полный DynamicList отметить только после приёмки всех свойств и обязанностей
  проектной операции; подготовленные коллекции сами по себе флажок не закрывают.

Файлы: collection-reference-property.mjs, mappings.mjs, emit.mjs,
source-projection.mjs, семейные генераторы и их существующие матрицы.
Сборки адресные, общий кеш migration-contracts, -j1, лимит пакета16МиБ.
Коммиты, push и PR не входят в этот блок.

Состояние приёмки: все четыре пункта выполнены. Повторный полный pnpm test
прошёл с прежними лимитами, включая5258 unit, обе нативные LMDB-группы
и3166 integration пакета rules. Архитектура, дубли и воспроизводимость
публикации проверены. Эксперимент VM для rules отклонён, режим пакета не менялся.
[Подробный результат и оставшиеся ограничения](../reports/2026-10-09-dynamic-list-collection-composition.md).

Дополнительная зависимость публикации устранена: старый генератор исходных
проверочных примеров принимает вложенные XML-пути. migration:contracts,
attachments и families обновлены штатно. Флажок полного DynamicList
не изменён: приняты три коллекции вместе, не весь объект и операция.
