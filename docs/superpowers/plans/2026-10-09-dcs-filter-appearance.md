# Оставшиеся отборы и условное оформление СКД

Продолжение общего принятого плана после полной приёмки поля набора данных.
Работа без субагентов; исходные XML неизменны. [Исходная проверка переносчика](../reports/2026-10-09-dcs-filter-appearance-readiness.json)
показывает только распознавание свойств, а не готовность объектов.

- [x] Выразить полный элемент сравнения отбора: 10 исходных регистраций,
  включая служебное parent. Установить его роль по старому выполнению и тестам;
  не включать его в смысловой YAML или молча пропускать без доказательства.
  Проверить UserSettingsID с неявным false в обе стороны.
- [x] Собрать рекурсивный выбор сравнения/группы и коллекцию из исходной
  регистрации, затем все пять свойств FilterRules. Использовать общий
  механизм рекурсивных деклараций, не обработчик по названию отбора.
- [x] Подключить AvailableFields с отсутствующим/пустым контейнером и
  обязательным восстановлением пустого XML, если исходное правило его создаёт.
  Не приравнивать разные пустые состояния без проверки исходных примеров.
- [x] Автоматически собрать все 18 свойств ConditionalAppearanceItemRules
  и коллекцию, затем четыре свойства ConditionalAppearanceRules.
- [x] Перенести независимые ожидаемые примеры и проверить сравнение,
  вложенные группы, пустые состояния, неявные значения, QName, повторы,
  порядок, локальные аномалии и читаемых соседей без XML-референса.
- [x] Опубликовать воспроизводимый рабочий каталог, проверить схемы,
  общую нейтральную матрицу затронутых механизмов, полный pnpm test,
  архитектуру, Clippy и новые дубли; отметить только целиком принятые строки.

Порядок зависимостей: элемент сравнения → рекурсивная группа → отбор →
элемент условного оформления → всё условное оформление. Уже принятые
common используются повторно. Предварительный результат переносчика:
сравнение 8/10, группа 7/8, отбор 3/5, элемент оформления 16/18,
оформление 2/4. Отсутствие правил и неподдержанные параметры не являются
аномалиями данных и не должны заменяться сохранением !xml.

Производительность проверять на обычном пути без параллельных сборок;
лимит общих AOT-пакетов 16 МиБ сохраняется. Полная схема СКД, её индексы
и цель 10× принимаются отдельно от этих common.
