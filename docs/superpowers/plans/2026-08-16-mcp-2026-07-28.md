# MCP 2026-07-28 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перевести `@nkdk/mcp` на modern-only MCP `2026-07-28`, SDK v2, TypeBox-договоры и локальный Streamable HTTP без сохранения legacy-совместимости.

**Architecture:** Единая фабрика `createNkdkMcpServer()` регистрирует возможности независимо от транспорта. `serveStdio()` обслуживает modern-only stdio, а Web Standard `createMcpHandler()` с Node-адаптером — stateless HTTP на `127.0.0.1`; CLI и единый координатор завершения выбирают и закрывают транспорт. Все прикладные MCP-схемы объявляются через TypeBox и адаптируются к Standard Schema только функцией `toMcpSchema()`.

**Tech Stack:** TypeScript 7, Node.js 26, `@modelcontextprotocol/server` 2.x, `@modelcontextprotocol/client` 2.x, `@modelcontextprotocol/node` 2.x, TypeBox 1.3.11, Vitest 4, pnpm, esbuild.

## Global Constraints

- Поддерживаемая версия протокола — только `2026-07-28`; legacy `initialize` должен отклоняться без fallback.
- stdio остаётся транспортом по умолчанию; HTTP включается только `--http`, слушает только `127.0.0.1`, путь — только `POST /mcp`, порт по умолчанию `3000`.
- `--watch` разрешён только для stdio; `--port` разрешён только вместе с `--http` и принимает целое число `1..65535`.
- `@nkdk/mcp` не импортирует `@modelcontextprotocol/sdk` и `zod`; `@modelcontextprotocol/client` остаётся только devDependency.
- TypeBox — единственный источник прикладных входных и выходных MCP-схем; strict/loose-семантика текущих договоров сохраняется.
- HTTP не получает auth, TLS, CORS, reverse proxy или настройку bind-адреса; допускаются только локальные Host/Origin.
- Не добавлять Tasks, MCP Apps, MRTR, `x-mcp-header`, пользовательские cache hints или изменения metadata/platform-служб.
- Существующие XML-фикстуры не изменять; `.agents/architecture.md` не изменять.
- После каждого законченного задания запускать `pnpm duplicates -- --base ac6151ea2`.
