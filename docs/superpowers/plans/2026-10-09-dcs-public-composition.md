# Общая регистрация принятых частей СКД

Продолжение принятого переноса, без субагентов. `dataCompositionSystem/index.ts`
собирает регистрации common; он не содержит полного преобразователя XML-схемы
DataCompositionSchema. Реализация новой схемы не подменяет перенос этой сборки.

- [x] Сверить все исходные регистрации с публичными библиотеками, построителями
  профилей и автоматическим переносом коллекций. Отсутствие простого псевдонима
  не означает отсутствие параметризованного договора; проверить реальные параметры.
- [x] Опубликовать полную запись ConditionalAppearance под common-именем;
  проверить реальное свойство формы из sourceProjection в обоих направлениях.
  Индексы остаются у владельца; частных ветвей в Rust не добавлять.
- [x] Опубликовать относительные библиотеки CalculatedField и
  DataCompositionSchemaDataSetField из тех же исходных правил, затем проверить
  вложение в реальные зарегистрированные коллекции. Размещение Field и
  пространства имён брать из исходной регистрации, не угадывать по типу.
- [x] Сверить OrderItemFields и StructureItemGroupCollection с уже принятыми
  общими коллекциями, проверить псевдонимы и существующие договоры профилей
  MetadataDcsMetadataValue/SettingsParameterValue/SettingsParameterValueCollection.
- [x] Выпустить общий отчёт доступности всех регистраций. Не закрывать корневой
  флажок dataCompositionSystem, пока не проверены все ответственности сборки;
  готовность всей формы и XML-схемы отмечать отдельно.
- [x] Выполнить проверки затронутых механизмов и исходных примеров, схемы,
  Clippy, архитектуру, новые дубли и полный pnpm test отдельно от сборок.

Исходные XML неизменны. Ожидания независимы от декларации. Использовать общие
AOT-пакеты с пределом 16 МиБ, не собирать огромный монолит. Новые данные
дополняют существующие матрицы. Прошлые release-замеры выбора вариантов не
считать проверкой скорости всей сборки СКД или подтверждением цели 10×.

Приёмка 2026-10-09: [отчёт и границы](../reports/2026-10-09-dcs-public-composition.md).
29 Rust-договоров, 90 проверок переноса, 30 проверок схем, Clippy,
архитектура, новые дубли и полный pnpm test прошли. Корневой common-флажок
не закрывается этим блоком; отдельно остаются обязанности полной сборки
регистраций и полные владельцы.
