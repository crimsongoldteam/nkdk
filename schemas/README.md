# Схемы деклараций

`nkdk-declarations.schema.json` — JSON Schema 2020-12 для написания исходных
YAML-деклараций. Одна схема обслуживает common (`kind: value`), фрагменты
(`kind: fragment`) и владельцев (`kind: object`). Она описывает текущую
реализованную грамматику, включая точный числовой профиль `decimal`.

Схему можно назначить YAML-файлам в редакторе или получить командой:

```sh
cargo run --manifest-path rust/Cargo.toml -p nkdk-dev -- declarations language-schema
```

Проверка структуры не заменяет компилятор:

```sh
cargo run --manifest-path rust/Cargo.toml -p nkdk-dev -- declarations check --dir rust/declarations
```

Компилятор дополнительно проверяет исходную форму YAML (повторные ключи,
якоря, теги и числовую запись), разрешает имена, проверяет типы, уникальность
адресов, порядок диапазонов и обратимость. Синтаксически допустимая декларация
может использовать конструкции, для которых генерация Rust ещё не завершена.

Схема пользовательских данных — отдельный результат конкретной декларации:

```sh
cargo run --manifest-path rust/Cargo.toml -p nkdk-dev -- declarations schema --dir rust/declarations --entry test.numeric-bound
```

Точные десятичные границы требуют соответствующей точности внешнего валидатора.
Штатная Rust-валидация использует точный десятичный тип независимо от возможностей
редактора. Независимый валидатор JSON Schema подключён только к тестам компилятора;
он не входит в рабочий бинарник.
