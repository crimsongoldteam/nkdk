## Что исправлено

1. XML и payload-файлы дочернего макета теперь прикрепляются к заданию владельца и не создают отдельное задание `Template.xml`, для которого отсутствует подготовщик metadata-модели.
2. Перед публикацией целевые пути проверяются через `realpath` ближайшего существующего родителя. Существующий symlink, ведущий за пределы Проекта, отклоняется до переноса файлов.
3. Если финальный `rename` подготовленного worker-файла завершается ошибкой, временный файл возвращается по исходному пути worker. Ошибка восстановления не скрывает исходную ошибку и возвращается через `AggregateError`.
4. Collector индекса допускает повторную запись только идентичного значения. Конфликтующие UUID, XML ID/name, order, alias и скалярные XML-значения завершаются явной ошибкой с `logicalAddress`, полем и обоими значениями.
5. Для свойств введён нейтральный контекст адреса узла индекса. Он устраняет реальные коллизии адресов свойств и коллекций без знания конкретных `itemType` в общих слоях; сегмент стандартных реквизитов объявлен в правилах.
