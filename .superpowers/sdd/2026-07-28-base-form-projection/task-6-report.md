# Task 6 report

## Статус

Выполнено. Интеграционная фикстура расширения полностью создаётся во временном
проекте: `cf` содержит вложенное поле, реквизиты и команду, а `cfe` перемещает
поле, меняет его `Вид`, явно заимствует реквизит, добавляет собственную команду
и режимные события `Перед`/`После`. Существующие XML-фикстуры не изменялись.

Итоговый XML проверяет внешний слой и `BaseForm`: вид, расположение,
`DataPath`, `CommandName`, идентификаторы из нужного снимка, события и состав
команд. Отдельные случаи проверяют отсутствующую форму `cf`, обязательный
`xmlId` из `cf` и локальный `xmlId` явно заимствованного реквизита. Во всех
случаях ожидается `full_xml_sync_assignment_failed`, сохраняется уже
записанный XML справочника и не остаётся частичная внешняя форма.

## Отклонение от brief

Integration-case недоступной локальной ссылки без projector удалён. В
зарегистрированных правилах форм локальные ссылки на реквизиты и команды
представлены только `DataPath` и `CommandName`; оба типа имеют
зарегистрированный BaseForm projector. Поэтому через публичную полную
синхронизацию этот error path при текущем наборе правил недостижим без
изобретения production-свойства или вмешательства во внутренний реестр.

Этот защитный путь уже покрыт unit-тестами
`baseFormProjectionRegistry.test.ts` и `baseFormProjection.test.ts` из Task 3.
