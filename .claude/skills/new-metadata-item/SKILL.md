# Добавление нового объекта метаданных

## Инструкция по добавлению нового объекта метаданных

1. Запроси у пользователя каталог нового объекта метаданных
2. Проверь в каталоге наличия папки `__fixtures__` с XML-фикстурами. Если папка отсутствует, попроси пользователя добавить XML-фикстуру.
3. Запроси у пользователя схему объекта метаданных
4. Запроси у пользователя список свойств и YAML-синонимы (названия на русском языке)
5. Создай файл правил `rules.ts` в каталоге нового объекта метаданных. Подробнее о правилах смотри в [rules](references/rules.md). После этого попроси пользователя проверить результат и предложи выбрать: внести изменения вручную или попросить агента внести правки.
6. Создай файл с типами `types.ts` в каталоге нового объекта метаданных. Подробнее о типах смотри в [types](references/types.md). После этого попроси пользователя проверить результат и предложи выбрать: внести изменения вручную или попросить агента внести правки.
7. Зарегистрируй объект метаданных в `PropertyTypeRegistry` (`packages/core/metadata/orchestration/property/registry.ts`).
8. Создай файл `__fixtures__/data.ts` в каталоге нового объекта метаданных. Подробнее о `data.ts` смотри в [fixtures-data](references/fixtures-data.md). После этого попроси пользователя проверить результат и предложи выбрать: внести изменения вручную или попросить агента внести правки.
9. Создай файлы тестов `fromXML.test.ts`, `toXML.test.ts`, `fromYAML.test.ts`, `toYAML.test.ts` в каталоге нового объекта метаданных. Подробнее о тестах смотри в [tests](references/tests.md).
