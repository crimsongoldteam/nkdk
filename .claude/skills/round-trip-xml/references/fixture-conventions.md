# Конвенции фикстур reproducer'а

## Один slug — один набор файлов

| Артефакт | Правило именования |
|----------|-------------------|
| XML-файл | `<slug>.xml` |
| TS-файл | `<slug>.ts` |
| TS-экспорт | `<slug>` (camelCase) |
| Ветка | `round-trip/<kebab-slug>` |
| Тест-блоки | `it("import <slug>")`, `it("export <slug>")` |

## Размещение

`packages/core/metadata/<module>/__fixtures__/<slug>.{xml,ts}`

`<module>` — наименьший значимый metadataItem, владелец правила. Не родитель, не коллекция — модуль того `rules.ts`, который должен быть поправлен.

## XML-фикстура

- Корневой тег = `xmlRootTag`, которое использует существующий `fromXML.test.ts` / `toXML.test.ts` модуля. Подсмотри рядом.
- Минимальный chunk на уровне property: только то, что воспроизводит баг. Не копируй весь узел из исходного файла.
- Форматирование (отступы, переносы, кавычки, пространства имён) — как в соседних `full.xml` модуля. XML-фикстуры сравниваются **строкой**, без канонизации — любое расхождение в форматировании сломает round-trip.
- Не перезаписывай существующий `<slug>.xml` в целевом модуле. Коллизия → стоп, спрашивай slug заново.

## TS-фикстура

Один файл `<slug>.ts` с единственным именованным экспортом — имя экспорта совпадает со slug'ом:

```typescript
import type { <ModuleType> } from "../types"

export const <slug> = {
  // ожидаемая форма объекта — что должен вернуть fromXML после фикса rules.ts
} as const satisfies <ModuleType>
```

Правила:

- Строй объект **от `types.ts`** модуля. Если поле есть в `types.ts`, но не покрыто XML-фикстурой — не указывай.
- **Не** снимай форму с текущего (сломанного) вывода `fromXML`. Фикстура = спецификация правильного поведения.
- `satisfies <ModuleType>` обязателен — ловит несоответствие формы типу на шаге компиляции, до запуска тестов.
- Если тип недоступен напрямую (например, нужен `Partial` или литеральный под-объект) — спроси пользователя, не подменяй тип молча.

## Round-trip — не пишем

Парные `it("import <slug>")` и `it("export <slug>")` эквивалентны round-trip блоку для целей reproducer'а. Отдельный round-trip блок не нужен.
