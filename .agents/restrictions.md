# Ограничения проекта

- XML-фикстуры не менять: они являются источником истины.
- Новые правила `fromXML`/`toXML`/`fromYAML`/`toYAML` не добавлять без явного запроса; предпочитать `rules.ts`.
- В `rules.ts` не задавать `order` без явной необходимости.
- В общих metadata-слоях не использовать знания о конкретных объектах, папках и XML-корнях.
- Динамические списки пока не валидируют и не преобразуют пути к данным.
- Перед закрытием задачи запускать `pnpm test` из корня.
