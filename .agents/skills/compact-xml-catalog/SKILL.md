# Компактирование XML-каталога

Создавай точную компактную копию дерева: содержимое `.xml` сохраняй, остальные
обычные файлы оставляй на своих местах с нулевой длиной.

## Запуск

Перед запуском определи абсолютные входной и выходной пути. Если пользователь
не указал один из них, запроси недостающий путь. Учитывай, что выходной каталог
будет полностью удалён и создан заново.

Запускай из корня репозитория:

```powershell
node .agents/skills/compact-xml-catalog/compact-xml-catalog.mjs `
  <input-directory> `
  <output-directory>
```

Пример:

```powershell
node .agents/skills/compact-xml-catalog/compact-xml-catalog.mjs `
  C:\git\round-trip\cf\erp `
  C:\git\round-trip-compact\cf\erp
```

## Договор

| Элемент входа                             | Результат                                |
| ----------------------------------------- | ---------------------------------------- |
| Каталог                                   | Каталог с тем же относительным путём     |
| `ConfigDumpInfo.xml` в любом регистре     | Полностью исключён из результата         |
| `Template.xml` в любом регистре           | Пустой файл с тем же относительным путём |
| Другой `.xml` или `.XML`                  | Копия байт-в-байт                        |
| Другой обычный файл                       | Пустой файл с тем же относительным путём |
| Символическая ссылка или специальный файл | Ошибка до очистки выхода                 |

Скрипт запрещает одинаковые пути и вложенность входа и выхода в любом
направлении.

Во время работы не изменяй входное дерево и родительские каталоги входа и
выхода другим процессом. Скрипт проверяет их перед очисткой, но не устанавливает
межпроцессную блокировку файловой системы.

## Отчёт

При успехе сообщи:

- абсолютные входной и выходной пути;
- число скопированных XML-файлов;
- число обнулённых файлов;
- число исключённых файлов `ConfigDumpInfo.xml`;
- число созданных каталогов;
- исходный и итоговый объём.

При ошибке покажи сообщение из `stderr` и не объявляй выходной каталог готовым.

## Частые ошибки

- Не меняй местами входной и выходной пути.
- Не заменяй скрипт командой общего копирования: она не обнулит прочие файлы.
- Не считай только строчное `.xml`: проверка расширения выполняется без учёта
  регистра.
