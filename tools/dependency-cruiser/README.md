# Проверка архитектурных зависимостей

Этот workspace-пакет изолирует `dependency-cruiser@18.1.0` вместе с
`typescript@6.0.3`. Основной проект использует TypeScript 7.0.2, публичный API
которого эта версия dependency-cruiser ещё не поддерживает.

Изолированный TypeScript можно удалить только после перехода NKDK на TypeScript
не ниже 7.1, успешной проверки `dependency-cruise --info` и прохождения
синтетической проверки type-only зависимостей.
