# Временный TS-источник сравнения

Эти файлы используются только для исследования действующего договора. Они не входят в runtime Rust и не должны становиться зависимостью его тестов. При окончательном удалении TS останутся независимые ожидания корпуса.

Для повторения i8n-profile-probe.ts создайте временный файл packages/rules/tests/migrationI8nProfiles.integration.test.ts с импортом `../../../tests/migration/oracle/i8n-profile-probe`, затем из корня выполните `pnpm --dir packages/rules exec vitest run --project integration tests/migrationI8nProfiles.integration.test.ts --no-isolate`. После запуска удалите только этот временный файл.

Результат записывается в tests/migration/i8n-full-round-trip-observations.json. Каждый вход хранится полностью и снабжён SHA256; хэши исходников также включены в отчёт. Успешное выполнение самого сборщика означает получение всех 256 наблюдений, а не отсутствие ошибок конвертера. Для успешных проходов выполняется проверка схемы корня, семантики свойства, повторных аннотированных ключей и принятия аннотаций. Исходные и оставшиеся видимыми проблемы записаны отдельно; валидация проекта целиком не выполняется. Контрольный обычный перевод обязан восстановиться без проблем проверки.
