# Работа с конфигурацией 1С в YAML

Инструмент преобразует XML-выгрузку конфигурации 1С в набор YAML-файлов и обратно.

## Идея

Проект создаёт читаемый и однозначный YAML-формат для работы с конфигурацией 1С, в первую очередь для ИИ-агентов.

Для YAML-файлов доступны схемы, контекстные подсказки и валидация структуры, ссылок и связей конфигурации.

> [!WARNING]
> Проект находится на ранней стадии разработки.

Новости и заметки по проекту публикуются в [Telegram-канале](https://t.me/overlay1c).

## Что даёт

- понятное YAML-представление конфигурации;
- двустороннее преобразование между XML-выгрузкой 1С и YAML-файлами;
- схемы YAML-файлов для ИИ-агента;
- проверку структуры и ссылок в YAML-проекте;

## Совместимость

Поддерживаемая версия платформы: `8.3.27`.

Тестирование выполнялось на XML-выгрузках конфигураций:

- Бухгалтерия предприятия КОРП, редакция 3.0, версия `3.0.193.19`;
- Управление торговлей, редакция 11, версия `11.5.25.109`;
- 1С:ERP. Управление холдингом, версия `3.2.11.3`;
- Документооборот государственного учреждения, редакция 3.0, версия `3.0.19.30`;
- Управление нашей фирмой, редакция 3.0, версия `3.0.12.261`;
- Тестовая конфигурация со всеми элементами и объектами.

## Подключение MCP-сервера

NKDK подключается к агенту как локальный MCP-сервер.

Склонируйте репозиторий и установите зависимости:

```sh
git clone https://github.com/crimsongoldteam/nkdk.git
cd nkdk
pnpm install
```

Укажите агенту команду запуска сервера:

```json
{
  "mcpServers": {
    "nkdk": {
      "command": "/path/to/nkdk/packages/mcp/bin/nkdk-mcp"
    }
  }
}
```

Замените `/path/to/nkdk` на абсолютный путь к локальному репозиторию.

После подключения агенту доступны MCP tools:

- `nkdk.get_schema` — получить схему YAML-файла или краткую сводку по ней;
- `nkdk.describe_project_structure` — узнать допустимые файлы и подкаталоги для каталога YAML-проекта;
- `nkdk.validate_project` — проверить YAML-проект и получить diagnostics;
- `nkdk.import_from_xml` — импортировать XML-выгрузку 1С в YAML;
- `nkdk.sync_to_xml` — синхронизировать YAML-проект обратно в XML.
