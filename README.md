# Редактор конфигурации 1С:Предприятие в формате YAML

Расширение для VS Code предназначено для работы с файлами конфигурации 1С на языке YAML. С проверками на ошибки и автодополнением свойств. Обмен с конфигуратором выполняется в формате XML. Для работы с формами используется язык на основе [Накидки](https://github.com/crimsongoldteam/md_design), а их просмотр выполняется средствами самого 1С:Предприятие.

> [!WARNING]
> В настоящий момент проект находится в стадии Proof of Concept. Реализована только работа со справочниками и формами, причем с серьёзными ограничениями. Новости и обновления будут публиковаться на канале [Telegram](https://t.me/overlay1c).

## Установка

1. Скачайте расширение и обработку со страницы [релизов](https://github.com/crimsongoldteam/nkdk/releases).
1. Установите расширение для VS Code. Нажмите на клавишу "F1" и выберите "Extensions: Install from VSIX...", затем выберите скачанный файл "nkdk-0.0.1.vsix".
1. Создайте новый проект в VS Code
1. Выгрузите вашу конфигурацию в формате XML
1. В VS Code нажмите клавишу "F1" и выберите "nkdk: Импорт конфигурации из XML"
1. Выберите папку с конфигурацией
1. Запустите клиент 1С:Предприятие и откройте обработку "FormPreview". Теперь при редактировании документов yaml и nkdk форма будет отображаться в обработке.
1. Для передачи обратно в конфигуратор снова нажмите F1 и выберите "nkdk: Синхронизация конфигурации с XML"

## Синтаксис формата NKDK

Текст без кавычек считается именем элемента. Текст в кавычках - это обычно заголовок элемента.

Имя элемента совпадает с реквизитом основного объекта формы:

```
.ИмяПоляВвода
```

Имя элемента отличается от реквизита основного объекта формы

```
ИмяПоляВвода(Объект.Реквизит)
```

Имя элемента совпадает с реквизитом формы:

```
ИмяПоляВвода
```

Имя элемента отличается от реквизита формы:

```
ИмяПоляВвода(Реквизит)
```

### Поле ввода

Вариант с заголовком

```
"Поле ввода": ИмяПоляВвода
```

Вариант с заголовком из реквизита

```
ИмяПоляВвода:
```

### Поле надписи

Вариант с заголовком

```
~"Поле надписи": ИмяПоляНадписи
```

Вариант с заголовком из реквизита

```
~ИмяПоляНадписи:
```

### Декорация формы для картинки

Вариант со стандартной картинкой

```
![Картинка] ИмяДекорацииКартинки
```

Вариант без картинки

```
!ИмяДекорацииКартинки
```

### Декорация формы для надписи

Вариант с заголовком

```
"Надпись" ИмяДекорацииНадпись
```

Вариант без заголовка

```
ИмяДекорацииНадпись
```

### Поле флажка

Флажок с заголовком справа

```
[] "Поле флажка" ИмяПоляФлажка
```

Флажок с заголовком из реквизита справа

```
[] ИмяПоляФлажка
```

Флажок с заголовком слева

```
"Поле флажка" [] ИмяПоляФлажка
```

Флажок с заголовком из реквизита слева

```
%ИмяПоляФлажка []
```

Выключатель

```
[|] "Поле выключателя" ИмяПоляВыключателя
```

Тумблер

```
<|> "Поле тумблера" ИмяПоляТумблера
```

> [!NOTE]
> Для выключателя и тумблера можно использовать управление заголовком аналогично флажку.

### Кнопка

```
< "Кнопка" ИмяКнопки>
```

### Командная панель

```
< "Кнопка" ИмяКнопки | -"Группа" ИмяГруппыКолонок | +"Подменю" ИмяПодменю > %ИмяКоманднойПанели
```

### Командная панель формы и таблиц

```
<< "Кнопка" ИмяКнопки | -"Группа" ИмяГруппыКолонок | +"Подменю" ИмяПодменю >>
```

> [!NOTE]
> Командная панель формы всегда должна быть первым элементом в форме.

> [!NOTE]
> Командная панель таблицы всегда должна быть перед таблицей.

### Таблица

```
| "Поле ввода" ИмяПоляВвода |~"Поле надписи" ИмяПоляНадписи |!"Поле картинки" ИмяПоляКартинки |[] "Поле флажка" ИмяПоляФлажка | ИмяТаблицы
```

```
| -"Горизонтальная группа" ИмяГоризонтальнойГруппы | +"Вертикальная группа" ИмяВертикальнойГруппы | ="Группа вместе" ИмяГруппыВместе | ИмяТаблицы
```

### Группа

Однострочный вариант

```
="Однострочная всегда группа" ИмяГруппы "Надпись" ИмяНадписи; "Другая надпись" ИмяДругойНадписи
```

```
-"Горизонтальная группа" ИмяГруппы "Надпись" ИмяНадписи; "Другая надпись" ИмяДругойНадписи
```

```
+"Вертикальная группа" ИмяГруппы "Надпись" ИмяНадписи; "Другая надпись" ИмяДругойНадписи
```

Многострочный вариант

```
="Горизонтальная всегда группа" ИмяГруппы
  "Надпись" ИмяНадписи
  "Другая надпись" ИмяДругойНадписи
```

```
-Горизонтальная группа %ИмяГруппы
  "Надпись" ИмяНадписи
  "Другая надпись" ИмяДругойНадписи
```

```
+"Вертикальная группа" ИмяГруппы
  "Надпись" ИмяНадписи
  "Другая надпись" ИмяДругойНадписи
```

### Страницы

```
//"Страницы" ИмяСтраниц
  /"Страница" ИмяСтраницы
    "Надпись" ИмяНадписи
```

### Остальные поля

```
?ПолеФорматированногоДокумента ИмяПоляФорматированногоДокумента
```
