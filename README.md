# Синтаксис формата NKDK

Символ `%` обозначает имя элемента. Например, `%ИмяПоляВвода` - это имя поля ввода.

## Поле ввода

Вариант с заголовком

```
Поле ввода: %ИмяПоляВвода
```

Вариант с заголовком из реквизита

```
%ИмяПоляВвода:
```

## Поле надписи

Вариант с заголовком

```
~Поле надписи: %ИмяПоляНадписи
```

Вариант с заголовком из реквизита

```
~%ИмяПоляНадписи:
```

## Декорация формы для картинки

Вариант со стандартной картинкой

```
![Картинка] %ИмяДекорацииКартинки
```

Вариант без картинки

```
!%ИмяДекорацииКартинки
```

## Декорация формы для надписи

Вариант с заголовком

```
Надпись %ИмяДекорацииНадпись
```

Вариант без заголовка

```
%ИмяДекорацииНадпись
```

## Поле флажка

Флажок с заголовком справа

```
[] Поле флажка %ИмяПоляФлажка
```

Флажок с заголовком из реквизита справа

```
[] %ИмяПоляФлажка
```

Флажок с заголовком слева

```
Поле флажка [] %ИмяПоляФлажка
```

Флажок с заголовком из реквизита слева

```
%ИмяПоляФлажка []
```

Выключатель

```
[|] Поле выключателя %ИмяПоляВыключателя
```

Тумблер

```
<|> Поле тумблера %ИмяПоляТумблера
```

> [!NOTE]
> Для выключателя и тумблера можно использовать управление заголовком аналогично флажку.

## Кнопка

```
< Кнопка %ИмяКнопки>
```

## Командная панель

```
< Кнопка %ИмяКнопки | -Группа %ИмяГруппыКолонок | +Подменю %ИмяПодменю > %ИмяКоманднойПанели
```

## Командная панель формы и таблиц

```
<< Кнопка %ИмяКнопки | -Группа %ИмяГруппыКолонок | +Подменю %ИмяПодменю >>
```

> [!NOTE]
> Командная панель формы всегда должна быть первым элементом в форме.

> [!NOTE]
> Командная панель таблицы всегда должна быть перед таблицей.

## Таблица

```
| Поле ввода %ИмяПоляВвода |~Поле надписи %ИмяПоляНадписи |!Поле картинки %ИмяПоляКартинки |[] Поле флажка %ИмяПоляФлажка | %ИмяТаблицы
```

```
| -Горизонтальная группа %ИмяГоризонтальнойГруппы | +Вертикальная группа %ИмяВертикальнойГруппы | =Группа вместе %ИмяГруппыВместе | %ИмяТаблицы
```

### Группа

Однострочный вариант

```
=Однострочная всегда группа %ИмяГруппы Надпись %ИмяНадписи; Другая надпись %ИмяДругойНадписи
```

```
-Горизонтальная группа %ИмяГруппы Надпись %ИмяНадписи; Другая надпись %ИмяДругойНадписи
```

```
+Вертикальная группа %ИмяГруппы Надпись %ИмяНадписи; Другая надпись %ИмяДругойНадписи
```

Многострочный вариант

```
=Горизонтальная всегда группа %ИмяГруппы
  Надпись %ИмяНадписи
  Другая надпись %ИмяДругойНадписи
```

```
-Горизонтальная группа %ИмяГруппы
  Надпись %ИмяНадписи
  Другая надпись %ИмяДругойНадписи
```

```
+Вертикальная группа %ИмяГруппы
  Надпись %ИмяНадписи
  Другая надпись %ИмяДругойНадписи
```

## Страницы

```
//Страницы %ИмяСтраниц
  /Страница %ИмяСтраницы
    Надпись %ИмяНадписи
```
